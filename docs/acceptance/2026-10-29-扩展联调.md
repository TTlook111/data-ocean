## 根因修复与独立复审

1. executing 返回已 PROTECTED 时曾继续 SQL：现在只复用同尝试/hash 的完整保护结果；未知状态停止。两处复用分支均不再进入结果核对模型预算。
2. 已有 checkpoint 忽略 Java 的恢复保护结果：同身份且完整凭据时从保护之后继续；模型/SQL 计数取较大值、期限取较早值，禁止旧尝试覆盖新 SQL。独立原样反例及边界 34/34 通过，不替代真实进程演练。
3. ANN 返回值可被重标为当前来源、同 ID 正文可被污染：ANN 只提供选择顺序和 score，正文、来源、依赖与审核信息取 Java 当前授权 membership；ID/snapshot/build 独立核对。相同副本去重、冲突身份全部排除，预算拒绝和异常 fallback 不复活冲突来源。
4. 明确技术记录计数被当作缺业务指标、或模型仅输出表达式片段：仅对整句、无筛选的记录条/行计数编译 COUNT(*)，结果不硬编码。其他业务、日期、筛选与 JOIN 仍走普通流程；所有审核、AST、IAM、行权限、保护及来源合同保留。
5. 最小技术投影/计数可由结构精确核对，不能因知识中的指令或“测试用途”文字虚构额外权限。严格排除截断 LIMIT、额外 SELECT 修饰、分区、WITH、窗口、锁等情况；不把结构 MATCH 当成 IAM 授权。共享 AST 明确拒绝 FOR UPDATE/FOR SHARE。
6. 真实受限行账号暴露执行谓词 `columnMetaId`/`columnId` 不一致：只修执行 wire，管理/候选 DTO 保持原字段名，不发送原始策略值。
7. 行条件字段未出现在投影中时缺少执行依赖：使用独立 policyColumns，仅供服务端策略注入及注入后的结构复测；原模型 SQL 按原可见字段校验，不能借策略依赖投影或自行筛选该字段。Java 验证元数据归属、快照和治理状态；实际使用归因仍按原 SQL。
8. 冻结引用按 JSON 字符串比较误判恢复：改为规范化对象键与外层引用顺序后比较，保留重复次数、来源 ID 数组顺序、版本、摘要及类型；损坏/额外 JSON 不接受。旧任务引用不重写、不补造。
9. 收尾主源回归另发现模型漏年份：任务 `2ec4cab0-d922-470e-a119-cbe1baae2499` 虽 COMPLETED 却返回 210，独立预期为 180，原结果与失败记录保留。对简单正向单公历年、当前已选表唯一可见且可筛日期字段，执行前核对每个物理扫描的所有布尔路径有年界条件或 YEAR 等价条件；不以模型 MATCH 替代。唯一性从当前可见目录核对，不能因模型少选字段或另一个日期无筛选权而替用户选择日期口径。否定/开放年份、字面文本、混合历史指标、多日期及非公历不机械推断；无法证明的复杂作用域安全失败，不强迫改写合法业务口径。
10. 模型只返回 COUNT 表达式及连续未审列别名：安全单表达式进入原 SQL/LLM 预算内格式修复，多语句、写入、变量、危险函数与不允许字段不会被当作格式错误。生成阶段把未审输出标签编译为技术名并同步本作用域排序，仍保持字段、公式和筛选；关系内层与 GROUP/HAVING 别名依赖保留门禁。
11. 明确的无筛选单数字字段 SUM 可由技术请求生成，不硬编码字段或答案。其正向全值域必须完整绑定已审字段标签与中性实体尾词，比较/范围修饰、否定尾句不能提供全值证据；尾句否定的其他指标必须有已审名字。结果仅来自完整 Java 保护回执，数值/NULL 不伪造，错误类型拒绝。实际用户条件不删除，IAM 条件仍后注入。
12. 明确字段与完整公历区间的单表投影可按严格 SQL 形状核对，结果是否为空由受保护回执证明。领域实体还须有已审表粒度和已审标识字段共同绑定；否定粒度文字、多个标题/粒度及仅同名字段不能证明实体。唯一可见日期仍须具筛选权，不能静默改用更新时间。其他日期口径、复杂 SQL 和业务含义继续走原语义判断/澄清。
