## 第一轮：治理闭环核心实现（红队补强前）

后续红队审查澄清：本轮证明的是列明的实现路径，业务文档生成时的精确集合检查不能等同发布/构建组已经覆盖预期业务事实；新版本形式复查也不能证明原反馈问题已修复。这些审查时的补强缺口及待补测试见[红队审查与最终方案](../archive/reviews/2026-10-24-治理闭环红队审查与最终方案.md)。原计数不包含该审查提出的新反例。

该澄清描述审查时的缺口，用户授权后的修改与证据另见本文末尾“2026-10-24 红队补强”；原轮次记录不回写成当时已通过新用例。

治理总览以“开始知识治理”为主入口。字段治理默认显示任务，按当前源与快照发现字段解释、角色、单位/枚举以及数据源用途、表粒度和关系知识缺口。后台 AI 逐项生成候选，失败可重试或人工接管；不会覆盖已有人工草稿。字段解释复用语义中心原工作面，业务知识复用同一工作台并提供语义中心入口；被替代的历史草稿/有效版默认收起，可展开追溯，当前有效版和新草稿同时保留。

人工保存、审核与复查对应精确来源和修订。来源变更需比对并确认，并发保存与晚到 AI 不能覆盖新版本；不适用和失败独立显示。字段完成需分类及当前 definition/binding/revision/review/evidenceHash、规则版本 2 和成功复查批次一致。`DISCOVERED` 可进入治理，问数资格仍按原严格规则判断。所有操作在平台内持久化，不修改业务源注释或数据。

文档组解释数据源用途、表用途/粒度、已审核关系/基数/聚合风险、指标与字段。单篇核对事实，构建确认与执行核对整组覆盖及精确业务修订；原始外键/推断关系为线索，不冒充已审核业务连接。非空文档重新生成独立文档组，保留人工正文；受控事实改变走知识修订。发布和显式 RAG 确认仍分开。

字段标签及动态使用可信度独立于正文。Java 在模型输入前验证当前权限、完整依赖与精确版本，查询任务固定档案与业务事实引用。评分变化不重切文档；旧向量分数不能替代当前档案，无使用证据显示不足。已选候选不等于实际使用，反馈按授权 SQL 中真正使用的字段归因。

一般问数评价先待归因，审核字段原因后记录版本化证据；修改意见撤销旧贡献，相同来源只贡献一次。非字段原因保留为关系/指标/SQL/展示问题，不批量扣字段分。试行策略 `(正向+1)/(总数+2)*100` 是使用证据参考，仍需业务校准。确认的负向当前版证据产生再治理任务，新修订复查后关联反馈进度。用户可查看自己评价状态，不读取审核私注。审计、状态和计分同事务，历史贡献可追溯。

## 2026-10-24 红队补强

| 失败回归 | 修正后的行为 |
| --- | --- |
| `SUM(amount)` 隐藏未限定字段；子查询/别名/窗口或函数内部排序隐藏依赖 | 使用现有 JSqlParser 完整解析受限表达式，所有节点走白名单；字段必须使用真实表名并声明表/字段依赖。未知语法、变量、子查询、窗口和复杂度超限明确拒绝，字面量中的点不误判 |
| 删除业务关系篇但表字段覆盖仍完整 | `validateCoverage` 同时精确比较当前有效业务事实类型与修订 ID，拒绝遗漏、额外引用及重复，确认和执行均复核 |
| 模型生成自己的 evidence 并覆盖输入资料 | 原始人工输入保留；AI 版本不继承人工确认。业务知识保存可记录资料引用、摘录及明确人工确认，绑定操作者、内容 hash 与来源 hash；缺少或失配不能提交/批准/复查 |
| 单字段只有审核意见就通过 | 新的 APPROVE 必须提供原始资料引用并明确确认人工核对，引用与意见进入精确修订/来源的不可变审核记录；AI 参考说明不冒充已确认依据 |
| 新修订形式复查直接结束原差评 | 负向字段归因先固定复现情景和预期结果；知识复查只推进 `AWAITING_VERIFICATION`，人工在平台中记录原标准对应实际结果、证据引用并确认，且新版本仍有当前有效批次，才进入 `VERIFIED` |
| 错误结果或旧版本尝试验收 | 保持待验证；过期版本/重复提交不允许结案。用户端只显示处理阶段，不泄露审核私注与验收资料 |
| 老执行恢复后覆盖新 worker | 唯一领取 token 同时保护候选最终落库与任务状态回写；最终落库使用短事务和行锁，不跨模型调用占锁。暂停使旧 token 失效 |
| 换问题措辞、SQL 空白或用户反复贡献同一证据 | 按数据源/快照、精确字段语义版本、规范化最终 SQL 合并样例；旧政策事件仅留档，新事件政策版本 2，不静默回填成独立证据 |
| 一键范围或重试无上界 | 快照超过 200 字段、100 表或 100 关系时拒绝批量并引导单对象治理；单次最多创建 200 任务，失败项每轮最多执行三次，支持暂停；反馈进入新轮次时保留原轮次审计 |
