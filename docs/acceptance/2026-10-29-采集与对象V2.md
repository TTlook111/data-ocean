## 完成的页面

- 采集任务按读取数据库结构、形成独立快照、进入治理与审核组织。保留后端分页/总数、触发方式、状态/进度、开始/完成时间、错误原因、运行中轮询、重试和生成快照入口。任务返回编号只证明请求已接收，成功不代表已发布或已构建 RAG；重试创建新任务，不能称作恢复。
- 发起采集使用同一绑定目标源的 `metadata:collect:run`，不额外要求 `datasource:view`。统计默认关闭，可开启；提交中禁止重复操作。跨源提交有查看权时定位该源，无查看权时显示任务编号及交接说明。当前页运行任务仅作提醒，后端裁决并发。
- 同步计划清楚标为影响全部启用数据源的全局配置。采集员只读，受保护系统管理员保存；每日/每周/自定义 Cron、开关、未保存预览均保留。不能无损映射到预设的 Cron 保留原串；清空时间提示且禁止提交。`running` 仅表示调度已注册，不能当正在采集。计划切 Tab 保留未保存草稿，任务切走停止轮询。
- 正式目录与快照结构共享一个数据源选择区。正式目录展示发布快照身份、同步状态、表/字段及集合内搜索，完整 FQN 展开/复制、对象版本和返回位置保留。搜索不伪装成服务端分页；对象版本不冒充快照版本。
- 结构页显示所选版本的表与字段。首批50条外的显式历史快照精确读取，失败不选最新；列表重试恢复字段读取；字段顺序、主键/可空性、治理状态、行数估算及统计缺失保留。
- 对象详情阅读优先，维护和复制归入对象上下文。字段、术语、标签治理、所属引用、血缘、下游及技术信息全部保留。原始注释不冒充业务定义；来源快照和当前发布目标不一致时分别说明；部分无权/失败不写成零。

完整功能映射见[第三阶段功能映射](../development/前端第三阶段-采集与对象功能映射.md)。实现继续使用用户批准的暖白/墨色/铜橙方向、原品牌资产及既有 Vue/Element Plus，不新增全局框架。

## 权限与请求保护

| 边界 | 本轮行为与验证 |
| --- | --- |
| 任务查看/执行分开 | 当前源 collect:view 与目标源 collect:run 分别控制；仅查看不显示重试或跨域维护入口；仅执行源不借其他角色的负责源 |
| 全局计划 | 负责源采集员只读；保存仍由 Java 再次检查系统管理员身份，不把局部采集权扩大到全局 |
| 元数据最小角色 | 目录、结构、详情不新增 datasource:view/readiness 依赖；浏览器记录 metadata-only 账号没有读取这些管理端辅助接口 |
| 显式源 | URL必须为合法正整数且有目标metadata查看权；不同步时不读偏好源。共用ScopeBar独立挂载，有权链接可切到目标源，无权链接明确拒绝 |
| 精确版本 | URL及本页选择器决定显式快照；公共store初始化偏好不能改写历史URL。快照/目录/实体返回身份均核验 |
| 换源/账号/撤权/卸载 | 成功、失败、finally及滚动恢复按请求代次、token、目标作用域隔离；能力摘要的loaded/error变化也触发失效 |
| 标签取消 | 只关闭本页确认框；确认后重核身份、对象及权限；旧DELETE完成回调不能解锁同实体刷新后的新操作 |
| 跨域定位 | 字段解释传真实来源快照、表名、columnMetaId；血缘传datasourceId和entityId，不互换，不拼接跨源权限 |

独立审查实际发现并修复：跨源提交落点、预设时间清空、旧标签finally解锁新操作、显式源回退以及合法跨源结构深链同步死锁。浏览器还实际暴露了初始化偏好覆盖历史快照URL，现已去掉该反向写回。相应反例保留在测试中，没有为测试通过扩大权限或弱化原业务断言；既有详情测试中的列对象响应ID、最小元数据能力mock随新增身份核验校正。
