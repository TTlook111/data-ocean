## 实际改动

- 问数从常驻并排结果栏改为左侧历史/新建、中间连续问答、底部 composer。数据源只在 composer 附近出现；结果在各自回答中展示，SQL、来源与大视图按需打开。
- 每条完成回答持有独立分页、图表、SQL、CSV 和反馈状态。卡片进入可视范围时重新读取 Java；完成正文、追问和结果一起受该次读取保护，不以旧 metadata 补出被拒绝的内容。
- 保留加载、空集、澄清、失败、取消、服务端超时、本地等待到期/恢复；只呈现实际阶段，不把固定步骤猜成全部完成。新任务执行时旧图表仍属于旧回答。
- 修正源、会话与账号切换中的迟到导航/请求、提交前异步窗口、停止后的迟到成功、旧 CSV 下载及反馈补充框归属；历史列表和消息失败具有明确的同源重试。
- 对齐既有 Java 权限合同：普通问数的 SQL/导出采用顶层 `viewSql/exportResult` 与 fresh 任务结论，不额外要求后台负责源；后台同绑定规则保持原义。

`frontend/src/styles/product-workspace.css` 只作用于问数及相关浮层，避免本阶段影响后台/登录页。用户提供的 `DataOcean-Logo/03-品牌蓝透明母版-紧裁.png` 已实际查看，原样复制到 `frontend/src/assets/brand/dataocean-mark.png`，保留品牌蓝与比例，没有生成或重画标志。

按已在云端隔离目录核验安装的官方 UI UX Pro Max 2.15.0 执行。除前轮设计系统检索，本阶段实际查询 `chat state preservation --domain ux` 和 `watch cleanup async --stack vue`，落实状态保留、可取消过渡、显式监听、作用域清理、键盘焦点和响应式规则；用户认可的 V2 结构优先于通用模板建议。安装包、缓存与 skill 不进入业务仓库。

## 浏览器覆盖

脚本：[query_conversation_v2.py](../../scripts/frontend-acceptance/query_conversation_v2.py)。只允许回环前端地址，拦截全部 Java API；示例账号、任务和数据均为合成资料。截图右下角标注“浏览器验收 · 合成 API 响应”。

26项检查包括：单列对话与唯一数据源入口；无后台负责源 reader 的 SQL/导出显示；SQL 不预取、按需读取与关闭；同任务来源/快照/权限/保护摘要；图表/数据切换；CSV/反馈归属；重复发送；处理中不串旧图表；停止；两轮结果及回看旧 SQL；换源/未就绪；反馈框卸载；完成空集；当前读取拒绝；无 SQL/导出；服务失败；澄清；服务端超时；历史列表/消息同源重试；初次加载；新会话/数据源失败/无可访问源；响应式与键盘；应用异常检查。部分检查将数个同类断言记为一项，详细项名以 JSON 为准。

视口为 390×844、768×1024、1024×768、1440×900、1600×1050 与 844×390 横屏。确认整页无横向溢出、输入区可达、窄屏历史可展开、数据源菜单可键盘打开及 Escape 恢复焦点；启用 reduced motion。桌面截图使用 1600×1050、DPR 1.5。
