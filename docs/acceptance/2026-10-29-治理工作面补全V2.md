## A：治理总览、质量覆盖与问题中心

总览明确来源质量 SOURCE 与业务语义 SEMANTIC 的不同作用，保留知识治理导航、来源质量检查、当前规则只读规划、问题摘要及实际批次/覆盖记录。主状态直接显示实际执行数（包括0）、失败与不适用数；完整/部分/失败/运行/历史有限/未知分别表达。历史0分不丢失，也不冒充当前完整评分；规则准备不等于已经执行，零问题不等于通过。当前完整评分只在同批次真实返回 totalScore 时使用该批次标签。

问题中心保留问题域、表、状态、维度、级别、责任人、分配给我、服务端分页、逐项及批量处理、分派、重开、同表发布记录与回治理/发布入口。未知域数量显示未提供，不补0。SOURCE与SEMANTIC各按后端状态规则处理；语义解决/驳回补齐已有接口要求的resolutionNote，冻结问题/源/快照，409保留输入。服务端仍校验最新成功语义复查与当前完整解释证据，来源检查不能替代。问题关闭也不证明原问数情景已人工核验。

| 边界 | 本批行为 |
| --- | --- |
| 功能权限 | 总览view、规则view、问题view、来源check独立，不把总览权当全包。当前源/快照由公共范围核验；最小治理角色无metadata:view的快照读取缺口继续明确提示，不补权 |
| 辅助目录 | 表目录独立metadata:view，用户目录独立全局organization:user:view。缺辅助能力不阻断已核验范围的合法问题API；表目录挂起也不阻主列表或统计；原精确表名过滤不被静默清为全部 |
| 读取隔离 | 身份/IAM/源/快照与单调代次使旧列表、统计、覆盖、目录、详情和错误失效；权限摘要已loaded但error时，重试强制重读 |
| 写入隔离 | 单条/批量/分派/重开与检查入口防重复，确认后重验当前能力与归属；切范围/身份取消自己的确认，不全局关闭其他弹窗。各await后重验，不把旧成功提示新范围 |
| 未知结果 | 同身份/真实目标的检查和问题写入共享内存锁；网络/408/5xx保留原目标，跨工作面阻止重复，不能凭旧SUCCESS解锁。不跨整页刷新，不能替代后端幂等 |
| 批量回执 | 冻结原ids，逐条保留updated/skipped/issueId/reason，不报全部成功，不自动重发；语义跳过项引导逐条核对依据 |
| 详情 | 同表记录需发布查看权；不存在单问题历史接口，不伪称完整问题历史。辅助失败有错误态，不等同零条记录 |
