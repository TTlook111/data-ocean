## 验收方法与证据维护

- 复跑前从[系统联调验收](../development/系统联调验收.md)确认成功标准、独立预期与权限边界，再按[验收脚本说明](../../scripts/system-acceptance/README.md)选择入口。
- 报告写明实际提交、环境、角色、操作、回执与未测范围，分别注明 H2/Mock、真实 MySQL、真实模型、浏览器回放和已登录操作。原始日志保留失败轨迹，凭据留在本机私有配置。
- 结束一轮验收后，将报告移入[已归档轮次](../archive/README.md)，仍需开发、复验或人工核对的事项继续维护在[后续开发](../development/后续开发.md)。历史验收结论保留原时点和覆盖边界。
