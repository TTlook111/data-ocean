## 如何维护

- 当前行为写模块、剩余工作写[后续开发](../development/后续开发.md)；复跑合同和命令只维护在[系统联调验收](../development/系统联调验收.md)及[验收入口](../../scripts/system-acceptance/README.md)。
- 同一环境/同一验收范围更新已有报告；先确认有独立证据价值再增加报告，避免每次小修改新增一份。不要复制旧迁移/测试流水。
- 失败、中断和未知写入结果不能被后续成功抹掉；H2、真实MySQL、模型、接口和浏览器分开。原日志/截图在本机环境指定位置，凭据不得写入共享文档。
