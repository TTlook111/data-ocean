# 工作台与治理总览 V3 实施验收

用户已认可 [V3 样稿](../previews/workbench-v3-20261031/README.md)，授权正式改造。本报告集中记录云端实现、公司真实联调和独立复验，三者分别记载；本轮未完成的验证不得沿用旧报告判为通过。

## 当前阶段

两批分别实施正式工作台和治理总览；首批工作台已推送 `65f28d9ec529f0237484d211d523e09f4e2f868b`，治理总览已完成实现与最终云端验证，作为第二批独立提交。公司与独立真实复验尚未执行本批代码。基线 develop `e4c86a5267e517da608919ef4134c9e1bd3f023a`，main 不参与本轮。

工作台读取现有权威 API，没有正式演示数据：负责范围的来源准备预览最多三个，选中来源后显示独立准备条件、实际阻断及一个有权进入的下一步。审批最小角色读取现有队列两条预览和总数，不额外读取数据源或元数据。无来源查看权时保留字段、知识或其他已授权工作入口，不把无权当作0个来源。

准备动作按已知业务状态码映射正式工作区，忽略后端历史 actionPath；显示与触发均检查同来源能力。缺少版本查看权时保持禁用并解释，不借来源查看权补权。无活动知识索引单独展示；后台授权配置不等于当前账号的问数许可，没有新增 RAG 硬门禁。

来源列表与准备结果校验身份、范围、唯一ID和字段完整性。未知结果、缺失/错误回执、失败和确认空分别处理；一次工作台读取最多核对100个来源，超过上限的准备状态保留未知，不推算总体分类。页面级 `focusSourceId` 只在当前有权来源目录中恢复，支持返回/刷新；非法或无权定位明确拒绝，需显式重选，不能跳到其他来源。该局部定位不会扩散到其他工作区参数。

## 先失败与修复证据

- 新增六项 V3 合同行为回归在旧组件全部失败，原因包括缺少有限来源预览、精确受权入口、独立知识状态、审批两条预览，以及403后仍追加旧批量读取。
- 实现中追加发现：工作台403已明确拒绝，但旧目录请求悬挂使“重新核验”被加载锁阻止。先失败回归确认仅有一次统计读取，之后为整页加载增加独立序列并在拒绝时立即释放当前读取状态；旧 load 结束不能结束或覆盖新的读取。
- 新增精确定位恢复、缺布尔字段保留未知、100读取上限等回归；没有修改后端、数据库、权限、模型配置或授权。

## 第二批：治理总览正式实现

继续使用 `/admin/governance` 及既有 governance:view、公共来源/快照范围，没有增加菜单、权限码或后端接口。主区是表×处理状态集中度、SOURCE/SEMANTIC构成和独立来源校验覆盖；不展示完整问题处理清单。已有来源检查、规则规划、历史评分与覆盖证据保留在按需展开的“执行依据与更多操作”，没有删除功能或把历史评分冒充本次评分。

问题总数及状态/分域边际分布来自 snapshot summary；表排行只读取 OPEN、CONFIRMED、REOPENED 三种单状态的完整分页。最多2000条、24次明细请求，每页100条；逐页核对总数、ID去重、状态、快照、可返回的来源归属，并与二次摘要和分域对账。超预算、空缺/小页异常、重复、错属、计数变化或网络失败即撤下表排行与涉及表数，保留可核实摘要。没有事务读取水位，界面和合同明确“非事务快照”，不以所有页请求成功证明原子一致。只展示前8组时明确还有多少问题未绘；无表名记录独立分组、不计入真实表数、不伪造该表名过滤。

分域或表汇总点击先选单个状态，表色段可直接传真实 tableName＋status。状态选择固定来源、快照与范围世代；切源/快照/身份关闭弹层；无完整交叉计数时显示未知，不从两个边际分布补造。问题页仍只支持单状态，不发送虚构 UNRESOLVED 参数。REOPENED 统一展示“需重新处理”（总览、问题筛选/行及通用徽标），原值、类型、状态机和操作不变；说明明确人工重新开启及语义复查两种来源。

校验执行图只按真实批次规则及核对一致的 ruleCount 作分母；缺失分母、无记录、有限历史、失败、无权分别说明。SUCCESS 指规则执行成功，不能当作质量通过率；PARTIAL/complete=false 不显示本次完整评分。停止表聚合只取消前端继续读取与回填，不调用后端取消或更改业务状态，仍可重新读取。

新增对抗回归覆盖聚合上限、异常小页请求预算、去重/错属/漂移、明细403、取消后重读、弹层切范围、精确筛选以及未知/0。另先复现并修复：弹层打开后明细403，已知拒绝应清除问题摘要并关闭弹层，不能沿旧选择继续导航。历史两项测试更新依据：入口由“开始知识治理”转为展开后的“字段治理”，仍断言精确源/快照与零检查写；批次生命周期 fixture 补充 DTO 要求的 snapshotId/datasourceId，保留旧账号迟到不覆盖新批次断言。没有删除不通过的权限或业务验证。

第二批真实 Vue 浏览器初次导航发现未定义的合成“表目录”辅助读取，已补齐有权目标页的只读 fixture；另一次检查错误地要求切源自动把新快照写进 URL，源码已确认现行 ScopeBar 会主动移除旧快照参数，当前快照由新源核验结果选择。测试改为确认新来源、移除旧快照、读取新范围统计，未改共享范围政策或生产代码绕过检查。失败原批次留本机，不记为通过。
