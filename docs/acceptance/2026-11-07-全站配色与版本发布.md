## 浏览器、对比度与前端回归

ego-lite 在 1440×900 下打开 35 个已登录入口和独立 origin 的登录页，核对路径、实际组件、最终主色和横向边界，再按实页缩略图复看。36 个入口均挂载，未见整页横向溢出。这次覆盖的是实际登陆身份下的首屏。真实无数据、拒绝和 Python 服务离线状态均按当时结果保留。图像由本机生成，其他机器需重新取得原件。[逐页记录](../../../DataOcean-runtime/release-palette-20261107/final-routes.json)

登录另实测 1366×768、1920×1080、390×844 和 1100×620。空提交定位账号输入，显隐密码和刷新验证码均可操作。失败后焦点与首次改密路由由定向回归覆盖。版本列表和详情另做两种桌面视口检查。

浏览器实测发现危险按钮的库默认悬停色过浅，危险按钮白字初测 2.11:1，真实撤回链接悬停初测 1.59:1。调整实心按钮和文字动作各自的悬停、按下及可见焦点颜色后，最终海蓝主题的 78 个颜色样本达到本轮阈值。其中正文 14.31:1，次级文字 6.01:1，主按钮 8.54:1，实际撤回悬停 7.70:1，SQL 代码 12.68:1，六类图形与底色为 4.29–6.88:1。禁用比较按钮 2.48:1 单列记录。这些测量覆盖所列元素和状态。[测量记录](../../../DataOcean-runtime/release-palette-20261107/contrast/README.md) · [最终输入与结果](../../../DataOcean-runtime/release-palette-20261107/contrast/contrast-summary.json)

最终前端全量 **105 文件、1280/1280 项通过**，类型检查与生产构建通过，仍有现有大分包提示。中间全量运行有 4 处旧文案断言失败。工作台将统计范围保留在可见指标名，治理空状态按未解决问题口径断言，随后重跑全量。装饰动画的专用断言随功能移除，实际认证合同继续测试。[最终全量回归](../../../DataOcean-runtime/release-palette-20261107/final-regression.log) · [生产构建](../../../DataOcean-runtime/release-palette-20261107/build-delivery.log)

本轮复用主机 `LAPTOP-9H1M0JLF` 的五个既有健康依赖。隔离库 `dataocean_e_acceptance_20260927` 为 V77，本轮没有新增迁移。正式 API 拒绝重复登记相同的 host、port、databaseName，返回 409。两个现有测试源均有正式快照。源 2 另有 16 条原有未解决 SOURCE 问题。验收使用源 2 新采集的快照 5 和标记测试规则 30，成功替换与全量复查采用外层回滚演练。[环境预检](../../../DataOcean-runtime/release-palette-20261107/preflight.json)
