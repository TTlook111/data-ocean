## 实现链路

S1 retrieve → retrieve_schemas → 向量召回、过滤与重排 → 图的资源规划；相邻片段与降级候选仍受相同来源及授权边界约束。

## 关键约束与关联影响

已确认消费缺口由[治理适配问题](../../development/RAG与问数治理适配问题.md)维护；修改 BUSINESS_RELATION 或纯表级事实时同时核对 Java membership，不能只改 Python 类型转换。
