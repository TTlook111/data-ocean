## 实现链路

confirmBuild 冻结构建 → 调度 processQueuedBuilds → Python 客户端切分/写入 → 数量与 manifest 核对 → activateVerifiedBuild → 后续 cleanupSupersededBuilds。

## 关键约束与关联影响

文档发布不自动确认构建；失败不切活动指针，在途引用未结束不得清理。Python 通用向量 API 不是跳过 S1 build 的替代路径。
