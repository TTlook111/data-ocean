## 功能说明

定位任务提交、取消、恢复和完成落库。恢复仅适用于属于当前账号且仍为 PROCESSING 的 S1 任务；不是恢复已取消任务。

## 实现链路

提交：sendQuestion → iamS1Ask → IamS1QueryServiceImpl.submit → Python 客户端异步派发 → execute_query → run_query_graph；结果经 Java complete 处理。

取消与恢复分别经过 cancel/resume；恢复前检查当前权限、快照、会话轮次与最近尝试状态。

## 关键约束与关联影响

取消与完成可能并发，不能以按钮状态代替服务端状态。恢复不得重置预算；checkpoint 不可用时停止。COMPLETED 仍需匹配同任务 PROTECTED 尝试与精确 SQL hash。
