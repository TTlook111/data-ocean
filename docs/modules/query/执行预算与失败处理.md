## 实现链路

图在受控调用前检查时限与预算；Java reserve/settle 记录模型调用预算。Python 结果回到 Java，再由页面任务读取展示。

## 关键约束与关联影响

预算调整需核对 Java、Python 与恢复流程。欠费、认证、限流、网络故障不能提示用户补业务条件；本地等待超时不等于服务端超时。
