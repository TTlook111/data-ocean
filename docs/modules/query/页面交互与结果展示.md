## 功能说明

问数以连续对话为主：左侧历史、中间逐轮消息、底部固定输入。完成回答内嵌图表/数据，SQL、来源与大视图按需弹窗；保留历史分页、澄清、失败、停止和恢复等待。页面组件负责组合，主要请求与状态逻辑在 composable。

`useQueryExport.exportPng` 当前只提示功能开发中，不是已完成的 PNG 导出实现；不要把方法存在当作导出能力已交付。

## 实现链路

QueryDatasourceView.vue 组合 useQuerySession/useQuerySubmit → iamS1.ts → Java 查询 API；pollTaskResult 同时接收进度并读取最终任务。完成消息由 QueryAnswer 再次按当前权限读取，再交给 QueryResult 内嵌或弹窗显示。当前 readiness 不冒充历史任务的冻结依据。

## 关键约束与关联影响

调整本地等待提示时必须区分 localWaitTimedOut 与服务端 TIMEOUT；界面显隐不替代服务端授权。完整状态规则见[任务生命周期](任务创建取消与恢复.md)。
