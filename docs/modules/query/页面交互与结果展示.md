## 功能说明

定位输入、进度、当前结果选择、SQL 展示和导出交互。页面组件负责组合，主要请求与状态逻辑在 composable。

## 修改位置速查

| 修改意图 | 文件与定位符号 | 关联影响 |
| --- | --- | --- |
| 发送、进度与结果选择 | [useQuerySubmit.ts](../../../frontend/src/composables/useQuerySubmit.ts)：`sendQuestion`、`pollTaskResult`、`applyPollResult`、`selectResultForTask` | SSE 用于进度；轮询读取任务结果。切换结果需防止旧请求覆盖。 |
| 请求与取消接口 | [iamS1.ts](../../../frontend/src/api/iamS1.ts)：`iamS1Ask`、`iamS1GetTask`、`iamS1CancelTask`、`iamS1StreamTask` | 公共请求只到 Java。 |
| 查看 SQL | [useQuerySubmit.ts](../../../frontend/src/composables/useQuerySubmit.ts)：`refreshSql` | SQL 必须属于当前选中的任务，读取失败不能保留其他任务 SQL。 |
| CSV 导出、评价与处理状态 | [useQueryExport.ts](../../../frontend/src/composables/useQueryExport.ts)：`exportCsv`、`handleFeedback`、`refreshFeedback` | 绑定当前显示任务，CSV 仍经服务端授权；反馈归因见治理专题。 |

`useQueryExport.exportPng` 当前只提示功能开发中，不是已完成的 PNG 导出实现；不要把方法存在当作导出能力已交付。

## 实现链路

QueryDatasourceView.vue 组合 useQuerySubmit → iamS1.ts → Java 查询 API；pollTaskResult 同时接收进度并读取最终任务。

## 关键约束与关联影响

调整本地等待提示时必须区分 localWaitTimedOut 与服务端 TIMEOUT；界面显隐不替代服务端授权。完整状态规则见[任务生命周期](任务创建取消与恢复.md)。
