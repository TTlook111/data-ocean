## 功能说明

定位会话列表、消息分页、当前轮次与摘要。Java/MySQL 是会话事实源，Python checkpoint 不保存另一套完整历史。

## 实现链路

页面 useQuerySession → iamS1.ts 会话 API → Java 查询/会话服务；提交查询时 buildQueryContext 组装上下文，保存助手消息后触发摘要刷新。

## 关键约束与关联影响

会话固定属于一个数据源；摘要不是授权依据。修改摘要不得让执行器饱和时在请求线程执行完整模型调用。
