## 功能说明

定位文档编辑、快照目录生成、审核与发布。发布文档与确认 RAG 构建是两个动作。

| 生成目录与切片预览 | [KnowledgeDocPublishService.java](../../../backend/DataOcean/src/main/java/com/dataocean/module/knowledge/service/impl/KnowledgeDocPublishService.java)：`generateDraft`、`batchGenerateFromSnapshot`、`generationInputs`、`previewChunks` | 类名 Publish 不表示它负责活动 build 切换。 |
| 审核与发布 | [KnowledgeDocLifecycleService.java](../../../backend/DataOcean/src/main/java/com/dataocean/module/knowledge/service/impl/KnowledgeDocLifecycleService.java)：`submitReview`、`approve`、`reject`、`publish` | 审核资格、来源和版本。 |

## 实现链路

KnowledgeDocController 分派 CRUD、生成与生命周期操作；生成目录形成草稿，审核发布后，构建走[构建与集合生命周期](../rag/构建与集合生命周期.md)。

## 关键约束与关联影响

更新事实结构时同步检查 KnowledgeSnapshotFactValidator 与 Python chunker；保留精确来源、审核记录和完整依赖。页面入口为 KnowledgeView.vue 与 KnowledgeDocView.vue，见模块首页。
