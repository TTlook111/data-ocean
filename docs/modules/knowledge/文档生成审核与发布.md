## 功能说明

定位文档编辑、快照目录生成、审核与发布。发布文档与确认 RAG 构建是两个动作。

## 实现链路

KnowledgeDocController 分派 CRUD、生成与生命周期操作；生成目录形成草稿，审核发布后，构建走[构建与集合生命周期](../rag/构建与集合生命周期.md)。

## 关键约束与关联影响

更新事实结构时同步检查 KnowledgeSnapshotFactValidator 与 Python chunker；保留精确来源、审核记录和完整依赖。页面入口为 KnowledgeView.vue 与 KnowledgeDocView.vue，见模块首页。

## 前端编辑与证据隔离

详情表单基准锁与内容版本号分开。未保存标题或正文不能提交旧保存版；普通刷新保留输入，替换已保存稿需确认。自己保存后等待期间继续输入，只有精确重读确认新锁和保存载荷才继续推进基准，不能借第三方版本绕过冲突。所有详情辅助读取以doc.version为证据代次，切分/来源/审核历史缓存随新修订清除并重读；明确查看历史正文仍有版本标签。

列表与非空详情的完整目录生成会创建独立文档组，按身份、源和快照共用在途/未知记录；空文档generateDraft保持独立文档锁。来源预览验证实际源/快照并按knowledge:manage读取，元数据选择器的metadata:view不自动扩展到其他知识接口。候选窗口固定文档与版本，换表范围清候选和人工确认，采纳期间冻结输入。

前端新建回执固定id/source，切账号和旧回包不改变新草稿或导航；只有目标源的knowledge:view才进入详情。定向和合成浏览器证据见[验收](../../acceptance/2026-10-29-版本与知识V2.md)。
