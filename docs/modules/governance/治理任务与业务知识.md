## 功能说明

用于修改缺口发现、一键治理、重试、业务知识修订与语义复查。来源质量规则与这里的业务语义治理分开。

## 修改位置速查

| 修改意图 | 文件与定位符号 | 关联影响 |
| --- | --- | --- |
| 发现任务、重试和后台处理 | [GovernanceTaskServiceImpl.java](../../../backend/DataOcean/src/main/java/com/dataocean/module/fieldsemantic/service/impl/GovernanceTaskServiceImpl.java)：`discover`、`retry`、`processQueued` | 快照、对象预算、当前权限及任务领取。 |
| 调度入口 | [GovernanceTaskWorker.java](../../../backend/DataOcean/src/main/java/com/dataocean/module/fieldsemantic/service/impl/GovernanceTaskWorker.java)：`tick` | 调度调用不等于任务已完成。 |

| 业务知识修订与审核 | [BusinessKnowledgeServiceImpl.java](../../../backend/DataOcean/src/main/java/com/dataocean/module/fieldsemantic/service/impl/BusinessKnowledgeServiceImpl.java)：`save`、`generate`、`action`、`sourceStatus`、`facts`、`membershipValid` | 数据源用途、表粒度、业务关系和指标的来源/依赖。 |
| 独立语义复查 | [SemanticCheckServiceImpl.java](../../../backend/DataOcean/src/main/java/com/dataocean/module/fieldsemantic/service/impl/SemanticCheckServiceImpl.java)：`run`、`latest` | 复查证据必须对应当前修订。 |

## 实现链路

GovernanceWorklist 经 governanceWorkflow API 发起操作；GovernanceTaskServiceImpl 发现并排队，GovernanceTaskWorker.tick 调用后台处理。字段任务进入 FieldSemanticServiceImpl，业务知识任务进入 BusinessKnowledgeServiceImpl；复查由 SemanticCheckServiceImpl 提供。

## 关键约束与关联影响

AI 结果是候选，不能覆盖人工确认和审核。新修订通过不等于原负向反馈已结案，后者见[反馈与使用档案](反馈归因与使用档案.md)。发布与 build 生效继续遵守知识/RAG 模块合同。
