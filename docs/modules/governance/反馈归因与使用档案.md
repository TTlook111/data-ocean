## 功能说明

用于修改问数评价、字段归因、当前版本使用参考分与原情景人工验收。旧 fieldtag 来源可信度不在这条计分链上。

## 实现链路

用户通过问数反馈接口提交 → GovernanceFeedbackServiceImpl 保存评价 → 管理端归因审核 → 有效证据影响精确版本使用档案；再治理及复查后仍需 verifyResolution 按原情景核验。

## 关键约束与关联影响

不能把读取过的候选字段都算作实际使用。无证据不记零分；规范化 SQL 样例去重及政策边界由现行治理模块维护。原预期结果不得为结案而改写，当前修复版本与人工证据必须匹配。

usedFields 以已保护任务保存的 usedColumns 为实际使用证据，并与该任务授权请求的字段范围相交；COUNT(*) 为取得表级授权而选的字段锚点不参与归因。缺少实际字段证据时返回空使用集合，不把全部授权字段补成使用证据。
