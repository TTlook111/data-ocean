## 实现链路

图生成候选 SQL 并做本地 AST 预检 → Java authorize → Python 按精确授权快照再校验 → Java 执行状态确认 → Python 只读执行 → Java protectResult → Java complete。已受保护尝试可复用原结果，但必须匹配当前 attemptId 与 SQL hash；以实际调用处核对失败分支。

## 关键约束与关联影响

不能放宽 COMPLETED 的 attemptId、精确 SQL hash 与 PROTECTED 合同。修改字段保护时核对投影、过滤、连接、分组排序与历史 SQL/CSV 读取，而不只检查结果表格。
