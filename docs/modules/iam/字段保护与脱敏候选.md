## 功能说明

用于修改 NORMAL/MASKED/HIDDEN 字段保护及采集产生的待确认脱敏候选。正式入口是授权配置中的字段保护面板。

## 实现链路

字段保护面板 → iamS1 API → 字段保护服务；候选面板走 MetadataMaskCandidateServiceImpl。配置写入之后，实际查询仍经过数据授权与 Java 结果保护。

## 关键约束与关联影响

MASKED 必须带安全掩码策略，NORMAL/HIDDEN 不能携带掩码策略。修改配置必须联查[查询授权与结果保护](查询授权与结果保护.md)，不能只靠界面隐藏列；不在字段治理页恢复第二个脱敏入口。

最终脱敏按输出列名的小写规范化结果匹配，Java 使用 `Locale.ROOT`。集合运算按列位置汇入的全部来源，以及仅大小写不同的同名输出，必须统一检查；同一输出键出现不同非空掩码策略时拒绝，不能静默选择其中一种。相同策略重复汇入可接受，空策略不能拿来消解冲突，MASKED 缺少策略仍拒绝。

Python 在 AST 阶段与 Java `deriveOutputMasks` 各自检查该冲突；Java 不信任上游已校验或历史持久化的 `sourceTrace`。完成保护失败不得落为成功，任务与历史读取同样拒绝暴露无法保护的结果。调整集合来源追踪、输出别名或大小写规则时，两侧回归必须一起核对。
