# 字段保护与脱敏候选

> 状态：现行代码导航；核对日期：2026-10-26。源码定位不代表运行验收。
>
> 上一级：[模块说明](../007-iam-s1.md) · [功能导航](../README.md)

## 功能说明

用于修改 NORMAL/MASKED/HIDDEN 字段保护及采集产生的待确认脱敏候选。正式入口是授权配置中的字段保护面板。

## 修改位置速查

| 修改意图 | 文件与定位符号 | 关联影响 |
| --- | --- | --- |
| 保存、撤销字段保护 | [IamS1FieldProtectionServiceImpl.java](../../../backend/DataOcean/src/main/java/com/dataocean/module/permission/s1/service/impl/IamS1FieldProtectionServiceImpl.java)：`saveProtection`、`revokeProtection`、`validateProtection` | 当前字段、保护策略、权限修订与审计。 |
| 候选确认与拒绝 | [MetadataMaskCandidateServiceImpl.java](../../../backend/DataOcean/src/main/java/com/dataocean/module/metadata/service/impl/MetadataMaskCandidateServiceImpl.java)：`confirm`、`reject` | 候选来源、实际写入与事务。 |
| 字段保护界面 | [IamS1FieldProtectionPanel.vue](../../../frontend/src/views/admin/access/iam/IamS1FieldProtectionPanel.vue)：`loadProtections`、`save`、`revoke` | 范围切换、能力控制和服务端错误。 |

## 实现链路

字段保护面板 → iamS1 API → 字段保护服务；候选面板走 MetadataMaskCandidateServiceImpl。配置写入之后，实际查询仍经过数据授权与 Java 结果保护。

## 关键约束与关联影响

MASKED 必须带安全掩码策略，NORMAL/HIDDEN 不能携带掩码策略。修改配置必须联查[查询授权与结果保护](查询授权与结果保护.md)，不能只靠界面隐藏列；不在字段治理页恢复第二个脱敏入口。
