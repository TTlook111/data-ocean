# DataOcean 项目现状

> 整理日期：2026-10-29。本页只维护当前结论；具体行为看模块，运行成绩看验收，剩余动作看后续开发。

## 当前结论

DataOcean 是治理驱动的 NL2SQL 平台。一次问题选择一个 MySQL 数据源，允许同库多表，前端只调用 Java；Java 管身份、IAM、治理、审核发布、持久化和最终保护，Python 管 LangGraph、RAG、AST 与只读执行。

本项目按个人本地开发和演示定位。治理核心、精确知识修订、显式 RAG 构建、受保护问数、反馈再治理及提交后查询追溯已有实现，并在所列合成范围取得真实服务证据。关键页面及七身份操作已完成本轮复验；未提供资料的其他业务口径和场景尚未验证，企业生产交付不作为当前完成标准。

本分支已迁移用户认可的对话主导问数 V2，以及暖白后台共享壳、数据源列表/连接表单/就绪详情、采集任务/全局计划、对象目录/精确快照结构/对象详情，采用仓库既有 Logo；第四阶段已迁移治理任务及字段解释/审核工作面，保留源级反馈与旧来源记录，不扩大最小角色的快照/目录权限。第五阶段已迁移元数据版本/独立详情/差异与审核发布、知识列表/新建/详情及独立RAG构建工作面；第六阶段已迁移关系图谱/实际查询使用与输出来源、查询分析/慢查询及操作审计；第七阶段治理总览/来源质量覆盖、问题中心、质量规则、治理状态及业务知识修订/审核已迁移，依据及原18项测试前提修正见[第七阶段验收](acceptance/2026-10-29-治理工作面补全V2.md)；其他后台业务页面及治理内部工作面尚未全部重设计，详见[剩余页面清单](development/前端第六阶段-血缘审计映射.md)。云端浏览器使用合成 API，没有重跑家庭或办公室真实服务。范围、独立审查与基线测试限制见[问数 V2](acceptance/2026-10-29-对话式问数V2.md)、[后台与数据源 V2](acceptance/2026-10-29-后台与数据源V2.md)、[采集与对象 V2](acceptance/2026-10-29-采集与对象V2.md)、[治理任务与字段审核 V2](acceptance/2026-10-29-治理任务与字段审核V2.md)、[版本与知识 V2](acceptance/2026-10-29-版本与知识V2.md)、[血缘与审计V2](acceptance/2026-10-29-血缘与审计V2.md)。

## 仍有边界

- 真实业务用途、粒度、指标公式/单位/关系基数仍需人工资料和原问题预期；程序化合成审核、参考分或 MODEL_RETURNED 不证明业务真值。
- 未覆盖的角色组合、在途 build 替换、大快照/长内容和网络异常，按实际使用需要补测。长期并发、基础设施灾备及其他部署环境未验证，不属于当前个人本地使用的前置条件。
- 查询影响统计覆盖历史快照，无精确版本/时间筛选；旧记录不补造保护证明。实体图、SQL 使用和结果派生不能混称物理数据流。
- 评分政策2是待校准参考；一键治理有预算，不包含自动业务回放、双人强制审核、任意规模分片、跨 build 向量复用或前置使用分重排。
- 切回旧配置或复用未知数据资产时，再按实际情况核对缓存和集合归属；不把历史环境调查长期挂为开发任务。旧 tokenVersion/黑名单保留到替代机制完成验收。
