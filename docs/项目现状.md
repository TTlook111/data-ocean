## 2026-10-22 发布门禁、导航能力过滤与血缘深链

**发布门禁从“未生效”改为真正生效。** 新增 `SnapshotReleaseGateService` 作为审核、发布和查询的唯一判定：来源（SOURCE）HIGH 未解决阻断审核和发布；可用表为 0 只阻断发布；语义（SEMANTIC）HIGH 只返回 `WARN`，不阻断。新增 `GET /api/admin/snapshots/{snapshotId}/release-gate`（`metadata:release:view`）。`SnapshotPublishServiceImpl` 在状态校验后、过期旧版本前执行门禁，失败时不产生写副作用；审核接口在目标为 `APPROVED` 时执行门禁并统一返回 409；质量检查自动置 `APPROVED` 前也检查门禁。未解决状态统一为 `OPEN/CONFIRMED/REOPENED`，重新检查清理同步包含 REOPENED。

**行为变化：** 已有 `APPROVED` 快照若仍有未解决 SOURCE HIGH 或没有 NORMAL/RECOMMENDED 表，将无法发布并返回 409；`CHECKING → APPROVED` 同受来源高风险约束；REOPENED 计入待处理统计、就绪度、质量分和清理。这些是有意的收紧，不自动修改数据消除阻断。

**前端：** 新增 `ReleaseGatePanel`，在版本详情弹窗、发布确认和快照详情页展示三项门禁；阻断时禁用发布确认，语义 `WARN` 明确标注不阻断。版本列表不为每行请求门禁。左侧菜单按查看能力过滤：`global`、`datasource`、`global-or-datasource` 三种作用域，未声明能力的工作区保持可见，能力读取失败 fail-open；一级域全部二级项不可见时隐藏，入口落到首个可见工作区。治理域按「结果与问题 / 规则与状态 / 字段治理」分组。对象详情血缘 Tab 新增「在血缘工作台中查看」，URL 使用 `datasourceId + entityId`；血缘页以该实体为增强血缘起点，修正原先固定首表的问题，并补加载失败、无实体无关系的说明。
