# DataOcean 项目现状

> 整理日期：2026-11-07。当前行为见模块，实际验证见验收，未完成工作见后续开发。

## 当前结论

DataOcean 是治理驱动的 NL2SQL 平台，当前按个人本地开发和演示定位。一次问题选择一个 MySQL 数据源，可同库多表；前端只调用 Java，服务职责与安全边界见[技术栈与模块职责](技术栈与模块职责.md)。

当前 `codex/product-renewal` 的工作台按操作者负责范围展示问数等候、任务状态与有效赞踩，可进入对应时段或周期的只读明细。治理总览展示所选快照的问题余量与进出变化，质量检查、原操作核对与批次证据在独立的“质量检查”页。公共主题、独立问数入口、知识阅读和显式编辑，以及质量规则的原子写入、未知结果恢复和问题行版本继续使用既有合同。本机状态和证据仅属于当前实施分支与隔离环境。

代码最高迁移为 **V78**，V53 永久不用。V78 已在本机隔离验收库生效，问题流转随原事务写入，原 29 条问题的字段摘要一致。趋势起算日前保留未知。其他数据库迁移状态须独立核对。[双看板验收](acceptance/2026-11-07-问数工作台与治理趋势.md) · [V77 检查与问题行版本](acceptance/2026-11-07-质量检查闭环与视觉对齐.md#迁移回归与保留项) · [V76 规则可靠写入](acceptance/2026-11-07-质量规则可靠写入.md#v76-与兼容边界) · [V75 取消](acceptance/2026-11-06-全站重设计与基础整治.md#v75-与取消交付)

## 已验证范围

登录页按用户偏好恢复了原先的四角色双栏构图，并为手机单独编排。四个角色可以跟随指针、回应点按和表单焦点，输入或显示密码时闭眼回避。六种窗口布局与后续互动复测分别记录在[登录页验收](development/全站重设计执行记录.md#2026-11-07-登录页角色与表单)。

此前 **2026-11-07 全站配色与版本发布** 将工作台和 AI 设置收拢为摘要，并精简问数、治理、知识及运行页面的重复说明。当时海蓝主题的 36 个页面入口在 ego-lite 完成实页检查，前端全量回归和构建通过。[该轮实页对照与验收](acceptance/2026-11-07-全站配色与版本发布.md)

版本发布已修复预读门禁与最终写入之间的反向竞争。真实 HTTP 检查先提交高风险问题后，发布返回 409，原正式指针得到保护。最小角色真实 API 已验。成功替换/撤回和 FULL 范围检查分别在真实 MySQL 回滚事务中验证。完整成功发布后的自动复查仍需独立来源。本轮沿用 V77。[版本模块](modules/005-metadata-versioning.md)

此前 **2026-11-07 质量检查闭环与视觉对齐** 已取得以下结果。详见[闭环验收](acceptance/2026-11-07-质量检查闭环与视觉对齐.md)。

- 真实采集新草稿快照4，限定products及明确维度的实际检查与独立预期一致；覆盖规则优先级、有问题、无问题、不适用、范围失败及停用对照，未执行全量或发布。
- 检查按原UUID持久恢复，真实响应丢失后刷新不重发且进入原批次；两账号问题版本竞争/ABA拒绝、批量部分成功、人工记录经复查保留有真实证据。
- 无辅助目录权限的处理者通过主业务范围接口完成合法问题处理；源外、规则维护及辅助目录拒绝保留。普通检查完成后的导航卡锁已修复。
- 治理总览、规则/执行记录、问题页的操作和视觉对齐；三治理页两种桌面视口及工作台/问数/知识/授权/AI代表页只读抽查，AI旧固定页宽已修。未外推全站所有子页或角色。
- Java、前端定向回归及构建通过。该轮 DashScope 复查为 TLS 失败。检查崩溃 RUNNING 接管和 RAG 中断接管仍待专项验证。

前一轮 **2026-11-07 质量规则可靠写入** 证据见[可靠写入验收](acceptance/2026-11-07-质量规则可靠写入.md)：

## 仍有边界

- DashScope 代理与直连在 TLS 阶段 EOF，尚未取得业务 HTTP 响应，不能判断 Key、额度或供应商业务状态。
- 业务用途、指标公式/单位、关系基数和原题预期需要人工资料；执行成功或参考分不能证明业务正确。
- 最小角色、在途 build 替换、大快照、长会话、网络故障和客户端竞争仍需按影响补验。长期容量、灾备和其他环境未验证。
- 查询影响尚无精确版本/时间过滤；实体图与查询使用不等于物理数据流。政策 2 参考分仍待校准。
- [后端静态问题](acceptance/2026-10-30-前端终验待确认后端问题.md)尚不能由前端锁或合成测试判为解决；远端 CI 没有通过结论。
