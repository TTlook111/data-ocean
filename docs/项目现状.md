# DataOcean 项目现状

> 整理日期：2026-11-06。只维护当前结论；功能合同见模块，实际成绩与失败见验收，未完成动作见后续开发。

## 当前结论

DataOcean 是治理驱动的 NL2SQL 平台。一次问题选择一个 MySQL 数据源，可同库多表；前端只调用 Java。Java 负责身份、IAM、治理、审核发布、持久化与最终保护，Python 负责 LangGraph、RAG、AST 校验与只读执行。按个人本地开发和演示定位，不以企业生产交付作为当前完成标准。

本轮在 `codex/product-renewal` 推进全站重设计与基础整治：白/浅冷灰内容面、深石板导航与青绿动作由唯一令牌源提供；后台独立问数入口、工作台真实指标与来源分布、质量规则单工作面、问数页头范围、知识默认安全阅读与显式编辑已落地。旧铜橙/V3 布局不再限制新设计；业务权限、精确来源、草稿与审核发布、显式 RAG 构建保护保留。

前端全量测试与最终构建通过，36 个实际页面入口已在 ego-lite 打开并逐张查看截图，工作台/规则/问数补了三种桌面尺寸。真实规则完成停用创建、编辑、重读和 UI 软删除；知识保稿与恶意内容预览没有保存文档。入口覆盖不等于所有角色、页签、写分支或异常通过，也不代表用户已批准视觉。结果及原始证据统一见[本轮验收](acceptance/2026-11-06-全站重设计与基础整治.md)。

已提交查询通知拆分 `f9d53484`、审批日期测试修复 `560a6364`、公共主题与三类样板 `0bed40c1`、取消持久交付 `2f7d98b0`、知识阅读与界面收尾 `94f4751f`，以及历史终态表达修复 `1c1d88fa`。这些是本机实现与验证提交，不等于已合并或部署到其他环境；当前工作与待补边界见[执行记录](development/全站重设计执行记录.md)。

本轮新问数没有业务成功结果：一次因模型连接错误 FAILED，一次真实 UI 取消得到 CANCELLED/ACCEPTED。已验证取消消息与轮次释放，以及合成持久意图在正常 Java 重启后补投并被 Python 接收；这不证明供应商调用或 SQL 实际中断。后续刷新曾发现取消历史正文误写“已完成”，已在 `1c1d88fa` 修复；新 Java 重启后实际重读会话415，状态与正文均为已取消，不再误报完成。此结果不外推真实摘要模型，已存长期摘要没有批量改写。

代码最高迁移为 **V75**，V53 永久不用。V75 已在本机隔离验收库实际执行并通过结构、原有记录及活动 build 不变核对，新 Java 启动与正常重启补投通过；其他数据库的 Flyway 状态仍须独立核对。迁移、UI 取消与重启补投的范围分别见[本轮取消证据](acceptance/2026-11-06-全站重设计与基础整治.md#v75-与取消交付)。

候选与人工事实分离、知识版本发布、受保护问数、反馈再治理及查询追溯仍按现行模块维护。2026-10-27～11-05 的家庭、公司、云端和合成环境成绩保留在原报告；旧“未提交”或旧视觉决定只属于当时时点，不作为本轮当前状态。

## 仍有边界

- DashScope 代理/直连路径在 TLS 阶段 EOF，尚无供应商业务 HTTP 响应；只确认连接失败，不推断 Key、额度或供应商业务状态。恢复后再核对新的成功问数链路。
- 原生 125%/150% 页面缩放未实际改变，不能计为通过；36 入口截图不覆盖所有子页签、最小角色写入、长会话/大数据、未知写恢复或新的 RAG 构建接管。

- 未提供的业务用途、指标公式/单位、关系基数和原题预期仍需人工资料；执行成功、参考分、程序化合成审核或MODEL_RETURNED不证明业务真值。
- 未覆盖角色组合、在途build替换、大快照、真实网络故障及并发需按影响补验。长期容量、基础设施灾备和其他部署环境未验证，不是当前个人使用的前置条件。
- 实体图、SQL使用和结果派生不等于物理数据流；查询影响没有精确版本/时间过滤，旧记录不补造保护证明。
- 管理账号目标隔离、最小角色辅助目录、null持久化、客户端并发与模型配置等[9项后端静态问题](acceptance/2026-10-30-前端终验待确认后端问题.md)尚不能由前端锁或合成测试判为解决。
