DataOcean是治理驱动的NL2SQL平台。一次问题选择一个MySQL数据源，可同库多表；前端只调用Java。Java负责身份、IAM、治理、审核发布、持久化与最终保护，Python负责LangGraph、RAG、AST校验与只读执行。按个人本地开发和演示定位，不以企业生产交付作为当前完成标准。

已实现候选与人工事实分离、精确修订和来源、文档审核发布、显式RAG构建、受保护问数、反馈再治理及提交后查询追溯。问数保留获认可的单列连续对话；后台使用暖白、墨色、铜橙及仓内Logo。正式组件页与内部工作面已纳入V2迁移，范围见[路由覆盖](acceptance/2026-10-29-全站路由覆盖与终验计划.md)及[合成验收](acceptance/2026-10-29-统一跨页终验V2.md)，页面迁移不等于所有分支真实通过。
