## 当前结论

DataOcean 已实现元数据治理驱动的单数据源 NL2SQL 主链。每次问题选择一个 MySQL 数据源，支持同库多表；前端只调用 Java。Java 管理权限、治理、发布、任务、会话和最终保护，Python 负责 S1 LangGraph、RAG、SQL 安全执行与制图。

**业务术语与语义知识改造：修改完成，核心流程验收通过。** 已验证术语定义与字段映射、修订审核、AI 候选生成与人工采纳、知识审核发布、单独确认 RAG 构建，以及使用新知识的受保护问数和历史重读。结论适用于本轮隔离单数据源测试环境，详见[验收结论](acceptance/业务术语与语义知识验收记录.md#验收结论)。

跨源、双用户、大快照和有在途引用的索引替换仍列为[后续专项验证](development/后续开发.md#6-扩展术语与知识边界验证)；当前不标记“全场景验收通过”。
