# 模型管理与安全调用页面

业务含义见[模块解说](../../product/modules/09-models.md)及方案第 9 章。下表只负责前端页面、动作和状态表达；当前进度见[原型状态](../原型状态.md)，共用控件与布局见[设计约定](../设计约定.md)。

| 页面或区域 | 使用者职责 | 必要动作与流转 | 权限与状态边界 |
| --- | --- | --- | --- |
| 模型列表与配置详情 | 具备服务配置、测试或启停权限者 | 新增或编辑 → 保存草稿、替换凭据、测试 → 提交生效；停用前核对用途影响 | 分离草稿与有效修订，旧凭据不回显 |
| 治理与问数用途设置 | 具备用途绑定权限者 | 分别选择已有可用配置 → 核对影响 → 确认切换对应用途 → 显示实际有效修订 | 切换不改权限或业务口径，失败不出现半生效 |
| 知识检索配置 | 具备检索配置与相关发布权限者 | 配置向量或重排用途 → 完成对应检索验证；需要重建索引时进入候选构建与发布流程 | 查询向量匹配索引配置，生成模型切换不自动重建索引 |
| 记录与诊断 | 具备对应诊断或故障处理权限者 | 查看变更与失败摘要 → 查看获准原因 → 重新测试或选择恢复方案 | 模型管理不自动开放业务原文与数据库权限 |
