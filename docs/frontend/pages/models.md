# 模型配置与调用记录

业务含义以[产品方案](../../product/产品方案.docx)第9章及[模块解说](../../product/modules/09-models.md)为准。实际覆盖见[原型状态](../原型状态.md)。

Embedding 已选择与当前生效配置、索引更新及回退兼容性的跨端约束见[知识版本与索引一致性](../../architecture/知识版本与索引一致性.md#embedding-模型变更)，不将原型索引状态视为真实构建验收。

模型秘密引用、调用外发、轮换及诊断记录的保护边界见[安全执行与审计](../../architecture/安全执行与审计.md)，配置或诊断查看能力不自动授予业务原文读取权。

系统配置保留模型配置、调用记录与故障两个页面。模型配置分模型列表、节点列表两个页签，不单设用途设置或知识检索配置页面。

## 模型列表

新增模型位于模型列表页签栏右侧。新增、编辑和详情使用居中弹窗。表单分开选择模型类型与接口格式：类型为生成、Embedding或Rerank；生成对应OpenAI Chat Completions、Anthropic Messages，向量对应OpenAI Embeddings，重排对应Cohere Rerank。类型变化后只提供匹配的接口格式，再填写配置名称、服务URL、模型名称、凭据及必要连接参数。这里表达原型选项，实际部署只承诺已实现并验证的适配器，不将不同格式视为只换URL即可兼容。

保存完整接入信息后，模型即可在相应节点中选择。启停状态只表达已启用或已停用，最近连接测试另列未测试、通过或失败；测试失败不自动停用，也不将已启用称为服务可用。连接测试用于排查接入，不增加人工登记用途验收、业务验收、审批或另行发布模型的步骤。列表按配置名称、类型、接口格式、模型名称、启停状态的表头顺序查询，支持分页和详情回看；新增后显示新增记录，返回保留原查询。编辑时旧凭据不回显，留空保留，明确填写才替换。配置修改保留历史修订，实际调用记录保存当时所用修订。

详情的编辑、测试连接、停用和恢复集中在底栏。停用列出所选配置及当前生效路径引用的受影响节点，并确认功能不可用的后果；已停用模型仍保留原分配关系，节点可改选其他模型。停用、恢复记录状态变化，不递增配置内容修订。配置权限和节点分配权限分别控制，未保存的实际修改离开时保护输入。

## 节点列表

每行依次显示节点及所属模块、这个节点做什么、分配模型。选择模型即保存本节点分配，不再弹出验收或审批流程。各节点独立分配，同一个模型可用于多个节点；选择范围限于能力匹配的已启用模型，已有停用模型保留回看并明确不可用。清空必需节点前确认影响，取消不改变分配，确认后明确显示当前不可用；可选Rerank可直接设为不使用。支持按节点名称或说明、所属模块筛选，保留桌面表格及分页。

节点清单共18项，按当前方案的实际AI调用职责组织：

| 模块 | 节点 | 能力 |
| --- | --- | --- |
| 数据治理 | 表说明生成、字段解释生成、关联候选发现、指标候选发现 | 4个生成节点 |
| 知识库与发布 | 知识文档规划、知识正文生成与更新、标准题建议 | 3个生成节点 |
| 智能问数 | 问题理解、追问生成、历史对话摘要、SQL生成、SQL意图语义核对、输出含义识别、SQL修正、结果解释 | 8个生成节点 |
| RAG | 知识与问题向量化、候选知识重排 | 1个Embedding节点、1个可选Rerank节点 |
| 反馈处理 | 反馈问题向量化 | 1个Embedding节点 |

SQL意图语义核对和输出含义识别对应产品方案第6章已有的意图核对及输出语义职责；模型只辅助识别和提供依据，系统保留最终检查与授权决定。反馈问题向量化用于召回相似候选，不自动归组、合并或判定根因。人工审核、权限、只读执行、预算与发布确认不另设AI节点。

单项、批量与重新生成复用对应治理节点，包含依据缺口判断及必要渐进读取后的解释；知识更新差异建议归入正文生成与更新，图表展示建议归入结果解释。标准题运行复用问数节点，人工审核与结果裁定不另设模型节点。

RAG根据本次问题自动取得知识，管理员不逐题挑选文档。其向量和可选重排模型在相应节点中选择，索引兼容性及知识发布沿用知识模块规则；节点分配不另建一套检索业务配置。

Embedding节点区分已选择配置与当前生效配置。更换模型或向量身份后显示待索引更新，新索引就绪前继续使用仍可用的原匹配路径；没有可用路径时明确不可用。更新失败保留旧路径并显示失败，匹配校验通过后才切换，过期目标不得覆盖新选择。清空分配立即停止使用该节点，原索引仍保留；重新选择时仅恢复已知匹配且可用的路径。知识和问题向量化使用配套配置，不能一端先行切换。

索引状态抽屉直接展示本次更新任务、范围、目标及生效配置，提供更新和失败重试，不跳转到无法处理索引的反馈业务队列。知识索引和反馈问题库索引分别更新，只切换匹配路径，不修改知识正文或代替发布。离线原型使用明确标注的固定更新结果；`?review=models`补充失败状态演示，均不执行真实构建。窄PC窗口保持三列，节点说明换行并分配实际可读宽度，选择框不覆盖说明。关闭弹窗或办理后，焦点返回原节点或原记录入口。

## 调用记录与故障

调用记录、连接测试和配置变更分别回看。按模型、节点、状态和发生日期查询；详情显示当次配置名称、实际模型标识、配置修订、状态、原因、耗时及已知用量，未知用量或费用显示未知。记录绑定不可随当前配置变化的快照，模型改名、编辑、停用和恢复后仍可追溯当次配置；缺失历史不能以最新配置冒充。具备模型查看权限时可展开当次配置及变更前后快照，不展示原始凭据。不默认展示完整提示词或业务结果。

有来源查看权限时，调用详情展示任务编号、数据源和当次业务对象，并回看来源任务摘要；能够定位的对象提供进入和返回调用记录的入口，往返保留原查询及页码。历史任务不能定位时保留当次摘要，不编造跳转。来源任务与业务对象沿用所属模块权限，诊断查看权不新增业务访问权。

可以测试当前模型连接或进入模型维护，不能在这里直接重放结果未知的业务任务。结果已交付而解释失败时保留交付事实，不为重新解释而重发SQL。连接测试不改变节点分配，查看诊断不新增业务数据访问权。

原型仅使用页面内存和固定样例，不保存输入凭据，不连接真实模型或执行真实RAG。浏览器及测试边界见[原型状态](../原型状态.md)。

## 布局尺度

模型列表新增按钮放在页签栏右侧，查询区独占可用宽度。正式后台的节点表为模型列预留 228px，选择框不超过 204px，剩余宽度优先留给用途说明。调用详情使用居中弹窗，两列信息使用一致的标签和值对齐，服务 URL 和长说明占整行。索引状态在分配控件下紧凑展示，详细快照按需展开，办理后焦点返回同一节点或记录入口。
