# 治理与问数运营看板页面

业务含义见[模块解说](../../product/modules/08-dashboard.md)及方案第 8 章。下表只负责前端页面、动作和状态表达；当前进度见[原型状态](../原型状态.md)，共用控件与布局见[设计约定](../设计约定.md)。

视图按职责和统计范围组织，不预设所有账号都可看运营总览。当前超级管理员原型的默认 Dashboard 不代表其他角色获得看板权限。

## 总览原型

总览顶部选择数据源及时间范围，默认近30天，可切换近7天或自定义起止日期。首张问数使用趋势通栏，下方采集运行、治理确认、可用知识和反馈处理四图在较宽 PC 窗口两列排列；保留侧栏，窄 PC 窗口将图表顺序下移。图表以折线及浅色面积填充为主，不铺独立数字卡片。

| 图表 | 展示口径 |
| --- | --- |
| 问数使用趋势 | 请求数与其中已交付结果数；交付不代表业务正确性 |
| 采集运行 | 成功与失败任务次数 |
| 治理确认 | 已确认的表说明与字段分别计数，AI 草稿不计入 |
| 可用知识 | 日末可用正式文档存量；标题取所选期间期末值，周/月不累加每日存量 |
| 反馈处理 | 新增与实际验收解决的问题数量；其他结案与合并不计入已解决 |

五图共用时间和数据源。60天以内按天，较长时段按周或月汇总，缺少统计保留空缺。图表支持悬停、左右方向键与 Home／End 读数、Esc 关闭提示，以及按需展开数据表；离开并返回保留本次筛选，刷新恢复初始示例。

统计使用独立、固定的评审样例，并显示“示例数据”，不读取其他模块的当前记录或真实服务，不承诺统计与业务原型的记录数量一致。代码覆盖与验证状态只维护在[原型状态](../原型状态.md)。

## 模块 Dashboard 原型

四页分别位于所属模块菜单首项，按各自页面访问功能核验；总览查看权不自动赋予模块看板权限。每页独立保留本次已应用的时间与数据源，刷新恢复近30天与全部数据源；统计条件不改写业务页面正在处理的对象或数据源。

| 菜单 | 配色与布局 | 图表内容 |
| --- | --- | --- |
| 数据源接入 → 接入概览 | 蓝青色，左宽右窄，上方趋势加环形，下方两张趋势 | 成功／失败采集趋势；期间已结束任务的成功、失败、取消占比；成功采集平均耗时；期末待事实核实变化 |
| 数据治理 → 治理概览 | 绿色高主图，右侧进度与待核对，下方通栏趋势 | 表说明与字段确认；期末待治理、治理中、已治理对象占比；变更后待核对条目；关联与指标确认 |
| 知识库与发布 → 知识概览 | 靛蓝通栏阶梯图，下方三列 | 正式可用文档存量；成功生效批次；验证未通过与执行错误题次；期末待更新、暂停、禁止使用文档分类点图 |
| 反馈处理 → 反馈概览 | 暖橙与青绿主图，左侧两张趋势，右侧浅暖底环形 | 新增与已解决；期末未结与等待验证；期间已解决、其他结案、已合并分布；平均解决耗时 |

均值按完成数量加权；存量取期末快照。待核对可与治理进度重叠，等待验证是未结问题的子集，知识维护状态可重叠。环形和点图同样支持键盘读数及分类数据表。模块原型使用固定评审样例。

| 页面或区域 | 使用者职责 | 必要动作与流转 | 权限与状态边界 |
| --- | --- | --- | --- |
| 治理、问数、反馈及运行视图 | 具有对应看板及统计范围权限者 | 选择期间与业务范围 → 查看同口径趋势、状态和提醒；刷新或局部重试 → 更新对应面板 | 零样本、未接入、延迟、读取失败和无权限分别展示 |
| 业务明细下钻与处理入口 | 具有相应明细或办理权限者 | 从汇总下钻 → 保留期间、范围和当前权限 → 查看证据；有办理权再进入对应模块 | 统计可见不等于明细可见或可修改，任务分派不自动授予资源权 |

## 正式反馈概览

反馈处理菜单中的「反馈概览」读取真实统计。工作区使用白底，顶部左侧放数据源和时效，右侧放期间和日期范围。主趋势通栏，积压和耗时在左，浅暖底结案环图在右。双列时结案区与左侧耗时图共用底边，展开任一列的数据表时仍保持对齐。主趋势读数是 28px，辅助趋势读数是 24px，结案图例逐行对齐数量与占比。窄桌面工作区按原型顺序堆叠，趋势图恢复阅读高度，侧栏继续常驻。

少量发生日期使用圆点定位，连续趋势保留折线。方向键、Home／End 读取图表数值，Esc 关闭提示。展开长期间数据时，在图表下方局部滚动并固定列名。具备队列查看权限时，可从期间总数或分组读数打开对账抽屉，再从事项编号进入原详情。返回概览保留来源、日期、指标和分页；浏览器刷新恢复默认期间。历史待验证缺失以空缺显示，说明可从积压图标题及数据表查看。解决耗时无样本时保留对应空态。[接口及口径](../../backend/feedback/运营统计.md)

界面局部参考 Awwwards 收录的 Mixpanel 分析图，把主读数和相关入口放在同一分区；颜色、间距和页面层级沿用后台规范及反馈原型。[Awwwards 设计参考](https://assets.awwwards.com/assets/books/Brain-Food-AI-Driven-Design-vol4.pdf)

桌面浏览器按 1440px 同屏核对原型与正式页面，另查 1024px、原生 125% 和 150% 缩放。操作覆盖期间切换、键盘读数、固定表头、手动刷新及统计下钻。双列底边已在默认、分别展开数据表及无解决样本时测量。[界面与操作证据](../../../output/playwright/2026-11-23-feedback-overview-polish/report.md) · [底边截图](../../../output/playwright/2026-11-23-feedback-overview-alignment/aligned.png) · [布局测量](../../../output/playwright/2026-11-23-feedback-overview-alignment/layout.json)

## 正式接入概览

工作区沿用接入原型的白底、蓝青色谱与两排布局。上排左侧展示采集运行趋势，右侧展示已结束任务的数量和占比；下排展示成功采集的平均执行秒数以及阶梯形式的待核实存量。窄桌面按运行趋势、结果分布、耗时、待核实变化的顺序堆叠。

来源、近 7 天／近 30 天和自定义日期复用看板工具栏。图表每个区间及全期读数均可展开，获得采集记录查看权限后可在同一来源、期间和截止时刻查看贡献记录，再打开原采集任务或结构变化。原页面返回保留统计条件。读取或权限失败使用共用反馈。 [统计与授权](../../backend/datasource/运营统计.md)

双列按 1440px 视口对照原型，实测默认和逐排展开数据表时各排上下边界对齐。另查 1024px 和原生 125%／150% 缩放、原记录下钻及返回、空样本与反馈概览回归。[浏览器验收](../../../output/playwright/2026-11-23-source-overview/report.md)

## 正式治理概览

治理概览沿用原型的白底和绿青色谱。左侧高主图展示表说明与字段确认，右侧分别展示期末治理进度和变更后待核对，下方通栏展示关联与指标确认。宽桌面时左侧跨行区与右列顶边和底边对齐。窄桌面按主图、进度、待核对、关联与指标的顺序换行。

筛选、图表键盘读数和局部数据表复用现有看板组件。具备治理工作台查看权限后，可以按原来源、期间和截止时刻核对记录，从表、字段及候选入口打开对应治理页签。面包屑和详情返回保留原统计条件和下钻位置。[接口与统计](../../backend/governance/运营统计.md)

1440px 同屏对照时，默认与分别展开三个上方图表的数据表均实测跨行区上下对齐。1024px、原生 125%／150% 缩放、关联和表说明下钻返回以及历史范围选择已通过浏览器回看。[浏览器验收](../../../output/playwright/2026-11-23-governance-overview/report.md)

## 正式知识概览

上方通栏阶梯趋势展示期末可用正式文档，下方并排展示发布动态、验证异常和维护关注。维护关注的点图按同一数量轴分别展示待更新、暂停和禁止。窄桌面按原型顺序堆叠，侧栏保持常驻。

历史可用性证据不足的区间留空。数据表沿用各期末和期间定义。下钻可回看原文档修订、发布批次对应任务及实际验证轮次，返回保留来源、期间、指标和截止时刻。各类详情分别核对原业务权限。[统计及历史覆盖](../../backend/knowledge/运营统计.md)

验证异常的主读数可直接展开贡献明细，再进入原验证轮次。入口层级参考 Awwwards 收录的 Mixpanel 异常分析案例。[Awwwards 设计参考](https://assets.awwwards.com/assets/books/Brain-Food-AI-Driven-Design-vol4.pdf)

1440px 同屏对照原型，另查 1280px、1101px 附近、1024px 和原生 125%／150% 缩放。三列并排时绘图区和面板底边对齐，分别展开下方三个数据表时两个业务入口也贴齐底边。已核对点图键盘读数、历史缺口和原记录往返。[浏览器验收](../../../output/playwright/2026-11-23-knowledge-overview/report.md)

## 正式总览

总览沿用原型的一张通栏主图和下方四张趋势图，共用来源、期间、粒度和截止时刻。拥有总览权限的账号可从侧栏进入。统计默认近 30 天，可切换近 7 天与自定义，离开后返回保留统计条件，浏览器刷新恢复默认。图表复用模块概览的数据表和键盘读数。

问数主图按首次提交统计同批请求及截至统计时刻的已交付结果，排除反馈专用复验请求。同一请求的澄清、内部重试和后续解释只保留一次请求。采集运行、治理确认、可用知识和反馈处理沿用所属模块口径。知识每组取期末可用存量，缺少历史证据的区间留空。

总览接口核验 `dashboard.view`，各模块统计继续检查各自的概览权限。问数与反馈统计使用当前账号有效的源访问范围，其余三图使用原模块后台范围。在全部数据源下，问数和反馈的范围较窄时提示实际覆盖。具有归属模块明细权限时，可用辅助图表的读数打开原对账抽屉，保留所选来源、区间和截止点。图表缺少统计权限或可用范围时给出对应反馈。

四张辅助图底部的快捷入口分别进入采集记录、治理工作台、知识文档和问题队列。选择单一来源时，入口预选同一来源，期间则用于图表读数下钻。

独立 MySQL 8.4 验收库完成 V48 至 V53 迁移。真实接口逐组比较总览和四个模块的日、周、月读数及指定指标明细，问数以原始请求和交付时间独立对账。只授予统计权限时，明细请求返回 403。撤销总览权限后，同一会话重新读取总览返回 403。[接口验收](../../../output/acceptance/2026-11-24-dashboard-overview/api.json)

桌面浏览器实测默认期间、来源及近 7 天切换、键盘读数和数据表。由采集统计进入原任务再返回，来源与期间条件仍有效。1440px 视口下辅助图双列对齐，1024px 下按原型顺序叠放，均保留 216px 侧栏。原生浏览器缩放待复验。[宽桌面](../../../output/playwright/2026-11-24-dashboard-overview/formal-desktop.png) · [1024px 截图](../../../output/playwright/2026-11-24-dashboard-overview/formal-1024.png) · [采集下钻](../../../output/playwright/2026-11-24-dashboard-overview/collection-drill.png) · [布局测量](../../../output/playwright/2026-11-24-dashboard-overview/layout.json)
