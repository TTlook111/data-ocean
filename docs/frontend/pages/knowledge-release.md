# 知识库与发布管理页面

业务含义见[模块解说](../../product/modules/05-knowledge-release.md)及方案第 5 章。下表只负责前端页面、动作和状态表达；当前进度见[原型状态](../原型状态.md)，共用控件与布局见[设计约定](../设计约定.md)。

| 页面或区域 | 使用者职责 | 必要动作与流转 | 权限与状态边界 |
| --- | --- | --- | --- |
| 知识文档草稿与详情 | 具备对应知识整理、审核权限者 | 从已确认标签生成草稿 → 修改与核对 → 确认；生成或收口有问题时返回原生成环节，资料仍缺时请求补充 | 只用获准来源，不把未确认建议或反馈猜测写成正式事实 |
| 候选构建、测试与发布 | 具备测试或发布权限者 | 确认发布范围 → 构建候选 → 查看相关测试与门槛 → 确认发布 → 成功后整批切换；失败查看原因并修订重测 | 无题先补题，门槛未通过不切换，其他范围保持独立 |
| 版本、暂停与回退 | 具备对应状态管理权限者 | 查看当前及上一版、差异与依赖；暂停 → 说明原因；回退 → 对上一版整批预检 → 全部通过后切换；解除禁止需明确确认 | 仅允许上一版；回退不绕过当前权限、禁止和资源状态 |

结构或资料变化沿用数据源侧核实结论，在表治理的受影响条目直接维护业务内容；条目审核后，知识文档承接已确认内容及实际来源修订，不另确认治理结果。需要更新知识时保留知识处理中，必要更新、验证与发布完成后自动回写来源进度。未受影响内容沿用原确认和知识，不另填无需修改结案。

## 变更知识更新

治理详情和变化详情的“处理知识更新”打开对应事项；知识文档与发布管理按当前数据源提供更新列表，支持对象或影响内容搜索、更新状态筛选、分页和结果回看。列表只承接知识处理中及已有更新记录，展示更新状态与候选，完成结果仅在详情回看，不重复建立业务治理待办。详情保留真实来源返回、前后差异、已知来源说明、具体治理修订、知识范围、候选及处理记录，不重复业务核对任务。

从已审核治理内容生成知识草稿 → 核对或修改文档表达 → 确认草稿 → 构建固定候选 → 自动运行相关已审核题 → 查看结果与阻断项 → 确认发布 → 必要时显式解除禁止。草稿直接带入已审核内容，不增加必填更新处理说明；验证题来自已审核标准题单，不在更新流程手填题目或勾选通过。需要改变业务含义时返回治理修订。编辑、确认、构建、验证、发布、解除禁止分别沿用现有操作权限，同一有权限者可以兼任。

草稿有实际修改后回到草稿状态并重新确认，不另分待整理与待确认两个阶段；未确认不能构建。无相关已审核题、待裁定、未验证或最新验证未通过均不能发布；缺题在标准题单中补充并审核后重新构建。验证未通过可重测或返回修订。修订草稿使原确认及当前候选失效，历史候选保留原快照；治理修订、来源状态或候选变化时，提交重新校验，旧验证结果不能套到新候选。已发布但尚未解除禁止时，若治理依据再次变化，保留以往发布记录并重新生成当前修订的草稿、候选与验证。发布确认明确数据源、范围、固定候选和验证结论，不提前解除禁止。

未禁止的新内容完成发布后直接回写“知识已更新、验证并发布”；仍有禁止的内容保持知识处理中，具体状态为“已发布待解除禁止”。有解除权限者再核对来源可用性、当前治理修订和同条目的其他未完成变化后显式解除，自动回写完成结果。删除字段的处理为停用对应依赖知识并验证发布，字段本身保持禁止；无需再提供解除入口。目录可见性变化无业务影响时只结束业务影响判断，访问异常另行处理。

当前仅实现页面内的上述变更更新交互，关联题单及运行结果为固定示例，自动逐题比对并绑定候选；页面不提供手填通过结果的入口。不执行真实模型、SQL、索引构建或正式测试、发布服务，标准题单维护页仍待制作。通用知识编辑、完整发布任务、版本回退和持久化仍按原型状态单独表达。
