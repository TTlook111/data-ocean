# 知识库与发布管理页面

业务边界见[模块解说](../../product/modules/05-knowledge-release.md)，实际覆盖和未接服务见[原型状态](../原型状态.md)。三个菜单共用当前数据源：知识文档、标准题单、发布与版本；后者包含发布任务和当前生效两个页签。

原型在现有“商品中心库”直接提供两份有效业务说明，以及商品、销售明细的已审核表字段、关联和指标；治理、来源引用及知识生成读取同一组页面内存记录，不另建演示页。文档、题单、候选及发布结果通过实际页面操作产生，候选题初始为草稿，预期和判定依据须人工审核。固定销量数据为10盒与2盒，实际汇总12盒独立于预期答案；净销量提示缺退货口径，说明题进入人工裁定。题目及验证页展示相同固定数据和修订，超出样例范围时明确未接执行服务。

没有已审核定义时在页面内展示空状态和治理入口。数据源详情可进入业务说明、已审核标签及知识文档；治理可继续到知识文档，文档可定位当前治理条目及相关题单，任务保留本批相关题单和版本入口，切页沿用当前数据源。

## 页面职责

| 页面 | 展示内容 | 主要操作 |
| --- | --- | --- |
| 知识文档列表 | 名称、来源对象、正式修订、整理修订、确认状态和更新提醒 | 按名称、对象及状态查询分页；生成或定位已有文档 |
| 文档详情与编辑 | 正文、治理依据、来源修订及资料引用、历史修订、关联发布 | 独立页编辑长正文；保存、确认、比较并合并更新、发起发布、回看正式版本 |
| 标准题单 | 问题、关联文档、修订、审核状态及复核提醒 | 生成候选题、补题、修订、审核、停用和运行记录回看 |
| 题目详情与编辑 | 问题条件、预期、数据依据、判定方式、误差、执行身份、审核及历史 | 保存草稿或审核确切修订；未补齐的预期不能进入审核题单 |
| 发布任务列表与详情 | 本批完整范围、基础版本、固定候选、构建、逐题证据、切换结果及历史 | 调整范围、构建重试、自动验证、重测、待裁定办理、确认发布、取消未生效任务、核实不明确结果 |
| 当前生效与版本详情 | 实际修订、来源发布、当前可用性、暂停原因、直接上一版及恢复记录 | 查看修订、暂停、核对完整依赖后撤下、隔离恢复验证、显式恢复、整批回退 |

文档页负责内容整理与确认，发布确认只在发布任务详情办理。题目维护与运行记录分开，候选与恢复验证使用同一套任务、题目快照和裁定记录；恢复验证通过不切换版本，也不自动解除生产限制。旧版本入口定位到当前生效页签，不另维护重复菜单。动作分别核验页面与操作权限，同一有权限者可以兼任。

跨页入口保留逐层返回来源、查询页码、表内滚动和焦点，浏览器返回沿用对应页面的上下文。发布任务的补题入口只展示本批相关题，并保留返回原任务操作；新增候选题默认带入本批文档。当前生效切换数据源时保留页签；发布后单文档直达版本，多文档限定本批生效范围，避免重新查找。

## 文档生成与修订

知识文档绑定一个数据源，按实际对象定位，不建立业务主题或场景分类。默认每张表形成一份基础说明，关联或指标按已审核条目及完整依赖形成联合说明。系统提出生成清单，用户选择本次文档及表说明条目范围，必要依赖由系统补齐。多个表默认分别生成，不能从原始外键或相似名称直接推定联合业务口径。

生成前核对纳入、排除及已有文档；相同稳定范围已有文档时定位原记录，避免重复建稿。只有实际生成的文档进入列表；来源事项的待生成范围通过交接详情承接。正文保留准确表字段名称、语义标签和治理修订，资料引用按原有权限回看。

草稿与正式修订隔离，确认绑定确切内容。保存已确认文档的改动形成下一草稿修订，原正文、候选及发布记录不覆盖。来源审核内容变化后提示待更新，进入差异核对页；人工整理过的正文保留供合并，保存后重新确认。业务含义或口径变化返回治理审核；未审核资料不能作为正式断言。

正文编辑使用完整任务页，支持长文本，实际未保存修改统一保护侧栏、面包屑和浏览器返回；继续编辑为默认选择。列表返回保留源、查询、有效页码与入口焦点。确认状态与更新提醒分别记录，原正式版本仍有效时继续使用。

## 标准题与候选验证

每源维护可复用题目，每次候选固定本批相关已审核修订。候选题可以辅助起草，预期及判定依据由有审核权限的治理人员确认；可先保存不完整草稿，不能以保存代替审核。说明、数值和规则类题分别处理；数值误差需预先明确，标准和实际结果分别保存。题目修订、停用或依赖变化使相关候选重新核对，不能删题绕过必要覆盖。

构建后自动运行相关题，缺少必要已审核题时提供补题入口并阻断。明确结果自动比较，说明类结果进入待裁定；只有当前候选待裁定结果可按证据裁定，明确失败和执行异常不能人工改成通过。历史题目、候选、运行和裁定记录保留原快照。固定样例外未接执行服务时显示执行异常，不提供手填实际结果或通过入口。

## 发布与版本

一次发布选择当前源的一份或多份完整确认修订，系统补齐明确的必要协同内容；仍有效且未变的依赖复用，无关文档不改版。范围调整保留原候选历史，重新构建验证。固定清单保存实际正文、治理依赖、题单和基础入口，临切换前重新检查。相关来源、内容、权限或验证依据变化时阻断，不沿用旧成绩；普通采集编号变化不构成内容变化。

本批全部必要内容通过后一次切换，失败不部分写入入口。切换结果不明确时先读取实际入口，再允许继续；不直接重复发布。正式修订按文档及其来源发布批次展示，不用全数据源统一修订号掩盖局部更新。

任务列表、详情和固定底栏共用当前门槛反馈。缺题或依据变化显示被阻断，并直接提供补题、文档处理、范围调整或重新构建入口。步骤条使用阶段名称，不将等待或阻断误写为正在执行。已取消任务停止给出继续发布建议；历史发布保留本次修订，后续回退或替代后的当前版本单独展示。

未生效的构建和验证保留取消入口；阶段后台完成时不关闭正在填写的确认表单，也不刷新其他页面抢走输入焦点。页面内存记录因刷新不存在时提供返回当前源列表的入口。

当前可用性与版本分开。暂停保留版本；可靠删除或不兼容按实际依赖拦截，业务存疑先待复核。恢复验证限定当前正式修订，在同一任务工作区运行和裁定，生产继续保持限制；有权人员核对证据后显式恢复。内容改变须先更新治理、文档并验证发布；删除对象不能恢复。撤下核对必要依赖范围并保留历史，恢复仍需验证和确认。

未运行恢复验证时显示未验证，原通过依据变化后显示已失效。题单变化可从原任务重新发起恢复验证，保留历史运行；治理定义变化先定位文档更新，不能指向不允许构建的恢复任务。正常版本不常驻展示低频回退的禁用警告，原因保留在对应操作旁。无实际修改的保存或重复审核不新建题目修订。

回退固定为当前发布完整范围的直接上一版组合，预检结构、依赖、当前权限、禁止与相关题目。缺失或不兼容、部分已被后续发布替换时整批阻断；切换不清除当前限制。回退结果同时写入发布和版本记录。

## 状态表达

| 对象 | 主流转 | 异常或并存状态 |
| --- | --- | --- |
| 文档修订 | 草稿 → 已确认；修改进入下一草稿 | 待更新提醒独立，正式旧修订仍可生效 |
| 标准题 | 草稿 → 已审核；修改形成新修订 | 待复核或已停用，历史记录保留 |
| 发布任务 | 准备中 → 构建中 → 验证中 → 待发布 → 切换中 → 已发布 | 构建失败、验证未通过、待裁定、执行异常、被阻断、结果待核实、已取消 |
| 恢复验证任务 | 待验证 → 验证中 → 验证已完成 | 相同逐题异常及裁定分支，不自动恢复生产 |
| 正式内容 | 当前修订、直接上一版及历史发布 | 正常、待复核、暂停、来源不可用或已撤下 |
| 来源事项 | 知识处理中 → 已完成 | 发布后仍受限时等待恢复；停用删除依赖后完成，删除对象仍禁止 |

原型内存状态不表示真实模型、SQL、索引、权限、发布或恢复服务已实现，边界统一维护在原型状态。
