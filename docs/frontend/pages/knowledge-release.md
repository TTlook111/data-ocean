# 知识库与发布管理页面

业务边界见[模块解说](../../product/modules/05-knowledge-release.md)，实际覆盖和未接服务见[原型状态](../原型状态.md)。模块首项为独立的知识概览 Dashboard，见[看板页面](dashboard.md#模块-dashboard)。知识文档、标准题单、发布与版本三个业务菜单继续共用当前数据源；后者包含发布任务和当前生效两个页签。

原型在现有“商品中心库”直接提供两份有效业务说明，以及商品、销售明细的已审核表字段、关联和指标；治理、来源引用及知识生成读取同一组页面内存记录，不另建演示页。文档、题单、候选及发布结果通过实际页面操作产生，候选题初始为草稿，预期和判定依据须人工审核。固定销量数据为10盒与2盒，实际汇总12盒独立于预期答案；净销量提示缺退货口径，说明题进入人工裁定。题目及验证页展示相同固定数据和修订，超出样例范围时明确未接执行服务。

没有已审核定义时在页面内展示空状态和治理入口。数据源详情可进入业务说明、已审核标签及知识文档；治理可继续到知识文档，文档可定位当前治理条目及相关题单，任务保留本批相关题单和版本入口，切页沿用当前数据源。

## 页面职责

| 页面 | 展示内容 | 主要操作 |
| --- | --- | --- |
| 知识文档列表 | 名称和用途、来源对象、正式修订、整理修订、确认状态和更新提醒 | 按名称或用途、对象及状态查询分页；直接审核草稿、核对更新、准备发布或阅读正式版 |
| 生成前确认 | 可回答的问题、适用条件、不支持内容、已有文档匹配、缺项及核对结果 | 开关选择本次生成项；同页调整职责与依据，补充用途，合并拆分建议，核对后逐项生成或定位 |
| 文档详情与编辑 | 业务章节、逐节治理依据、主动范围及必要依赖、资料引用、历史修订和关联发布 | 独立页修改职责、章节及依据；保存、确认、差异合并、合并拆分、发布及正式版本回看 |
| 来源更新与合并拆分 | 全部实际影响文档及版本类型，来源、目标、显式引用去向和退出动作 | 逐篇处理影响；目标草稿与原稿并存，取消恢复原选择，目标生效与旧文档退出同批发布 |
| 标准题单 | 问题、关联文档、修订、审核状态及复核提醒 | 生成候选题、补题、修订、审核、停用和运行记录回看 |
| 题目详情与编辑 | 问题条件、预期、数据依据、判定方式、误差、执行身份、审核及历史 | 保存草稿或审核确切修订；未补齐的预期不能进入审核题单 |
| 发布任务列表与详情 | 本批完整范围、基础版本、固定候选、构建、逐题证据、切换结果及历史 | 调整范围、构建重试、自动验证、重测、待裁定办理、确认发布、取消未生效任务、核实不明确结果 |
| 当前生效与版本详情 | 实际修订、来源发布、当前可用性、暂停原因、直接上一版及恢复记录 | 查看修订、暂停、核对完整依赖后撤下、隔离恢复验证、显式恢复、整批回退 |

文档页负责内容整理与确认，发布确认只在发布任务详情办理。题目维护与运行记录分开，候选与恢复验证使用同一套任务、题目快照和裁定记录；恢复验证通过不切换版本，也不自动解除生产限制。旧版本入口定位到当前生效页签，不另维护重复菜单。动作分别核验页面与操作权限，同一有权限者可以兼任。

跨页入口保留逐层返回来源、查询页码、表内滚动和焦点，浏览器返回沿用对应页面的上下文。发布任务列表以文档名为主、编号为辅，按实际阻塞和权限提供处理文档、准备题单、处理异常题、处理待裁定或查看发布结果；直达办理后先返回对应任务，再回原列表。发布任务的补题入口只展示本批相关题；新增候选题默认带入本批文档。同批既有明确失败又有待裁定题时，优先处理失败，裁定不能替代异常修复。当前生效切换数据源时保留页签；发布后单文档直达版本，多文档限定本批生效范围，避免重新查找。

## 文档生成与修订

知识文档绑定一个数据源，按用途组织、按对象查找，不建立业务主题或场景分类。生成采用独立任务页，先明确业务事项，再核对清单、职责、适用条件、代表性问题和完整治理依据。商品中心库默认提出《商品标识与当前状态》和《商品原销售数量统计》两项建议；只需销量时可单独生成第二项。篇数随职责及实际依据确定，不按表、关联或指标机械成篇。

列表主入口为“生成知识文档”，进入“生成前确认”，核对后才生成正文。首屏展示名称、用途、可回答的问题、适用条件和不支持内容，用表和依据调整处于次级区域；当前原型以“示例建议”标明来源。新建议用“本次生成”开关选择，已有文档明确区分核对更新、另建和暂不处理；核对前显示待核对，不能提前标为依据齐全。“合并建议”进入独立选择状态，避免把合并勾选误解成生成范围。已有文档从原记录办理替代，不能合并拆分建议后遗忘原稿。

展开后修改职责、问题和核心条目，表作用与完整依据按需展开。修改后标待核对，底部汇总新建、已有和缺项；核对前生成禁用，核对后突出实际办理动作。必要依赖不能直接去除，收窄用途后重查；普通同表字段不自动补入。操作、依据情况和使用控制分别表达。未生成建议不计文档数；重新规划保留稳定身份，职责变动带入已有文档的核对页，不静默丢弃输入或覆盖正文。

核对冻结本次采用的范围和来源；提交重新校验当前权限及修订。逐项反馈新建、定位或更新入口、成功和具体失败，成功结果保留，失败可独立重试，重复提交不重复建稿。来源再次变化时保留输入并重新核对。缺项不阻塞其他完整建议，禁止状态不因整理草稿而解除。

生成完成后底栏汇总已完成篇数，主操作进入本批尚未确认的草稿，不再保留“生成 0 份草稿”。提交按钮仅统计当前可办理项；未完成项就近显示原因，补齐后可重试，已经生成的文档可独立回看；后续核对不会重新生成成功项。

阅读以“正文、范围与依据、修订与发布”三个页签组织，正文左侧定位章节，右侧保持阅读宽度，代表性问题及相关题单可直接定位。编辑沿用分栏，文档职责、治理范围和各章节分别编辑，切换不丢输入；章节同时维护对应依据。范围调整后重新核对，来源更新逐节查看新内容，明确采用本节建议或保留人工稿；错误定位对应章节和输入，保存草稿与确认分开。

名称、用途、条件、问题、排除项、范围、正文及依据绑定均属于修订。文档页并列显示正式版及其可用状态、整理稿及其确认状态，并标明正在阅读哪一版；编辑时显示基于的修订和未保存状态。正式标题和正文取发布快照；列表分别表达正式使用状态、整理修订、确认和更新提醒，不能草稿已更新就把旧正式版误标正常。换依据即使正文相同也保存新状态并重新确认验证；展示标题或采集批次不制造修订。业务定义变化返回治理，正式使用限制保留，维护缺口不写成事实。

更新入口列出全部受影响文档及整理稿、正式版本、在途候选，逐篇进入差异合并或记录有依据的无影响判断。来源依赖未确认等阻塞进入编辑页即显示，可定位具体治理条目；未取得有效当前依据时不展示空的更新建议。比较新旧正文时保留人工稿，来源或正文再次变化阻断过期提交。来源事项只有全部必要文档完成处理和必要恢复后才回写完成，不以首篇发布作为办结。

合并拆分逐份填写目标名称与用途，拆分时隐藏合并对象，不使用两组逐行对应的长文本；关闭、Esc 和返回保护输入。目标页以清单显示职责、修订和确认状态，只有存在显式引用时才展示引用方和去向，可选择多份目标，无引用不显示空配置。来源稿期间变化阻断旧整理结果，保留目标并要求核对新增人工修改。原稿切换前仅待替代，取消保留原正式版本和人工内容；已取消目标仅供回看，不再提供编辑、确认或发布入口。发布页展示目标和同批退出旧稿，候选冻结替代、引用、题单及基础版本，失败不部分切换。旧稿退出不删除共享事实、不连带禁止其他文档，整组回退同时恢复新旧组合，被替代文档不能单独恢复。

正文编辑使用完整任务页，支持长文本，实际未保存修改统一保护侧栏、面包屑和浏览器返回；继续编辑为默认选择。列表返回保留源、查询、有效页码与入口焦点。确认状态与更新提醒分别记录，原正式版本仍有效时继续使用。

## 标准题与候选验证

每源维护可复用题目，每次候选固定本批相关已审核修订。代表性问题不自动变成标准题；候选题可以起草，预期及判定依据由有审核权限者确认，可保存不完整草稿。覆盖检查关注关键能力和边界，商品样例包含身份和前导零、已确认及未知状态、关联与重复累计、同单位汇总、退货和时间边界。固定验证数据按实际引用的治理内容选择，合并拆分改变文档身份后仍使用匹配的样例。说明、数值和规则题分别处理，预期与实际独立保存，误差预先明确。题目修订、停用、合并拆分或依据变化后重新核对，不删题绕过必要覆盖。

待审题从列表直接进入桌面审核工作区，左侧为当前源或原任务范围内的待审队列，右侧阅读问题、预期与依据。“审核并下一题”只审核当前展示的确切修订，随后定位下一道待审题；最后一题审核后回到原题单。修订题目后可继续原审核队列，题单返回保留原任务、查询与有效页码。相关题单空态直接展示缺少的能力与边界，并提供生成题目草稿入口。

构建后自动运行相关题，缺少必要已审核题时提供补题入口并阻断。明确结果自动比较，说明类结果进入待裁定；只有当前候选待裁定结果可按证据裁定，明确失败和执行异常不能人工改成通过。历史题目、候选、运行和裁定记录保留原快照。固定样例外未接执行服务时显示执行异常，不提供手填实际结果或通过入口。

题目编辑分“问题与范围”和“预期与判定”，切换保留输入，误差只在数值题出现，固定验证数据按需查看。审核绑定实际展示的题目和文档依据，期间变化后重查。运行列表压缩长预期，完整预期、实际及规则从结果回看；裁定页保留本题预期与实际，提交核对运行编号，不能用旧弹窗裁定后来的重测。

人工裁定使用宽弹窗并排查看预期、判定规则及答案依据和完整实际结果，两侧正文分别滚动；底部裁定结论、依据与提交始终保留。空依据就近提示并定位输入，关闭、取消及 Esc 保护实际未提交内容。提交仍核对打开时的运行编号与权限，发生变化时保留输入并提示重新核对。

## 发布与版本

一次发布选择当前源的一份或多份完整确认修订，系统补齐明确的必要协同内容；仍有效且未变的依赖复用，无关文档不改版。范围调整保留原候选历史，重新构建验证。固定清单保存实际正文、治理依赖、题单和基础入口，临切换前重新检查。相关来源、内容、权限或验证依据变化时阻断，不沿用旧成绩；普通采集编号变化不构成内容变化。

已确认文档、创建任务的范围核对及构建前页面提前展示标准题的已审核、待审核与缺题情况，沿用候选校验的能力与边界覆盖判断。缺题仍可创建准备中的任务，不增加审批层级；主操作引导准备相关题单，补齐后返回原任务构建并验证。提前展示就绪情况不替代提交时的修订和权限核验。

本批全部必要内容通过后一次切换，失败不部分写入入口。结果不明确时核实全部目标和退出动作：全部生效才标已发布，完整未切换才返回待发布，部分切换或版本不一致继续待核实，不直接重发。正式修订按文档和批次展示，不用全源统一修订号；历史名称与范围取固定快照。

任务列表、详情和固定底栏共用当前门槛反馈。缺题或依据变化显示被阻断，并直接提供补题、文档处理、范围调整或重新构建入口。步骤条使用阶段名称，不将等待或阻断误写为正在执行。已取消任务停止给出继续发布建议；历史发布保留本次修订，后续回退或替代后的当前版本单独展示。

验证详情首屏汇总通过、未通过、待裁定与执行异常数量，零项采用中性色。待裁定题在显示时前置，固定底栏以处理待裁定题为主操作，直接打开当前运行的第一道待裁定结果；完成一题后更新剩余数量。重新运行验证保留为次要操作，排序不改写冻结题单或原始运行记录。

发布完成后回到结果首屏，先展示本批文档的冻结名称、实际发布修订、当前生效修订与可用性；当前暂停、禁止等限制继续展示。历史发布与后来的替代、回退分开表达，不能用当前草稿名称或正常标签覆盖历史事实。发布过程、完整验证和处理记录在下方按需展开，仍可查看全部证据。

未生效的构建和验证保留取消入口；阶段后台完成时不关闭正在填写的确认表单，也不刷新其他页面抢走输入焦点。页面内存记录因刷新不存在时提供返回当前源列表的入口。

当前生效聚焦正式修订、批次、可用性及控制，正文通过“阅读正式正文”回看，上一版全文按需打开。暂停保留版本；删除或不兼容按实际依赖拦截，业务存疑先待复核。恢复验证限定当前正式修订，生产继续受限；有权人员显式恢复后同步本次治理对象的使用控制，删除对象不能恢复。撤下沿实际引用去向展开必要范围，保留历史并在全部必要退出后回写来源事项。

未运行恢复验证时显示未验证，原通过依据变化后显示已失效。题单变化可从原任务重新发起恢复验证，保留历史运行；治理定义变化先定位文档更新，不能指向不允许构建的恢复任务。正常版本不常驻展示低频回退的禁用警告，原因保留在对应操作旁。无实际修改的保存或重复审核不新建题目修订。

回退固定为当前发布完整范围的直接上一版组合，预检结构、依赖、当前权限、禁止与相关题目。缺失或不兼容、部分已被后续发布替换时整批阻断；切换不清除当前限制。回退结果同时写入发布和版本记录。

## 状态表达

| 对象 | 主流转 | 异常或并存状态 |
| --- | --- | --- |
| 文档修订 | 草稿 → 已确认；修改进入下一草稿 | 待更新提醒独立，正式旧修订仍可生效 |
| 标准题 | 草稿 → 已审核；修改形成新修订 | 待复核或已停用，历史记录保留 |
| 发布任务 | 准备中 → 构建中 → 验证中 → 待发布 → 切换中 → 已发布 | 构建失败、验证未通过、待裁定、执行异常、被阻断、结果待核实、已取消 |
| 恢复验证任务 | 待验证 → 验证中 → 验证已完成 | 相同逐题异常及裁定分支，不自动恢复生产 |
| 正式内容 | 当前修订、直接上一版及历史发布 | 正常、待复核、暂停、来源不可用或已撤下 |
| 来源事项 | 知识处理中 → 已完成 | 发布后仍受限时等待恢复；停用删除依赖后完成，删除对象仍禁止 |

原型内存状态不表示真实模型、SQL、索引、权限、发布或恢复服务已实现，边界统一维护在原型状态。
