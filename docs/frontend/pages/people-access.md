# 人员角色与权限页面

业务含义见[模块解说](../../product/modules/02-people-access.md)及方案第 2 章。下表只负责前端页面、动作和状态表达；当前进度见[原型状态](../原型状态.md)，共用控件与布局见[设计约定](../设计约定.md)。

| 页面或区域 | 使用者职责 | 必要动作与流转 | 权限与状态边界 |
| --- | --- | --- | --- |
| 人员与部门 | 具备人员或组织管理权限者 | 创建账号、维护归属 → 填写身份与来源 → 预览确认；停用或恢复 → 核对影响或当前适当权限；归档前处理关联 | 创建后待首次登录；停用、复核恢复和归档分别表达，保留历史 |
| 角色与功能权限 | 具备角色管理及对应授予能力者 | 创建或修改角色 → 配置页面、按钮和功能 → 预览受影响人员 → 校验后保存；向个人分配角色 | 角色不绑定业务数据源或数据范围，部门不分配角色；受保护管理能力另行核验 |
| 授权执行与撤销 | 具备执行或撤销权限者 | 根据获批申请核对对象、范围、期限和申请版本 → 执行并回告；撤销 → 核对数据来源和影响 → 提交 | 额外数据访问必须有关联申请，审批与执行分开，不提供岗位直接授予入口 |
| 员工访问申请及进度 | 具有申请资格的本人 | 申请访问 → 填用途、业务范围、期限 → 提交；需补充 → 修改相关业务信息后重新提交；未生效子项可撤回；查看已生效范围与回告 | 不要求知道表字段；草稿、待审批、需补充、撤回、驳回、待执行、部分生效等分别表达；问数申请与后台办理相互关联 |
| 访问申请审批与执行 | 各责任范围内的有权负责人、授权执行者 | 查看用途 → 映射所需资源、行字段条件与期限 → 分项批准、要求补充或说明理由驳回；批准后由有权执行者复核并执行 → 回告实际结果 | 本人申请采用替代审批；独立子项可分别生效，联合组合须整体满足条件；审批与执行分别表达 |
| 授权记录 | 具有对应记录可见性者 | 查询范围、人员与日期 → 查看实际授权来源、期限和办理详情；撤权等变更进入有权授权管理流程 | 待批准或待执行不冒充已生效；到期保留原办理事实，技术对象按目录权限展示 |
| 权限审计 | 具有对应审计可见性者 | 按操作者、目标与时间查询 → 查看必要前后差异、原因、结果和权限版本 → 追溯关联授权或任务 | 审计不复制整份业务查询结果，敏感诊断另行授权 |
| 本人资料与申请 | 当前登录本人；他人资料管理在有权后台页面办理 | 从后台个人管理查看本人账号、我的申请及访问范围；问数保持独立 | 本人资料、申请及范围在后台；不设独立账号安全或登录会话页面 |

## 功能权限与数据访问

个人角色控制能进入哪些页面、使用哪些按钮和功能；部门配置初始数据源和获准范围，额外数据访问走申请。功能可用与数据可访问同时满足才允许对应操作。拥有管理员等角色不自动获得业务数据访问。

| 位置 | 配置与展示 | 修改边界 |
| --- | --- | --- |
| 部门初始数据访问 | 按数据源选择一个或多个预设访问范围，展示获准表、行条件和字段；来源期限清空为长期 | 影响本部门直属成员，包含直属兼任关系；不改个人角色、申请授权、其他部门或下级配置 |
| 人员分配角色 | 选择角色与角色期限，只读展示对应页面、按钮和功能 | 不出现部门角色、数据源或业务数据范围配置，不改变初始数据访问或申请授权 |
| 人员详情 | 独立展示个人角色；数据访问另列各部门初始来源与已生效申请，包含范围、期限、来源停用或待复核状态 | 角色到人员分配维护，初始访问到部门维护，额外访问到本人申请；不把待审批、驳回或撤回记录当作有效数据来源 |
| 我的访问范围与我的申请 | 本人查看当前数据访问来源 → 申请额外数据源与范围、业务用途和期限 → 预览提交 → 查看状态与详情，可撤回待审批申请 | 提交后为待审批，不立即可访问；批准与执行后的真实生效另行实现，不添加演示审批或一键授权按钮 |

配置数据源时，访问范围只列该源下可选项，切换源清空原范围。预设范围明确对应表、行条件和字段，不提供不受限制的整库默认访问。列表和详情逐项保留这些对应关系，避免把一个来源的行和另一个来源的字段拼接。

部门配置变更先展示数据源与范围、期限及影响成员的前后差异。预览与取消不修改示例数据，确认后更新展示；清空并保存或结束初始数据访问后显示未配置。调岗仅调整部门数据来源，个人角色和申请授权保持不变。恢复部门后，保留的数据配置仍须复核。账号及对象停用等状态约束仍适用。

当前原型以少量固定功能角色、数据源、范围和申请状态展示上述关系，范围中的部门名称仅作为文案替换；不计算权限、解析行条件、连接业务数据库或执行审批授权。完整角色管理、审批办理、授权执行和历史审计按模块另行制作。
