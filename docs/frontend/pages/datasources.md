# 数据源接入与元数据采集页面

业务含义见[模块解说](../../product/modules/03-datasources.md)及方案第 3 章。下表只负责前端页面、动作和状态表达；当前进度见[原型状态](../原型状态.md)，共用控件与布局见[设计约定](../设计约定.md)。

| 页面或区域 | 使用者职责 | 必要动作与流转 | 权限与状态边界 |
| --- | --- | --- | --- |
| 数据源列表与概览 | 具备对应数据源可见或管理权限者 | 选择当前源 → 查看连接、采集、治理和知识状态；进入可操作的连接、采集、变化或治理页面 | 分别显示健康、完整性和可用范围，不用连接成功替代知识可用 |
| 数据源审批责任 | 具备责任配置权限者；具备页面可见权者可回看 | 在“数据源管理 → 审批责任”搜索数据源或负责人、筛选责任状态 → 查看详情 → 选择主审批人与替代负责人 → 核对变更及未处理子项影响后保存 | 两人不同且有可用审批功能；技术维护不自动取得配置或审批权；仅更新未处理子项，保留已办事实，不增加访问 |
| 连接新建与编辑 | 具备连接配置、测试或启停权限者 | 填分组配置及凭据 → 分项测试 → 保存草稿或启用；暂停采集、停用、恢复、更新连接密码及退役 → 核对影响后执行 | 凭据遮蔽；管理连接不自动获得数据查询权 |
| 企业业务说明 | 具备该源资料查看、提交或相应管理权限者 | 写自由说明或上传资料 → 保存修订；编辑、撤下、恢复或删除 → 核对条件并记录操作 | 按数据源供治理共享，不逐人选择；所有修订均未被任务取用或成果引用才可删除，含历史和在途引用；原始附件查看和下载单独受控 |
| 表结构目录与对象详情 | 具备对应目录可见权者 | 按类型与目录、治理状态搜索 → 查看对象结构、解释、缺项及来源 → 进入有权治理的对象 | 表级与全源目录可见范围分别控制，搜索数量不泄露受限对象 |
| 采集记录与结构变化 | 具备采集、变化核实或治理查看权限者分别办理 | 发起采集 → 查看进度、失败重试及本次变化；变化分列事实与进度，可靠差异自动确认，疑点核实后进入影响评估；可回看来源与治理结果 | 继续核实保留待核实；无影响不强制负责人，处理完成不等于整表已确认、发布或解除禁止 |

连接表单中的技术联系人、业务联系人均为选填，不显示必填星号，标签直接使用字段名称；默认不选且可以清空。列表、核对及详情在未指定时保持可读。联系人用于自行联系，不配置通知或派单流程；企业业务说明的提交资格和数据访问审批责任分别按对应权限配置。

数据源详情的“已禁止使用的知识”在有记录时通过数量打开只读明细，展示知识内容、依赖对象及禁止原因；关闭或按 Esc 返回原详情并恢复焦点。零项只展示数量。有效配置修订放在“配置记录”中，即使没有后续变更记录也保留当前修订。

数据库账号使用企业提供的既有只读账号，新增时留空；当前用户名密码表单直接标为数据库密码，编辑时留空沿用已设置值。启用后进入该源目录，未采集时显示首次采集入口；发起采集仅做一次范围与账号核对，运行限制的既定约束保留。

数据库版本在连接测试后只读展示，不需用户填写。MySQL 不展示 Schema；PostgreSQL 在测试完成后选择 Schema 范围，未测试时禁用选择，首次使用返回列表的全部项。连接参数变化使测试结果失效，单独缩小 Schema 选择保留连接测试结果。核对、详情、采集任务及目录均保持同一范围；改变既有范围后须重新采集。

新增、编辑及核对不展示 TLS 校验、证书引用或连接超时填写项，数据源配置不保存这些逐源选项；平台连接策略保留加密、证书验证与默认超时，分项测试继续展示网络与加密是否通过。

审批责任列表展示数据源、主审批人、替代负责人、责任状态及更新时间，姓名附登录名。未配置与需复核分别表达；表单只提供有可用审批功能的正常账号，重复选择须修正后再核对。详情与核对复用后台抽屉和变更预览，不填技术连接资料。

数据源名称、主审批人、替代负责人分别查询，条件取交集，责任状态另行筛选。窄 PC 窗口固定右侧操作列；人员配置未变化时不能核对或确认保存。从待分流申请进入时直接打开该源配置，取消返回原单据；保存后回看原申请及新负责人，再回到保留条件的队列，不绕到全部数据源清单。

具体分派规则见[审批责任与分派](../../product/modules/02-people-access.md#审批责任与分派)。管理入口默认展示数据源概况，与审批责任并列；目录、采集及业务说明使用共用当前数据源选择，切源恢复各自查询。对象详情使用固定底栏抽屉，进入治理保留源与对象身份。实际覆盖和验证范围统一见原型状态。

企业业务说明列表由标题进入详情，修订与附件数量并入标题辅助行；提交人姓名与登录名分行，使用情况区分未使用、治理任务进行中、已有治理引用及仅历史修订被引用。有效资料前置编辑、撤下，已撤下资料提供恢复；删除收进“更多”，不满足条件时禁用并直接展示原因。详情保留引用条目、实际引用修订、任务状态、修订历史与撤下／恢复记录。撤下填写原因后核对，恢复与删除只做一次明确目标和后果的确认；取消不写入。处理后保留当前数据源、查询和有效页码，焦点回到资料或相邻记录。

对象详情先显示对象路径、状态、字段及业务解释，来源标识、世代、采集快照和读取能力放入可展开区。任务实时结束后按最终状态提供重试等操作，关闭后列表使用最新状态。

目录中的对象包括表和视图，列表使用“对象 / 解释”，搜索使用“对象名或解释”，不限定解释的语言。来源注释按原文展示；详情按对象类型使用“表注释”或“视图注释”，字段表格单独使用“字段注释”，不把表或视图的注释称为数据库注释。

详情的短字段可双列，数据源用途、表或视图注释、变化对象、来源证据及受影响内容独占整行；保留原文换行，连续英文可断行。长标题在固定标题栏省略，正文展示完整名称，关闭入口和底栏不随长文本移出视口。长正文由抽屉内部纵向滚动承接。

来源信息保留对象世代，标签右侧问号使用组件库 Tooltip，支持鼠标悬停与键盘聚焦，Esc 先关闭说明并保留当前详情。说明用同名对象删除重建的例子解释代次，表、视图及其他有独立身份的目录对象均可适用；普通采集、改字段或修改视图定义不自动换代，来源证据不足时不推断重建。已确认重建且身份仍待核对时，在详情顶部显示对应表或视图的重建提示；完成身份核对后不继续显示待核对提示。

结构变化分开显示“变化对象”和“变化项”：表注释变化的对象为表名，变化项为表注释；字段类型变化的对象为真实的表名加字段名，变化项为字段类型；目录可见性变化只指向表或视图。列表主行显示真实对象路径，辅助行显示变化项；查询同时匹配对象路径与变化项，详情和变化核实沿用同一口径。不能把“来源注释”等属性名称当作字段名拼接；真实中文字段名仍按来源名称保留。

目录状态是对象摘要，不与本次任务成功或失败混为一项。结构变化和属性缺失可同时存在，筛选任一状态均须保留符合的对象。字段解释仍待确认的示例用部分确认，不冒充对象治理完成；源概况分别展示完整确认及部分确认对象数量。普通视图字段不展示生成默认值，详情不套用普通表主键及物理索引；未支持读取注释时按读取状态表达，不写成没有注释。

变化记录的来源与采集信息展示发现任务和前后快照，可回看同源任务；任务详情列出本次变化，对象详情可打开相关变化。历史来源不随新采集改写，完整成功与候选结果分开表达。

结构变化分列“变化事实”和“处理进度”，分别查询。证据充分的差异直接已确认，来源不明保留待核实；核实表单明确选择确认变化、排除结构变化或继续核实，填写依据或待补充内容，不再保存即一律已核实。继续核实不交接治理；排除结构变化保留原因，不解除来源访问异常或既有禁止。可靠事实进入治理影响评估，可从详情查看关联处理记录；原始业务解释和整表治理摘要不因办理而自动覆盖。

已引用业务说明的正文或附件实质变化、撤下时，资料保存与影响评估同次形成；标题修改、无内容修改及未引用资料不自动创建评估。资料详情展示每次评估的编号、进度、负责人、结论和治理结果，可进入治理审核与复核。前后正文、附件和修订绑定当次变化，后续修改不改写旧评估，原任务与成果继续引用原资料修订；恢复不自动结束旧评估。

修订和状态按以下口径表达：

| 展示项 | 何时变化 | 不由什么动作触发 |
| --- | --- | --- |
| 配置修订 | 连接、范围、运行参数、联系人、用途或凭据有实质修改时递增；相同 Schema 集合的顺序变化不算修改 | 重复测试、无修改保存、启停或启用已有草稿不生成新配置修订 |
| 采集快照 | 每次采集任务分配候选编号，可靠对象结果关联本次快照；失败、取消仍有任务记录 | 编号递增不表示已发生结构差异，不改变对象世代、资料修订或知识版本 |
| 业务说明修订 | 标题、正文或附件实质修改后递增，历史保留当时标题、正文和附件 | 无修改保存、撤下或恢复不增加内容修订；状态动作另留记录，恢复不抹去撤下原因 |
| 知识发布版本 | 治理确认、候选构建、相关测试及发布检查通过后切换正式版本 | 采集、业务说明更新或连接恢复不自动发布，也不自动解除禁止 |

取消采集、暂停采集、停用、恢复数据源、退役及撤下资料保留必要原因；恢复定时采集的原因可选。核对页展示已填写原因，取消原因和撤下原因可在处理后详情回看。失败原因由任务只读显示，不要求用户重填系统错误。变化核实、治理确认和解除知识禁止分开表达；仅记录技术核实结论不解除禁止。恢复连接只反馈实际执行的连接和读取检查，不冒充结构差异或索引验证。
