# 数据源接入与元数据采集页面

业务含义见[模块解说](../../product/modules/03-datasources.md)及方案第 3 章。下表只负责前端页面、动作和状态表达；当前进度见[原型状态](../原型状态.md)，共用控件与布局见[设计约定](../设计约定.md)。

| 页面或区域 | 使用者职责 | 必要动作与流转 | 权限与状态边界 |
| --- | --- | --- | --- |
| 数据源列表与概览 | 具备对应数据源可见或管理权限者 | 选择当前源 → 查看连接、采集、治理和知识状态；进入可操作的连接、采集、变化或治理页面 | 分别显示健康、完整性和可用范围，不用连接成功替代知识可用 |
| 数据源审批责任 | 具备责任配置权限者；具备页面可见权者可回看 | 在“数据源管理 → 审批责任”搜索数据源或负责人、筛选责任状态 → 查看详情 → 选择主审批人与替代负责人 → 核对变更及未处理子项影响后保存 | 两人不同且有可用审批功能；技术维护不自动取得配置或审批权；仅更新未处理子项，保留已办事实，不增加访问 |
| 连接新建与编辑 | 具备连接配置、测试或启停权限者 | 填分组配置及凭据 → 分项测试 → 保存草稿或启用；暂停采集、停用、恢复、更新连接密码及退役 → 核对影响后执行 | 凭据遮蔽；管理连接不自动获得数据查询权 |
| 企业业务说明 | 具备该源资料查看、提交或相应管理权限者 | 新增、编辑时填写说明或上传资料 → 直接保存；撤下、恢复或删除 → 核对条件并记录操作 | 按数据源供治理共享，不逐人选择；所有修订均未被任务取用或成果引用才可删除，含历史和在途引用；原始附件查看和下载单独受控 |
| 采集记录 | 具备采集记录查看或操作权限者 | 查看任务 → 按状态回看等待、进度、成功结果、失败或取消原因；按权发起、取消或重新采集 | 独立页面，菜单位于元数据目录之前；只有成功任务展示采集结果与结构分析，失败仅展示原因及基本信息 |
| 表结构目录与对象详情 | 具备对应目录可见权者 | 按对象名或解释、对象类型及目录状态搜索 → 查看对象结构、解释、缺项及来源；有变化时直接查看该表及字段的变化 → 事实核实齐备后主动进入治理 | 表级与全源目录可见范围分别控制，搜索数量不泄露受限对象 |
| 结构变化页签 | 具备变化查看、核实或治理查看权限者分别办理 | 在元数据目录中切换到结构变化 → 系统确认明确差异、人工核实疑点 → 同一对象事实核实齐备后进入治理；可回看发现它的成功采集任务 | 页签与目录各自核验权限，保留来源往返；核实不替代治理确认、发布或解除禁止 |

连接表单中的技术联系人、业务联系人均为选填，不显示必填星号，标签直接使用字段名称；默认不选且可以清空。列表、核对及详情在未指定时保持可读。联系人用于自行联系，不配置通知或派单流程；企业业务说明的提交资格和数据访问审批责任分别按对应权限配置。

数据源详情的“已禁止使用的知识”在有记录时通过数量打开只读明细，展示知识内容、依赖对象及禁止原因；关闭或按 Esc 返回原详情并恢复焦点。零项只展示数量。有效配置修订放在“配置记录”中，即使没有后续变更记录也保留当前修订。

数据库账号使用企业提供的既有只读账号，新增时留空；当前用户名密码表单直接标为数据库密码，编辑时留空沿用已设置值。启用后进入该源目录，未采集时显示首次采集入口；发起采集仅做一次范围与账号核对，运行限制的既定约束保留。

数据库版本在连接测试后只读展示，不需用户填写。MySQL 不展示 Schema；PostgreSQL 在测试完成后选择 Schema 范围，未测试时禁用选择，首次使用返回列表的全部项。连接参数变化使测试结果失效，单独缩小 Schema 选择保留连接测试结果。核对、详情、采集任务及目录均保持同一范围；改变既有范围后须重新采集。

新增、编辑及核对不展示 TLS 校验、证书引用或连接超时填写项，数据源配置不保存这些逐源选项；平台连接策略保留加密、证书验证与默认超时，分项测试继续展示网络与加密是否通过。

审批责任列表展示数据源、主审批人、替代负责人、责任状态及更新时间，姓名附登录名。未配置与需复核分别表达；表单只提供有可用审批功能的正常账号，重复选择须修正后再核对。少量责任信息使用居中详情弹窗，配置与核对复用短表单及变更预览，不填技术连接资料。

数据源名称、主审批人、替代负责人分别查询，条件取交集，责任状态另行筛选。窄 PC 窗口固定右侧操作列；人员配置未变化时不能核对或确认保存。从待分流申请进入时直接打开该源配置，取消返回原单据；保存后回看原申请及新负责人，再回到保留条件的队列，不绕到全部数据源清单。

具体分派规则见[审批责任与分派](../../product/modules/02-people-access.md#审批责任与分派)。管理入口默认展示数据源概况，与审批责任并列；目录、采集及业务说明使用共用当前数据源选择，切源恢复各自查询。对象结构使用独立页面，字段表、注释及来源不挤入窄抽屉，进入治理保留源与对象身份。数据源新增和连接编辑使用居中宽弹窗，填写、测试和核对在同一弹窗内切换，保留背景列表查询及有效页码；内部内容滚动，关闭时保护实际未保存修改。业务说明新增／编辑使用独立任务页，保存后返回实际入口，页内离开保护未保存修改。单次测试、密码更新和核实结论继续使用聚焦弹窗。实际覆盖和验证范围统一见原型状态。

企业业务说明列表只显示资料标题、提交人、更新时间、资料状态和操作，由标题进入详情，修订与附件数量并入标题辅助行，提交人姓名与登录名分行。查询仅保留资料标题、提交人和资料状态，不提供使用情况或处理进度筛选。新增与编辑填写说明或选择附件后直接保存，不设核对页；保留必填及附件校验，未修改时不可重复保存。有效资料直接显示编辑、撤下与删除，已撤下资料提供恢复与删除；删除不满足条件时禁用，悬停或键盘聚焦可查看具体引用对象、被引用修订及详情去向。详情仅在有记录时展示引用记录与变更影响；无记录时省去对应区块及空态说明。修订历史与撤下／恢复记录继续保留。撤下填写原因后核对，恢复与删除只做一次明确目标和后果的确认；取消不写入。处理后保留当前数据源、查询和有效页码，焦点回到资料或相邻记录。

引用记录区分治理任务取用与治理成果引用，逐条展示对象名称、编号、状态、使用方式、资料修订、引用人或任务发起人（姓名与登录名）、引用时间和具体用途。点击名称在同一抽屉查看引用详情：人工依据展示采用的原文、成果内容及确认人和确认时间；任务输入展示用途、进展与产出和完成时间。具体治理内容另核对治理查看权，无权时保留引用追溯信息并给出权限反馈。两类均可回看被引用那一版的正文和附件，历史修订与当前版明确区分，原修订不可用时显示异常，不以最新版替代。返回或 Esc 恢复资料详情的滚动及引用入口焦点，关闭按钮退出整个抽屉。资料详情保留引用条数和不能删除的后果提示，任务完成或资料撤下不抹去历史引用。变更影响另行展示处理编号、进度、处理人与治理结果，不与引用状态混为一项。治理建议的生成、采用和人工确认已联动页面内任务取用与成果引用；固定引用作为初始示例保留，尚未接真实执行与存储服务。

对象详情先显示对象路径、状态、字段及业务解释，来源标识、世代、采集快照和读取能力放入可展开区。任务实时结束后按最终状态提供重试等操作，关闭后列表使用最新状态。

采集的处理进度与读取结果分开：列表与详情统一使用“已发现／已尝试读取”，统计本次配置范围内、采集账号可见的表和视图，并非仅统计本次新增对象。已尝试读取数等于结构读取完整、结构读取不完整和读取失败三类数量之和；未处理数为已发现数减去已尝试读取数，失败也计入已尝试读取，不表示读取成功。取消核对沿用“已尝试读取”。结构读取结果只表示字段、类型、注释及适用的键和索引等元数据，不表示业务数据质量或治理完成。字段等可靠结构已取得、索引等属性缺失时计入结构读取不完整，不计作读取失败；两类异常均可重试。

采集记录及元数据页签的菜单顺序、状态详情和权限展示沿用[设计约定](../设计约定.md#数据源接入)。页面往返保留各自查询、有效页码、滚动与焦点；失败后的重新采集覆盖当前配置范围，原任务保留。

目录中的对象包括表和视图，列表使用“对象 / 解释”，搜索使用“对象名或解释”，不限定解释的语言。来源注释按原文展示；详情按对象类型使用“表注释”或“视图注释”，字段表格单独使用“字段注释”，不把表或视图的注释称为数据库注释。

上下文详情的短字段可双列，数据源用途、表或视图注释、变化对象、来源证据及受影响内容独占整行；保留原文换行，连续英文可断行。长标题在固定标题栏省略，正文展示完整名称，关闭入口和底栏不随长文本移出视口。抽屉长正文在内部纵向滚动；结构详情使用页面内容区滚动，字段表仅在需要时横向滚动。数据源详情打开禁止知识、来源采集等相关内容时复用同一抽屉，返回上一级恢复原滚动与焦点，不叠加多个抽屉。

来源信息保留对象世代，标签右侧问号使用组件库 Tooltip，支持鼠标悬停与键盘聚焦，Esc 先关闭说明并保留当前详情。说明用同名对象删除重建的例子解释代次，表、视图及其他有独立身份的目录对象均可适用；普通采集、改字段或修改视图定义不自动换代，来源证据不足时不推断重建。已确认重建且身份仍待核对时，在详情顶部显示对应表或视图的重建提示；完成身份核对后不继续显示待核对提示。

结构变化分开显示“变化对象”和“变化项”：表注释变化的对象为表名，变化项为表注释；字段类型变化的对象为真实的表名加字段名，变化项为字段类型；目录可见性变化只指向表或视图。列表主行显示真实对象路径，辅助行显示变化项；查询同时匹配对象路径与变化项，详情和变化核实沿用同一口径。不能把“来源注释”等属性名称当作字段名拼接；真实中文字段名仍按来源名称保留。

目录状态是对象摘要，不与本次任务成功或失败混为一项。结构变化和属性缺失可同时存在，筛选任一状态均须保留符合的对象。目录列表及对象结构页聚焦元数据，不展示治理进度、确认数量或业务定义待核对提示，也不提供治理进度筛选；治理进度及具体核对项在治理工作台展示，目录继续保留治理入口。目录标签与数量分层并保持同一阅读起点，访问丢失在真实成功读取后才解除，事实核实或业务影响处理完成不解除读取异常。普通视图字段不展示生成默认值，详情不套用普通表主键及物理索引；未支持读取注释时按读取状态表达，不写成没有注释。

数据源概况分列最近结构采集、业务治理和知识。目录对象总数是当前目录在所选读取范围内的对象数，治理进度按表说明与字段统计：已治理、治理中、待治理三类互斥，合计等于目录总数；已治理要求这一范围的必要业务定义全部确认，关联和指标另行审核。业务定义待核对的对象数单列，可以与治理进度重叠，不参与三类求和。数据源概况与治理工作台沿用同一统计范围；元数据目录及对象结构页不重复展示逐表治理进度。最近采集结果对应具体任务及其时间；失败、取消不覆盖目录成功快照，目录对象总数不等于失败任务本次发现数量。知识按项统计，与对象并非一对一；采集完整、表说明与字段已治理及知识发布各自表达。

变化记录的来源与采集信息展示发现任务和前后快照，可回看同源任务；成功任务可进入目录内对应对象的结构变化，变化详情可回看来源采集记录，对象详情继续保留查看变化入口。历史来源不随新采集改写，成功快照与失败或取消的候选结果分开表达。

结构变化列表保留变化对象、变化类型、发现时间、处理阶段和操作；查询按对应表头顺序提供对象、类型、发现日期和阶段。阶段为待核实、待治理、治理中、知识处理中、已完成，分别提供核实变化、进入治理、继续治理、处理知识更新和查看结果。事实结论保留在详情；可靠差异直接待治理，证据不足才待核实。处理阶段不替代整表治理进度，也不表示对象或知识已恢复可用。

待核实详情展示变化对象、前后差异、采集依据和具体疑点，主要操作为核实变化。目录中未读到对象时，核实结论明确为对象已删除或对象仍存在，并填写依据；确认删除才禁用对象并进入受影响内容的治理，对象仍存在则排除结构变化，读取异常保留到重新采集成功。其他差异按实际事实确认或排除；无法判断时取消或返回，不新增记录。已确认详情展示受影响的治理条目并直接进入治理。来源说明有可靠依据时在来源信息中回看，不单独维护变更原因，不展示未知原因占位或独立的变更原因与核对事项区块。技术疑点在核实页，具体业务问题随对应治理条目展示；必要禁用反馈继续保留。

同一张表及字段的待核实项清零后，主动进入对应表治理条目；来源结论和证据只读沿用，受影响业务内容直接补充、修改或审核，不另办变化待办、无需修改结案或结果确认。目录可见性改变不重置业务定义。知识处理中的变化直接进入对应知识更新事项，后续按[变更知识更新](knowledge-release.md#变更知识更新)处理。查看变化只定位当前对象，核实范围与治理入口不受查询筛选影响；来源往返保留当前源、查询、有效页码、滚动和焦点。条目审核、必要发布和显式解除自动回写来源阶段与结果，知识处理中仍保留目录关注项；完成后移除变化提示，属性缺失独立保留。技术核实不自动确认业务定义或整表治理。

已引用业务说明的正文或附件实质变化、撤下时，保留资料修订和影响来源，将受影响条目并入表治理；仅改标题、内容未变及未引用资料不新增治理工作。资料详情只读回看自动汇总的进度、处理人和审核结果，可直接打开对应条目；映射未明的资料在表治理列表保留待定位入口，关联同源条目后直接处理。前后正文、附件及修订绑定当次变化，历史引用不静默改绑新版；恢复不自动结束未完成的治理或解除禁止。

修订和状态按以下口径表达：

| 展示项 | 何时变化 | 不由什么动作触发 |
| --- | --- | --- |
| 配置修订 | 连接、范围、运行参数、联系人、用途或凭据有实质修改时递增；相同 Schema 集合的顺序变化不算修改 | 重复测试、无修改保存、启停或启用已有草稿不生成新配置修订 |
| 采集快照 | 每次采集任务分配候选编号，只有采集成功才更新目录并分析变化；失败、取消的已读内容只保留在任务 | 编号递增不表示已发生结构差异，不改变对象世代、资料修订或知识版本 |
| 业务说明修订 | 标题、正文或附件实质修改后递增，历史保留当时标题、正文和附件 | 无修改保存、撤下或恢复不增加内容修订；状态动作另留记录，恢复不抹去撤下原因 |
| 知识发布版本 | 治理确认、候选构建、相关测试及发布检查通过后切换正式版本 | 采集、业务说明更新或连接恢复不自动发布，也不自动解除禁止 |

取消采集、暂停采集、停用、恢复数据源、退役及撤下资料保留必要原因；恢复定时采集的原因可选。核对页展示已填写原因，取消原因和撤下原因可在处理后详情回看。失败原因由任务只读显示，不要求用户重填系统错误。变化核实、治理确认和解除知识禁止分开表达；仅记录技术核实结论不解除禁止。恢复连接只反馈实际执行的连接和读取检查，不冒充结构差异或索引验证。
