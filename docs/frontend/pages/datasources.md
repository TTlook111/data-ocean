# 数据源接入与元数据采集页面

业务含义见[模块解说](../../product/modules/03-datasources.md)及方案第 3 章。下表只负责前端页面、动作和状态表达；当前进度见[原型状态](../原型状态.md)，共用控件与布局见[设计约定](../设计约定.md)。

| 页面或区域 | 使用者职责 | 必要动作与流转 | 权限与状态边界 |
| --- | --- | --- | --- |
| 数据源列表与概览 | 具备对应数据源可见或管理权限者 | 选择当前源 → 查看连接、采集、治理和知识状态；进入可操作的连接、采集、变化或治理页面 | 分别显示健康、完整性和可用范围，不用连接成功替代知识可用 |
| 数据源审批责任 | 具备责任配置权限者；具备页面可见权者可回看 | 在“数据源管理 → 审批责任”搜索数据源或负责人、筛选责任状态 → 查看详情 → 选择主审批人与替代负责人 → 核对变更及未处理子项影响后保存 | 两人不同且有可用审批功能；技术维护不自动取得配置或审批权；仅更新未处理子项，保留已办事实，不增加访问 |
| 连接新建与编辑 | 具备连接配置、测试或启停权限者 | 填分组配置及凭据 → 分项测试 → 保存草稿或启用；暂停采集、停用、恢复、轮换凭据及退役 → 核对影响后执行 | 凭据遮蔽；管理连接不自动获得数据查询权 |
| 企业业务说明 | 具备该源资料提交或管理权限者 | 写自由说明或上传资料 → 保存修订；补充、替换或撤下 → 记录变更并提示相关治理复核 | 默认仅提交人与该源资料管理者可见，不强制技术映射或固定模板 |
| 表结构目录与对象详情 | 具备对应目录可见权者 | 按类型与采集、治理状态搜索 → 查看对象结构、中文解释、缺项及来源 → 进入有权治理的对象 | 表级与全源目录可见范围分别控制，搜索数量不泄露受限对象 |
| 采集记录与结构变化 | 具备采集或复核权限者 | 发起采集 → 查看实际进度；失败对象重试或取消；查看前后差异 → 核对影响并提交复核结果 | 部分成功与未知覆盖分开；结构变化不自动覆盖人工确认或解除禁止 |

审批责任列表展示数据源、主审批人、替代负责人、责任状态及更新时间，姓名附登录名。未配置与需复核分别表达；表单只提供有可用审批功能的正常账号，重复选择须修正后再核对。详情与核对复用后台抽屉和变更预览，不填技术连接资料。

数据源名称、主审批人、替代负责人分别查询，条件取交集，责任状态另行筛选。窄 PC 窗口固定右侧操作列；人员配置未变化时不能核对或确认保存。从待分流申请进入时直接打开该源配置，取消返回原单据；保存后回看原申请及新负责人，再回到保留条件的队列，不绕到全部数据源清单。

具体分派规则见[审批责任与分派](../../product/modules/02-people-access.md#审批责任与分派)。当前审批责任页签已有离线交互，数据源概况、连接与采集页面仍待制作。
