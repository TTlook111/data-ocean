# 智能问数与查询流程页面

业务含义见[模块解说](../../product/modules/06-query.md)及方案第 6 章。下表只负责前端页面、动作和状态表达；当前进度见[原型状态](../原型状态.md)，共用控件与布局见[设计约定](../设计约定.md)。

| 页面或区域 | 使用者职责 | 必要动作与流转 | 权限与状态边界 |
| --- | --- | --- | --- |
| 问数工作台 | 具备所选源问数权限者 | 选单一数据源 → 新建并发送问题；在同一输入框点选或自由补充、改条件、换题；仅补缺项回暂停节点，改变原意才重新理解；运行中停止 → 展示中断实际状态 | 切源分隔上下文，换题重核；取消、等待、到期和失败分别展示 |
| 回答、明细与查询依据 | 当前有权查看该结果者 | 默认看业务结论 → 按需展开明细、切换图表/表格或查询依据；有相应权限者查看 SQL；导出当前可见结果 | 展示查询时间与可信数据更新时间，未知明确标注；能看即可导出，无回答分享 |
| 结果已交付、解释未完成 | 当前仍有权查看且结果仍可用者 | 保留已交付表格；解释失败时就近提供“重试解释”，继续使用原查询结果 | 解释状态与查询状态分开；不重发 SQL、不更新数据时间，不把旧结果当作重新查询 |
| 历史与重新查询 | 具备记录归属及当前结果权限者 | 搜索或打开历史 → 看当次答案及历史标识；重新查询 → 重新核对意图、源、权限与版本 → 产生关联的新答案 | 过期、失权与记录不可用分别说明，不用新数值覆盖旧答案 |
| 评价、申请与处理进度 | 原提问人及相应事项申请人 | 点赞直接记录；点踩 → 填非空原因 → 提交；可修改或撤销评价；权限不足按用途申请，已关联治理事项可补充，收到回告后回原问重查 | 他人不能评价该回答；知识缺口自动建或关联治理事项，用户补充不改写知识 |

## 数据访问与输出限制

数据源授权及所选中文输出限制规则共同约束问数，不依据所属部门追加业务记录过滤。用户指定的门店、部门等仍作为本题业务条件处理。输出限制命中后在原问题目的内重新生成；无法满足原问题才说明无权，治理标签不足则按知识缺口处理。文字、表格、图表、历史和导出遵循相同限制，受限字段仍可参与合法查询条件。

当前原型顶栏可选择示例账号可用的数据源，切换时保留各自对话和草稿，打开历史恢复当次数据源。经营业务库有固定毛利汇总、成本输出受限等示例，其他源不复用这些结果。选择项来自共用示例人员与数据源目录，不代表真实权限计算。

申请入口跳转后台表单，带入当前事项卡对应的原问题和已知数据源，用户核对后提交；不填写数据授权期限或选择业务范围模板。原型只表达申请及状态，不解析中文规则、执行 SQL 或连接真实审批。字段仅作合法条件时，不能因问题包含受限字段名称就判为无权；未覆盖问题不生成假结果。

查询依据按需展示已确定的日期区间、同比或环比比较方式、本次临时公式及适用口径。原因类回答区分已核实的变化与尚不能证明的原因；不增加逐次执行确认。具体原型覆盖仍见原型状态，不能据本页推断新交互已实现。
