# 原型状态

当前为离线交互原型，正式前后端重构尚未开始。业务规则见[产品方案与解说](../product/README.md)，界面规则见[设计约定](设计约定.md)，原型入口及脚本见[页面专题](pages/README.md#原型定位与衔接)。本页仅维护当前覆盖及验证边界。

## 跨模块状态边界

- 后台按页面及操作权限控制；审批负责人、任务分派和本人记录归属仍约束办理。问数另核数据源访问与输出限制，部门不产生业务记录过滤。
- 同标签页往返交接已保存的人员、规则、申请、授权、审批审计、治理、文档、题单及发布状态；未提交表单不交接，刷新后台恢复初始示例，不支持跨标签页实时同步。
- 规则变更后，旧样例不直接沿用原交付资格；保留当次快照并按当前限制核对，必要时提供重新查询，不自动重放旧查询。
- 建议与采样、人工确认、知识发布、生产禁止及解除分别表达。来源恢复、发布成功或模型索引切换不自动解除已有禁止。
- 凭据不回显、不进入原型交接快照；模型配置只接收演示凭据。没有真实认证、业务API、AI、SQL执行、索引、通知投递或服务端持久化。

## 当前验证

后台固定展示超级管理员，替代审批人的批准由页面模型回放，不能作为真实多账号认证验收。固定题单按冻结文档及验证数据判定，说明题由人工裁定；这不代表已接入真实模型或业务数据库。

界面检查按[验收要求](验收.md)执行。PC 布局、鼠标、键盘与原生浏览器缩放分别记录实际结果，等效视口不能代替原生缩放；完整读屏与真实服务仍未验收。技术选型和服务验证边界分别见[前端设计](README.md#前端技术选型)与[后端设计](../backend/README.md#版本基线与验证边界)。
