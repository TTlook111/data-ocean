# 原型状态

当前是离线交互原型，正式前后端重构尚未开始。规则见[设计约定](设计约定.md)，本页只记录已有覆盖和待落实项，不能据菜单存在推断模块完成。

数据访问页面按“数据源＋中文输出限制规则”展示，不设数据授权期限；部门只分配初始访问，角色只控制功能，问数不附加部门记录过滤。原型只维护示例及必要交互，不建设权限计算、规则解释、SQL 校验或审批执行引擎。

## 实现边界与定位

- [登录原型](../../prototypes/app/login.html)、[后台原型](../../prototypes/后台管理/index.html)可独立查看，问数使用[独立工作台](../../prototypes/app/index.html)。
- 行为主要在[后台页面脚本](../../prototypes/后台管理/people.js)、[角色页面](../../prototypes/后台管理/roles.js)、[角色目录与示例](../../prototypes/后台管理/role-data.js)、[审批页面](../../prototypes/后台管理/access-requests.js)、[审批示例](../../prototypes/后台管理/access-request-data.js)、[数据源责任页面](../../prototypes/后台管理/source-approvals.js)、[责任配置与路由](../../prototypes/后台管理/source-approval-data.js)、[规则维护脚本](../../prototypes/后台管理/output-rules.js)和[问数事项卡](../../prototypes/app/case-view.js)。后台修改及角色编辑草稿只留在页面内存，刷新恢复初始示例。
- 规则保存只更新规则列表，不模拟共享规则修改对已有来源的生效策略，也不合并多来源规则；这两项业务决定仍待确认。
- 部门树和成员查看范围用于人员组织管理，不形成业务记录过滤。页面已移除范围推导字段与展示，不进行身份核验、权限计算或真实 SQL 执行。审批只更新示例状态，执行页面待制作，既有生效记录是固定示例。
- 原有办理单据与独立/联合关系由示例预置；新个人申请按已知源生成独立子项，未处理子项根据当前责任配置分派，未知源可核定分流。手动新增拆分、编辑联合组合和申请人需补充后的修改重提仍待制作。修订检查、账号功能资格、本人及负责人限制仅是页面约束，不代表真实权限计算、服务端授权上限、事务或并发校验已实现。
- 问数和后台复用同一份示例人员与数据源目录；问数跳转带入当前问题和已知源，仍需核对提交。已删除旧门店授权与期限模拟；审批不反向改变问数固定结果，真实登录身份、申请记录和问数权限结果尚未接通。
- 问数固定样例只展示业务结果或输出受限卡片，不按“成本”等词一概拦截；未覆盖的条件、口径和数据源明确无示例，不生成假结果，不代表中文规则或 SQL 含义校验已实现。
- 页面可操作不代表真实 API、服务端权限或生产行为已验收。本次未调用业务 API、修改数据库或启动应用服务。
