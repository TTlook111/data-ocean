# 原型状态

当前是离线交互原型，正式前后端重构尚未开始。规则见[设计约定](设计约定.md)，本页只记录已有覆盖和待落实项，不能据菜单存在推断模块完成。

数据访问页面按“数据源＋中文输出限制规则”展示，不设数据授权期限；部门只分配初始访问，角色只控制功能，问数不附加部门记录过滤。原型只维护示例及必要交互，不建设权限计算、规则解释、SQL 校验或审批执行引擎。

## 组件与导航

| 项目 | 当前状态 |

| 账号与当前导航 | 后台整块头像、姓名和部门可打开个人菜单；Esc 关闭并回到触发按钮。进入页面后侧栏当前项滚动到可见位置 |

| 人员详情底栏 | 左侧“更多”，右侧“分配角色”和“编辑人员”，正文保留信息展示 |
| 人员分配角色 | 紧凑弹窗只选择角色名称，较多时可搜索并在列表内滚动；保存前不修改，新增角色可选，重命名同步现有名称引用，停用角色只保留本人既有选择。不设置期限、不展开功能明细、不填分配原因或增加预览步骤；恢复人员也已移除角色期限 |
| 角色编辑与回看 | 页面按已有配置定位，精确页面名优先命中；选择操作同时选择页面访问，取消页面访问移除其普通操作。核对可返回修改，切页暂留草稿，明确取消或保存后清除。成员详情仅表体滚动，查询和分页回退保留 |
| 数据访问展示 | 部门按数据源分组编辑，人员来源按数据源折叠与分页；本人列表直接展示数据源、规则和来源。规则、访问与申请详情统一为固定底栏抽屉，正文保留全文与换行 |
| 共用列表 | 查询采用次级按钮，新增或申请使用主色；字面匹配、稳定排序、空结果和分页共用组件，详情回退保留查询页码 |
| 日期 | 共用日期控件使用 `ElDatePicker`，中文日历与 `YYYY-MM-DD` 格式；人员角色、数据授权与申请不设置期限 |
| 滚动与 PC 布局 | 常规窗口由结果区滚动，极矮窗口由工作区承接；保留常驻侧栏和桌面表格，空间不足由表格横向滚动承接 |

## 实现边界与定位

- [登录原型](../../prototypes/app/login.html)、[后台原型](../../prototypes/后台管理/index.html)可独立查看，问数使用[独立工作台](../../prototypes/app/index.html)。
- 行为主要在[后台页面脚本](../../prototypes/后台管理/people.js)、[角色页面](../../prototypes/后台管理/roles.js)、[角色目录与示例](../../prototypes/后台管理/role-data.js)、[规则维护脚本](../../prototypes/后台管理/output-rules.js)和[问数事项卡](../../prototypes/app/case-view.js)。后台修改及角色编辑草稿只留在页面内存，刷新恢复初始示例。
- 规则保存只更新规则列表，不模拟共享规则修改对已有来源的生效策略，也不合并多来源规则；这两项业务决定仍待确认。
- 部门树和成员查看范围用于人员组织管理，不形成业务记录过滤。页面已移除范围推导字段与展示，不进行身份核验、权限计算或真实 SQL 执行。审批与执行页面仍待制作，既有生效记录是固定示例。
- 问数和后台复用同一份示例人员与数据源目录；问数跳转带入当前问题和已知源，仍需核对提交。已删除旧门店授权、期限及本地审批模拟；真实登录身份、申请记录和问数权限结果尚未接通。
- 问数固定样例只展示业务结果或输出受限卡片，不按“成本”等词一概拦截；未覆盖的条件、口径和数据源明确无示例，不生成假结果，不代表中文规则或 SQL 含义校验已实现。
- 页面可操作不代表真实 API、服务端权限或生产行为已验收。本次未调用业务 API、修改数据库或启动应用服务。

## 当前验证依据

部门配置、访问来源与申请状态等未改动交互保留既有依据：配置、预览和详情无自动部门记录范围，提交待审批不产生访问，组织资料与角色保留；Esc 可关闭详情并返回原入口。规则维护清单本轮未重新做浏览器验收。
