# 原型状态

当前是离线交互原型，正式前后端重构尚未开始。规则见[设计约定](设计约定.md)，本页只记录已有覆盖和待落实项，不能据菜单存在推断模块功能完成。

## 当前覆盖

| 范围 | 状态与边界 |
| --- | --- |
| 登录 | 默认仅展示登录名密码及必要反馈，有首次改密、忘记密码和重新登录示例；显式 `?review=1` 模式提供示例填入，不接真实认证 |
| 总览 Dashboard | 有默认入口与“待制作”占位，不用重复菜单的卡片模拟统计内容 |
| 人员与部门 | 有查询分页、详情、新增编辑、初始密码与重置、角色选择、调岗、成员和子部门迁移、停用恢复及归档示例 |
| 部门成员范围 | 默认含下级并去重，可切换仅直属；配置不隐式继承 |
| 部门初始数据访问与个人角色 | 独立配置：部门选择数据源和范围，展示表行字段限制；个人角色只展示页面、按钮和功能。选择、换源清空范围、多数据源、预览、取消、保存、结束来源与角色变更均有交互示例，互不改写 |
| 业务范围候选生成与确认 | 生成前核对治理版本、确认事实和缺口，只从完整确认的治理子集产生候选；未治理源阻断，相同边界复用已有定义，候选依据变化时不能确认。列表分待核对和已确认，核对采用左右对照，字段区分开放、关联、限制及不开放；确认定位到已确认项，仅新增范围定义。固定示例不代表真实治理或 AI 已接入 |
| 问数 | 保留局部对话、结果和单项申请示例；数据源上下文集中在顶栏，示例标记只在显式评审模式显示，不代表整个问数方案完成 |
| 我的访问范围与我的申请 | 本人范围按来源展示业务含义，有查询分页与详情，约 15 条示例。申请填用途、所需数据范围和期限，已确认范围只作可选参考；可不选数据源提交，不将本人部门预设为开放条件。已有参考范围可按名称和说明搜索，完整性、重复项、日期和说明有校验；业务摘要核对后定位到待审批详情并可撤回，不进入当前访问来源。负责人映射、审批及执行尚未制作 |
| 角色功能、授权执行、申请办理、授权记录、审计及账号信息 | 新后台保留入口并显示待制作 |
| 数据接入、治理对象编辑审核、知识发布、反馈及模型配置 | 保留对应入口与待制作页面；业务范围候选流程的示例不代表真实治理已完成 |

## 组件与导航

| 项目 | 当前状态 |
| --- | --- |
| 人员更多与部门操作 | 使用文字加箭头的 `ElDropdown`；人员保留常用行内动作，低频动作进入菜单，危险动作分隔；Esc 关闭菜单并回到触发按钮 |
| 人员详情底栏 | 管理动作集中在固定底栏：左侧“更多”向上展开，右侧“分配角色”和主要操作“编辑人员”同高对齐；首次登录说明保留在菜单中，不重复前置 |
| 人员详情访问来源 | 按范围明细分页，双行展示业务范围和来源，可用键盘展开业务说明与表行字段限制；不同来源分别保留，不计算有效权限 |
| 共用操作与列表 | 查询采用次级按钮，新增或申请使用主色；表单底栏按钮同高、间距一致，人员、成员和本人列表采用统一字面匹配与稳定排序；结束部门初始访问收进“部门操作”并保留确认 |
| 滚动与规范样张 | 常规 PC 窗口由表格承接记录滚动，极矮窗口改由工作区统一纵向滚动；规范样张使用顶栏面包屑、文字“更多”和 `ElDropdown`，保留空结果及长内容检查 |
| 单日期 | 人员角色、恢复复核、部门数据来源期限和申请期限共用 `ElDatePicker`，中文日历与 `YYYY-MM-DD` 格式；可选期限清空表示长期，回车确认日期不直接提交表单 |
| 顶部层级 | 顶栏使用 `ElBreadcrumb`，真实上级可返回，当前页定位；内容区保留程序化页面名称，不重复显示大标题 |
| 主操作位置 | 新增人员在查询工具栏，新增根部门在组织架构区；部门操作归选中部门，成员、子部门与初始数据访问的整体操作统一放在页签栏右侧，内容区不重复页签标题；切换页面后保留人员查询条件与分页状态 |

这些共用控件已应用于当前人员与部门页面，其他模块仍按上表的覆盖范围制作，不能据此推断全站已统一或完成验收。

## 实现边界与定位

- [登录原型](../../prototypes/app/login.html)与[后台原型](../../prototypes/后台管理/index.html)可以独立查看，问数仍使用[独立工作台](../../prototypes/app/index.html)。
- 主要行为在[后台页面脚本](../../prototypes/后台管理/people.js)、[业务范围脚本](../../prototypes/后台管理/business-scopes.js)和[登录脚本](../../prototypes/app/login.js)，初始人员、部门各约 15 条示例，修改只留在页面内存，刷新恢复。
- 预览、取消和确认用于表达交互；不实现权限计算、真实授权继承、审批执行或认证服务，密码不写入人员示例、预览或本地存储。
- 功能角色、数据源、治理依据及初始范围来自固定示例；业务范围脚本可在当前标签页生成候选并经核对确认后加入可选定义，刷新恢复。原型不调用真实模型，不代表完整角色管理、治理或审批授权已制作；不计算实际有效权限或范围合并。
- 页面交互可用不等于接口、权限或生产行为已验收。需要证据时核对当前源码及相应界面结果；等效视口不能记作真实浏览器缩放验证。
