# 原型状态

当前是离线交互原型，正式前后端重构尚未开始。规则见[设计约定](设计约定.md)，本页只记录已有覆盖和待落实项，不能据菜单存在推断模块完成。

数据访问页面已同步“数据源＋中文输出限制规则”，不设数据授权期限；部门范围按所属部门及组织层级只读展示，角色只控制功能。原型只维护示例及必要交互，不建设权限计算、规则解释、SQL 校验或审批执行引擎。

## 当前覆盖

| 范围 | 状态与边界 |
| --- | --- |
| 登录 | 默认展示登录名密码、必要反馈与“填入示例账号”；有首次改密、忘记密码和重新登录示例，不接真实认证 |
| 总览 Dashboard | 有默认入口与“待制作”占位 |
| 人员与部门 | 有查询分页、详情、新增编辑、初始密码与重置、角色选择、调岗、成员和子部门迁移、停用恢复及归档示例，人员与部门各 15 条 |
| 部门成员范围 | 默认含下级并去重，可切换仅直属；配置不隐式继承 |
| 输出限制规则 | 在“人员与权限”下新增、编辑、搜索及查看名称与完整中文内容；预置三条规则，检查必填与重名，新增后可在部门配置中选用。清单正文最多两行，名称打开详情抽屉，新增后清空遮挡新记录的筛选 |
| 部门初始数据访问 | 每个数据源内直接展示选择与规则全文；顶部展示只读范围和受影响成员。支持多源、移除、预览、返回修改、取消及保存，不显示业务范围模板、表字段勾选或数据授权期限 |
| 人员详情与我的访问范围 | 功能角色与访问来源分开；按来源、数据源回看规则全文及自动识别的部门范围，保留来源停用或待复核状态。本人初始 10 条访问示例，不计算有效权限 |
| 我的申请 | 填需要的数据与业务用途，已知数据源选填；可无数据源核对提交，提交后定位待审批详情，可撤回，不增加当前有效访问。不选业务范围模板、部门范围或授权期限 |
| 问数 | 保留局部对话与结果；数据源上下文在顶栏，“申请访问”跳转后台表单并带入原问题。中文规则匹配、命中重生成和知识阻塞交互尚未制作 |
| 角色功能管理、授权执行、申请办理、授权记录、审计及账号信息 | 保留入口与待制作；本次不增加模拟审批、一键授权或权限引擎 |
| 数据接入、治理对象编辑审核、知识发布、反馈及模型配置 | 保留入口与待制作；治理不再生成授权用业务范围 |

## 组件与导航

| 项目 | 当前状态 |
| --- | --- |
| 顶部层级与操作 | 顶栏使用 `ElBreadcrumb`，内容区不重复大标题；新增和申请在查询区，部门页签整体操作在页签栏右侧 |
| 人员更多与部门操作 | 文字加箭头的 `ElDropdown`；低频动作进入菜单，危险动作分隔并确认，Esc 关闭并返回触发按钮 |
| 人员详情底栏 | 左侧“更多”，右侧“分配角色”和“编辑人员”，正文保留信息展示 |
| 数据访问展示 | 部门按数据源分组编辑，人员来源按数据源折叠与分页；本人共用范围只展示一次，规则、来源和详情动作分开。规则、访问与申请详情统一为固定底栏抽屉，正文保留全文与换行 |
| 共用列表 | 查询采用次级按钮，新增或申请使用主色；字面匹配、稳定排序、空结果和分页共用组件，详情回退保留查询页码 |
| 单日期 | 角色及恢复复核使用 `ElDatePicker`，中文日历与 `YYYY-MM-DD` 格式；数据授权与申请不提供期限 |
| 滚动与 PC 布局 | 常规窗口由结果区滚动，极矮窗口由工作区承接；保留常驻侧栏和桌面表格，空间不足由表格横向滚动承接 |

## 实现边界与定位

- [登录原型](../../prototypes/app/login.html)、[后台原型](../../prototypes/后台管理/index.html)可独立查看，问数使用[独立工作台](../../prototypes/app/index.html)。
- 行为主要在[后台页面脚本](../../prototypes/后台管理/people.js)、[规则维护脚本](../../prototypes/后台管理/output-rules.js)和[问数事项卡](../../prototypes/app/case-view.js)。后台修改只留在页面内存，刷新恢复初始示例。
- 规则保存只更新规则列表，不模拟共享规则修改对已有来源的生效策略，也不合并多来源规则；这两项业务决定仍待确认。
- 部门范围只展开示例组织和只读文案，不进行身份核验、权限计算或业务数据库过滤。审批与执行页面仍待制作，既有生效记录是固定示例。
- 问数和后台仍使用各自固定示例账号；问数跳转只带入问题文本，真实统一身份、申请记录和问数权限结果尚未接通。存量问数审批模拟代码不作为新版产品规则或验证依据。
- 页面可操作不代表真实 API、服务端权限或生产行为已验收。本次未调用业务 API、修改数据库或启动应用服务。
