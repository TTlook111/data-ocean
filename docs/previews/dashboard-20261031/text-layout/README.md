# 工作台布局样稿：任务文字版

**设计预览，非正式工作台；全部为合成演示数据，不代表真实业务指标。**

保留暖白、墨色与铜橙，采用顶部概况横带、主任务区与右侧辅助区。本目录保留此版，供后续图表版对比；没有修改正式Dashboard或菜单。

- [桌面完整截图](desktop.png)：浏览器视口1280×720，完整页面图片1280×868。
- [390px完整截图](mobile.png)：浏览器视口390×844，完整页面图片390×1484。
- [自包含HTML](index.html)：GitHub通常展示HTML源码；请下载文件后，用本地浏览器打开。无需安装依赖或连接网络。

HTML可切换正常、空、失败、部分未知、无权限等演示场景，支持待办筛选、准备维度展开和只读去向预览。全部交互在本地模拟，不请求后端、模型，不写入业务数据。演示控件不代表新增产品能力。

菜单按当前配置：**数据资产（一级）→关系与影响（分组标题）→数据血缘（二级）**，路由为`/admin/assets/lineage`。工作台不常驻展开其他域的二级项。

图标来自Lucide，ISC/MIT许可已嵌入HTML；Logo沿用本仓库品牌资产。
