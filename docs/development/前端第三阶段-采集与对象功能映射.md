# 第三阶段：采集与数据对象功能映射

起点为 `95c4b69fa5edefc11522564fe01547fc66575279`，独立分支 `feat/frontend-conversation-v2-20261029`。仅前端及验收文档；不改变 Java API、数据库、IAM 或快照发布规则。

| 原功能 / 正式入口 | 页面组织与保留能力 | 合同 / 源码 |
| --- | --- | --- |
| `/admin/collections` 任务 | 读取结构→独立快照→治理审核的职责说明；范围、服务端分页、状态进度、时间错误、轮询、重试、结果版本入口 | `SyncTask.vue`；查看 `metadata:collect:view`，执行 `metadata:collect:run`，各按同一绑定目标源 |
| 发起全量采集 | 当前有执行权的源；统计默认关闭，可开启；提交中禁重复，返回任务编号；有查看权时定位该源，无查看权时交接说明 | `triggerSync`；前端当前页运行任务仅作提醒，后台仍裁决并发；重试创建新任务，无恢复/取消接口 |
| `?tab=schedule` 同步计划 | 每日、每周、自定义 Cron；保存/未保存预览；全局作用说明；只读账号清楚显示 | `SyncSchedule.vue`；GET 按采集查看，PUT 还要求受保护系统管理员；`running` 仅为调度已注册 |
| `/admin/assets` 正式目录 | 已发布对象与快照结构分开；表/字段、搜索、完整路径复制/展开、对象版本、目录同步状态、详情与返回位置 | `AssetsView.vue`；仅 `metadata:view`，不新增 datasource/readiness 依赖；列表搜索为已返回集合内过滤，无伪服务器分页 |
| `?view=tables&snapshotId=…` | 精确历史快照、表搜索、字段顺序、主键/可空、治理状态、行数估算/统计缺失 | `TableExplorer.vue`；首批50条外精确读取；失败不回退最新版；列表重试须恢复结构读取 |
| `/admin/assets/entities/:entityId` | 阅读优先，维护与复制归入对象上下文；字段、术语、标签治理、所属引用、血缘、下游及原始技术信息保留 | `AssetEntityDetailView.vue`；来源与发布目标分开；关联区 `FORBIDDEN/ERROR/UNAVAILABLE` 不转零 |
| 字段/状态/血缘入口 | 保留精确来源与目标区能力核验 | 字段解释传 `datasourceId + sourceSnapshot + tableName + columnMetaId`；血缘传 `datasourceId + entityId`，不能互换 |

公共保护：换源、换账号、能力摘要变化、卸载时失效旧读取/错误/finally；写请求固定发起时对象，确认后重核身份及能力；只关闭本页拥有的确认框。页面不自动发布、不自动构建 RAG，不将任务成功认定为业务正确。

执行顺序：先采集任务及全局计划作为可回滚小批，再目录/结构/详情作为第二小批。验收使用真实 Vue 与 Chromium、合成 API；真实 Java/采集器/数据库验证待具备已核验环境后补做。独立审查和实际结果见第三阶段验收记录。
