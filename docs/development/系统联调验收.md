# 当前版本系统联调验收

> 整理日期：2026-11-01。本页维护可复用的验收合同、覆盖方式和复跑入口。每次执行固定自己的提交与环境，实际成绩从[验收索引](../acceptance/README.md)读取；不沿用某轮旧基线或浏览器阻塞状态作为当前结论。

## 正确性合同

1. 审核身份、来源修订、发布版本和显式 RAG build 分开记录。草稿、未审核或来源失效的知识不能成为回答依据。
2. 查询始终受当前 S1 功能、独立数据授权、表字段和行条件限制；后台管理另需同一绑定提供功能及负责源，不能跨绑定拼接。系统管理员的管理能力不替代数据授权。隐藏字段禁止使用，脱敏字段不得用于间接推断。
3. 任务固定 build、来源快照和精确审核引用。授权、执行、保护、完成逐阶段重验；来源撤回后不切换到另一版本继续执行。
4. 合成口径以入口题集为准：一行一订单；订单多对一关联唯一商品；完成状态 COMPLETED；金额 SUM(quantity*unit_price)；年界半开区间。真实业务没有确认的成本、利润、税费含义不由测试脚本决定。
5. 同 task/attemptId/原 SQL hash 只对应一次受保护执行；重试、取消和恢复共享预算，不能重复执行、投影或计分。
6. SQL 的实际表、所有用途字段、输出来源与结果相符。COUNT(*) 的授权锚点不是实际使用字段。空结果可以是正确答案，但必须有真实执行、列结构和来源证据，不能用缺失数据冒充空集。
7. 反馈依据实际使用字段与当时固定修订归因。新修订通过后还需原情景复核，不能靠旧版本得分或模型自述结案。
8. 用户问题、数据库注释和知识正文是数据，不能修改权限、审核要求和只读 SQL 边界。提示词不是权限执行机制。

| 语义中心：知识文档/RAG | 分篇与整组覆盖；显式 build；失败保留活动指针 | 真实发布、新 build、MySQL/Milvus；合同测试 | 大规模、长期在途替换及所有故障窗口 |

| 查询审计、血缘和影响 | 提交后投影、同尝试/hash、实际来源、去重 | 获准的真实进程终止、MySQL 未提交表/列血缘回滚与恢复唯一投影；接口/图及独立复核 | 数据库服务崩溃、存储故障、所有图交互和未知旧集合 |
| 问数反馈、使用档案 | 真实字段、修订绑定、去重、反馈修订与原题 | 真实反馈流程单列；H2 事务与反例 | 真实业务人员采纳和评分校准 |
| 运营与平台：Prompt、AI 配置、日志、监控 | 固定场景合同、无密钥输出、异常分类 | 配置白名单只读、API 冒烟、专项隔离测试 | 全九场景模型质量、真实告警历史 |
| 后台调度与恢复任务 | 专用执行器、领取令牌、幂等和有界恢复 | 按故障脚本分别记录获准窗口、非空列投影、后台恢复领取及离线反例 | 未触发的定时任务、基础设施故障及其他崩溃窗口 |
| 恶意知识与问题 | 不提升指令等级、不跨源、不写库、未审内容不入 build | 实际注释/已审释义暴露、正向查询、写操作拒绝和草稿 membership 核对 | 任意注入载荷、外部文档格式与所有模型行为 |

实际菜单以 `frontend/src/router/adminDomains.ts` / `adminNavigation.ts` 为准；[入口脚本](../../scripts/system-acceptance/acceptance.py)的 inventory 输出全部 Controller 映射位置、后台 @Scheduled 位置及前端路径。它是静态盘点，不等于这些端点全部实测。每次运行应保存请求明细、角色、版本与结果，再与本表对照。

## 入口与证据

复跑使用 [脚本说明](../../scripts/system-acceptance/README.md)。先 inventory/preflight/oracle，再明确执行 fields/business/publish/build/questions；不自动安装、供应基础设施或执行数据库迁移。

每轮证据应记录提交与工作树差异、当前进程、目标库版本、模型名称、build、题目及其独立预期。完整闭环关联字段修订、业务修订、文档版本、build、任务、执行尝试、SQL 摘要、受保护结果、来源与反馈。通过、失败、跳过、阻塞分别列示；模拟/H2 与真实服务分开。浏览器截图进入 `output/playwright/`，运行日志、备份与临时凭据只放本机环境约定的仓库外目录。

家庭核心链路的实际版本、各窗口任务与限制见[扩展记录](../archive/2026-10-29-扩展联调.md)；后续办公室、独立云端与前端各轮结果由[验收索引](../acceptance/README.md)定位。表中列的是所需证据，不代表已全部执行；未实际操作的项目明确记为未测或阻塞，不能由 API、Mock 或旧环境通过推定。
