## 已知工程风险

1. `LogActionAspect` 已默认关闭参数日志；后续若显式启用，应先建立统一敏感字段脱敏策略。
2. 前端当前没有 Vitest 测试；新增或改动关键查询页面时应优先补测试。
3. 前端构建有大包告警；将 ECharts 和血缘可视化按路由拆包。
4. Python 测试仍报告 Redis 客户端 `retry_on_timeout` 的弃用警告。

## 当前开发顺序

1. 安全收口：日志敏感字段脱敏、标识符白名单校验。
2. P9 告警真实执行：定时评估、告警历史、恢复和去重。
3. P10 配额真实执行：用户、部门、数据源和月度成本取最严格限制。
4. P12 管理端闭环：告警规则/历史与配额策略页面。
5. 测试与性能：查询链路集成测试、前端关键交互测试、前端大包拆分。

## 维护规则

- 每次合并功能后更新本文档的“功能状态、验证状态、主要待办”。
- 只有构建和相应测试通过，模块才能标记为“验证通过”。
- `AGENTS.md` 记录协作约束和稳定架构事实；本文档记录会变化的项目状态。
