- 问数体验工作台已读取真实任务时长、状态和当前有效赞踩。独立答案抽检仍缺按原题、业务预期及获授权结果核对的正式样本来源；该指标当前显示待接入。10 秒是工作台的回答等候目标，真实用户屏幕首次呈现时刻仍需专门采集。[工作台指标](../modules/010-platform-operations.md#工作台与告警配置)
- 恢复 DashScope 连接，再验证新的成功问数及独立预期结果。目前代理/直连均在 TLS 阶段 EOF，不能据此推断 Key 或额度。
- 补验证供应商/SQL 实际停止、强杀窗口、响应丢失、多客户端竞争及真实摘要模型。取消持久化、UI 回执、正常 Java 重启补投和会话 415 回读已有[证据](../acceptance/2026-11-06-全站重设计与基础整治.md#v75-与取消交付)，旧长期摘要未批量修正。
- 用可独立计算预期的样例补用途/粒度、指标公式/单位、关系基数；覆盖同库多表、聚合重复计数、多轮上下文、复杂日期和缺口澄清。验证必要关系撤回、JOIN usage 收紧及同名对象隔离，不能从问题或 AMOUNT 标签猜业务口径。
- 验证模型规划偶发无关关系、用途误拒和原题安全重试的稳定性；校准政策 2 参考分及规范化 SQL 样例。修订复查与原反馈情景 VERIFIED 分开，未经审核的历史 SQL 或 JOIN_PATH 不能直接进入可信知识。
- 真实 RAG 补在途引用下替换、来源撤回、历史 build 资格、完整文档组覆盖/hash 与指针切换；旧 ACTIVE 不能证明未知构建成功。
- 如需补云端无模型环境的检索/问数/恢复/CSV/血缘/反馈验收，先核对模型与 Embedding 授权、向量依赖、数据授权及 Java 冷启动配置同步；不跨机器搬凭据或默认产生外部费用。

## 后端待确认合同

[静态问题证据](../acceptance/2026-10-30-前端终验待确认后端问题.md)不是所有问题当前仍可复现的证明。修改前先核对现行实现与真实行为：

- 全局通知采用共享还是每用户独立已读，需双账号核对。
- IAM 字段保护、他人有效权限及最小治理角色的辅助目录合同；保留合法主读取，不扩大辅助授权。
- 普通用户维护者与管理账号的目标隔离，需可信目标类别及服务端 guard，不能猜用户名或旧角色数组。
- 主部门/父部门清空的 NOT_NULL 风险、部门默认启用，以及用户/角色/策略/候选缺客户端 CAS 的竞争窗。未解决前不开放清空已有值，预读或前端锁不是原子保障。
- Chat 保存对 Embedding pending、全局切换链、维度检测 provider 归属、Provider upsert、多步配置写入的并发和部分失败合同。
- 反馈 DTO 缺逐行 datasourceId、approve/reject 先读后更新且缺客户端版本条件。保留全授权源合并读取与服务端逐条授权，验证多管理员竞争。
