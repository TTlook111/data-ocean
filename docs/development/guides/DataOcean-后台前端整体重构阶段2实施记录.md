# DataOcean 后台前端整体重构：阶段 2 实施记录

## 本次范围

阶段 2：数据接入。

本次只修改前端，不修改 Java、Python、数据库、权限码和后端 API URL。

## 已落地

- 新建数据源工作区 DataSourcesView.vue：
  - 数据源列表、名称和状态筛选。
  - 新建、编辑、删除和启停。
  - 新建保存前必须测试连接成功。
  - 编辑连接配置变化后必须重新测试。
  - 创建成功后进入 /admin/data-sources/:id。
- 新建数据源驾驶舱 DataSourceDetailView.vue：
  - 使用数据源详情和 readiness 接口。
  - 展示连接、采集、治理、快照发布、知识发布、授权和可问数流程。
  - 根据服务端 readiness 只突出当前主要动作。
  - 展示阻断原因、最近快照、采集任务、治理问题和最近活动。
- 新建采集任务工作区 CollectionsView.vue：
  - 合并采集任务和同步计划。
  - 使用 tab 查询参数恢复工作区。
  - 保留 datasourceId 范围参数。
- 新目标路由已切换到上述页面：
  - /admin/data-sources
  - /admin/data-sources/:id
  - /admin/collections
- 旧采集任务初始化异常已收敛到页面错误提示，不再冒泡为全局未捕获异常。

## 验证

- 浏览器已验证：
