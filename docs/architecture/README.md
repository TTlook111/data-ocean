## 已定选择与待定事项

- 正式前端已选择 React；原型继续使用现有依赖。组件体系及其他前端选择归[前端设计](../frontend/README.md#前端技术选型)。
- 后端技术栈、服务边界、持久存储、任务执行和状态恢复、接口契约、部署与运维方式尚未确定，范围见[后端设计](../backend/README.md)。
- 方案里的逻辑对象、字段和技术参考用于说明设计输入，不是物理建表、框架选型或服务拓扑。正式架构应明确选用什么、用途、必要理由和约束；不沿用旧系统技术作为默认答案。
- 架构评估时需明确代表性数据规模、并发与响应目标、模型部署及信息发送边界、任务和历史保留、故障恢复要求。已确认业务约束直接沿用；尚无依据的具体数值列为待确认输入，不把示例预算或旧系统实测当作新系统承诺。
