# D 批首个事项接口

新版知识入口在 Java。通用响应、字符串标识、分页、命令查询和错误码继承[公共契约](../../architecture/接口与事件契约.md)。下表是首轮实施契约，实测状态见[验收](验收.md)。所有可写请求带 Idempotency-Key，编辑请求还带预计聚合版本。服务端从会话和真实记录取得身份、版本、来源及授权。

当前实现包括事实选项、文档草稿和确认、标准题保存和审核、准备任务、真实索引构建、逐题验证、人工裁定、正式发布及版本回读。规划和回退按下表的契约继续接入。

## 知识文档

以下路径以 /api/v1/knowledge/sources/{sourceId} 为前缀。权限以现有 IAM 目录为准。任何文档、题目或发布候选只能通过所属源读取。

| 方法与路径 | 请求和成功回执 | 核权及写入 |
| --- | --- | --- |
| GET /facts | 对象编号、关键词、分页。返回可引用的 C 批确认身份、内容修订、结构修订、依赖与当前状态 | knowledge.view。原文按现有资料权限裁剪 |
| POST /plans | 目标、主动事实身份。返回任务和本次规划摘要 | knowledge.generate。按当前源获准资料与确认版本固定规划输入，规划不创建文档 |
| POST /documents | 核对后的规划或人工范围和初稿。返回文档编号、修订及版本 | 从规划生成要求 knowledge.generate；人工创建和编辑要求 knowledge.edit。固定引用并保存草稿 |
| GET /documents | 关键词、状态、分页 | knowledge.view。显示草稿、已确认、需复核及已发布的实际状态 |
| GET /documents/{id} | 可指定 revisionId，返回正文、章节引用、差异提示及修订列表 | knowledge.view。按同源及证据权限读取 |
| PUT /documents/{id}/draft | expectedVersion、标题、用途、边界、代表性问题、章节及事实身份 | knowledge.edit。保存不可变新修订；更新实际变更的依赖 |
| POST /documents/{id}/confirmations | expectedVersion、revisionId | knowledge.confirm。只确认已保存的当前修订，逐项核对依赖和必要内容。通过后记录操作者、时间和确切修订 |

事实引用由项目现有治理目标与固定修订组合表达，浏览器不传确认者、正文证据来源或结构快照身份充当权威值。章节引用须属于实际文档范围。

## 标准题单

| 方法与路径 | 请求和成功回执 | 核权及写入 |
| --- | --- | --- |
| GET /test-cases | 文档、查询、待审状态和分页 | test-cases.view。支持当前候选相关题的固定修订视图 |
| POST /test-cases | 文档、问题、覆盖点、判定方式、预期、数据依据和执行条件 | test-cases.edit。允许保存不完整草稿 |
| PUT /test-cases/{id}/draft | expectedVersion 与草稿内容 | test-cases.edit。编辑产生新修订 |
| POST /test-cases/{id}/reviews | expectedVersion、revisionId | test-cases.review。预期、判定方式、数据依据和所需执行条件齐全才可审核 |
| POST /releases/{id}/validations/{runId}/results/{resultId}/judgment | expectedVersion、决定、理由 | test-cases.judge。须有实际证据查看权，只裁定当前候选的待裁定结果 |

自动数值题固定实际治理指标、维度、条件、单位和比较规则；技术执行结果和预期独立存储。说明题需实际技术输出和来源证据才进入人工裁定。明确失败和执行异常均由修复后重跑。

## 发布与版本

| 方法与路径 | 请求和成功回执 | 核权及写入 |
| --- | --- | --- |
| GET /release-preflight?documentId=… | 返回文档就绪状态、确认标题和修订、当前生效绑定、审核题数量、向量配置修订、阻断项及就绪时的 `inputFingerprint` | releases.view。预检摘要涵盖确认文档、审核题修订、向量配置和当前基础绑定 |
| GET /release-preflight/document-options | 按 `keyword` 和分页查询当前源确认标题 | releases.view。搜索词按字面匹配确认正文，草稿名称变更不影响选项 |
| GET /releases | 当前源的发布任务。可按 `documentId`、`keyword`、`status` 和分页查询 | releases.view。发布编号按字面查找，任务返回目标修订、可选候选编号和阶段 |
| GET /releases/{id} | 返回任务、目标修订、实时构建前置、当前候选构建记录和已替换候选的原修订及构建 | releases.view。候选关联后回读固定题数，构建成功显示回读片段数和向量维数 |
| GET /releases/{id}/events | 当前合法连接接收 `knowledge-build.updated` 阶段快照 | releases.view。重连回放实际状态，详情 GET 随时可用 |
| POST /releases | `documentId`、`documentRevisionId`，返回已保存任务的命令回执 | releases.build。校验同源确认及治理依据，缺少题单或向量配置仍可保存准备任务 |
| POST /releases/{id}/scope-adjustments | `expectedVersion`、`documentId`、`documentRevisionId` | releases.build 和 releases.view。准备中、构建失败或待验证的任务可更新同源单文档范围。变更后递增原任务版本并回到准备中，旧候选及构建仍归属原任务。重试沿用原命令编号 |
| POST /releases/{id}/builds | `expectedVersion`、`fingerprint`，HTTP 202 返回构建命令回执和代次 | releases.build。首建使用详情的预检摘要，来源锁内重验并原子冻结候选、固定题单与片段。重试提交候选摘要，沿用原候选并创建新代次 |
| POST /releases/{id}/cancellations | `expectedVersion`、`reason`，已有候选时需提交其 `fingerprint` | releases.build。取消未生效任务及在途尝试，后续领取和迟到回执按实际状态阻断 |
| GET /releases/{id}/validations | 可通过 `runId` 回看历史运行。返回该次结果、获准的原片段及裁定 | releases.view。逐题内容还须具备标准题查看权限及本人当前适用的源授权。候选原文及裁定依据还需 knowledge.view |
| POST /releases/{id}/validations | `expectedVersion`、`buildId`，返回 HTTP 202 与运行编号 | releases.test。成功构建后自动创建首次运行，手动重测生成新运行并保留历史 |
| POST /releases/{id}/impact-preview | `action=PUBLISH`、`expectedVersion`。返回范围、基础与目标修订、构建、验证和核对凭据 | releases.publish。核对当前权利、来源、固定依赖、基础版本、逐题结果及真实索引 |
| POST /releases/{id}/publish | `expectedVersion`、`reviewToken`。回执绑定本次实际版本编号 | releases.publish。事务内复核并切换整批权威指针，记录审计及 Outbox。原命令可回读提交事实 |
| GET /releases/{id}/publication | 本次发布、实际当前生效及本次直接上一版 | releases.view。切换后结果与当前可用性分别回读 |
| POST /releases/{id}/reconciliations | `expectedVersion`、原核实命令编号 | 核实沿用发布所需的当前动作、正文和来源权限。核对实际指针与同版索引，保留原绑定 |
| GET /bindings | 可按 `scopeId`、文档名、来源对象、可用性和分页读取当前生效 | releases.view。仅查询 MySQL 生效指针上的版本，可用性按实时复核结果筛选后分页 |
| GET /bindings/{id} | 返回所选绑定、直接上一版及获准的确切正文 | releases.view。完整正文还须有知识文档查看权限及本人源授权 |
| GET /bindings/{id}/controls | 暂停范围和原因、恢复状态及办理记录 | releases.view、knowledge.view 和本人源授权 |
| POST /bindings/{id}/pauses | `reason`，返回暂停记录 | versions.pause，另核对页面、正文及本人源授权。保留原生效绑定，限制独立于发布版本 |
| POST /bindings/{id}/pauses/{pause}/runs | 返回 HTTP 202 与隔离验证运行 | releases.test，另核对证据访问和本人源授权。固定当前绑定及同一正文的已审核题单 |
| GET /bindings/{id}/recovery/{run} | 返回指定隔离运行、实际逐题结果及可裁定状态 | releases.view、knowledge.view 和本人源授权。逐题证据仍按查看者权限裁剪 |
| POST /bindings/{id}/pauses/{pause}/restore | `runId`、`reason`，返回原暂停的解除回执 | governance.allow，另核对本人证据访问。重新核对绑定、权限、题单、治理依据和实际索引 |
| GET /bindings/{id}/query-use | 核对指定正式知识的实时问数使用资格 | query.view、query.ask 和本人源授权。受限、过期或不同源的绑定拒绝参与 |
| POST /releases/{id}/rollback | expectedVersion、reviewToken、原因 | 按回退权限核对当前与直接上一版，提交完整回退；继续执行当前风险限制 |

版本冲突和指纹差异返回 409；过期依赖使用 409301；题单或索引未就绪使用 409302。Python 内部接收固定候选和运行代次，回写使用内部服务鉴权和当前执行条件；不接受浏览器会话、数据库凭据、原始 SQL 或任意索引端点。
