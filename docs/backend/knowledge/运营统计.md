# 知识概览与对账

页面与交互见[知识概览](../../frontend/pages/dashboard.md#正式知识概览)。可用性沿用[知识版本与索引规则](../../architecture/知识版本与索引一致性.md)。

| 只读接口 | 权限 | 返回 |
| --- | --- | --- |
| `GET /api/v1/knowledge/overview` | `knowledge-dashboard.view` | 来源、截止时刻、趋势分组和全期间汇总 |
| `GET /api/v1/knowledge/overview/details` | 看板权限与归属页面查看权 | 对账分页，可定位原文档修订、发布任务或验证轮次 |

后台沿用现有来源统计范围和共用期间规则。默认近 30 个北京时间业务日，按日、自然周或月分组。下钻使用原 `sourceId`、`fromDate`、`toDate`、`timeZone` 和 `asOf`。文档类指标还要求 `knowledge.view`，发布、验证指标还要求 `releases.view`。

| 读数 | 事实与口径 |
| --- | --- |
| 期末可用正式文档 | 每个文档的正式范围只计一次。先按发布、回退和撤下重建各期末生效绑定，再核实实际索引回读、暂停、禁止、模型和冻结依赖 |
| 成功生效批次 | 按批次实际核实时间统计。同批多文档计一批 |
| 验证未通过、执行错误 | 候选验证按原轮次发起日期归组，每轮每题有一条原结果。按截止时刻已有的结果或人工裁定分类，失权和条件失效仍保留独立状态 |
| 待更新 | 截至期末存在比正式修订更新的正文 |
| 暂停、禁止使用 | 暂停按原范围的暂停与恢复时段统计，禁止按冻结引用命中的治理限制事件统计。维护分类可重叠 |

当前可用性沿用正式问数的版本和来源门禁。历史回放使用绑定切换及限制的已记录时点。源结构或治理事实在期末之后已改变时，缺少原证据的可用性读数留空。明确的暂停、禁止、模型停用和依赖失配仍可确定当时不可用。有空缺的可用性窗口无完整下钻。

V52 为模型启停追加生效时点。旧模型版本数与配置修订数一致且当前仍启用时，可以证明其沿用了首次启用；其余旧模型从迁移观察时刻起有状态证据。逐题结果记录实际写入时刻，旧结果保存迁移观察时间；人工裁定保留原来的确切时刻。

隔离 MySQL 实际迁移和接口验收覆盖模型停用恢复、版本暂停及相应历史截止点。受控台账回放覆盖多文档发布批次、回退、撤下、逐题分类与维护状态重叠。接口另外核对来源筛选、分页、长期间分组和同一会话权限撤销。[接口与验收证据](../../../output/playwright/2026-11-23-knowledge-overview/report.md)
