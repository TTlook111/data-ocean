# D 批首个事项验收

使用隔离平台 MySQL、合成商品源、原有 Redis 和独立命名的 Milvus 代次。确认两种商品属于同一测试分类，其中一种有两条展示记录。两种商品都是事先准备的合成事实。把期望值写入审核题单，实际结果独立运行。

## 当前实测

- 隔离库从 V57 迁移至 V58，在节点列表单独为「标准题建议」分配千问。以一份已确认库存文档生成五道建议，逐题采纳后仍为草稿，补齐独立判定依据后审核首道说明题。实测未分配模型、旧文档修订、越界采纳与无依据审核被拒，重复命令沿用原草稿。刷新续看未重复外发，调用记录、配置修订及 Token 用量已对账。ego-lite 覆盖键盘、两种桌面宽度及 125%／150% 原生缩放。[任务与审核对账](../../../output/acceptance/2026-11-24-test-suggestions/review-and-model.json) · [采纳校验](../../../output/acceptance/2026-11-24-test-suggestions/adoption.json) · [候选题界面](../../../output/playwright/2026-11-24-test-suggestions/candidates-1024.png)

- 隔离库存源用千问实测数据源规划、正文生成、保存草稿、人工编辑及确认修订。已有文档逐节采纳后保留未选人工正文和历史修订，原命令重试未重复写入，越界依据及错误规划归属被拒。未选章节的治理确认变化时，采纳被拒，原修订保持。正文请求的模型修订和 Token 用量可从模型运行概览和调用明细对账。ego-lite 已核对两个桌面宽度、125%／150% 原生缩放和键盘入口。[确认与调用对账](../../../output/acceptance/2026-11-24-document-write/confirmation-and-usage.json) · [更新接口](../../../output/acceptance/2026-11-24-document-write/update.json) · [保留依据复验](../../../output/acceptance/2026-11-24-document-write/retained-basis.json) · [更新差异页面](../../../output/playwright/2026-11-24-document-write/difference-1024.png)

- 隔离库补验首版无直接上一版时整批回退无确认凭据。仅有回看权限的同源人员提交回退返回 403，跨来源回看被拒。两个并行回退请求只有一个提交成功，同命令重试返回同一回执。两个实际指针均恢复到原 r1，版本入口回读同一条回退记录。合成向量在隔离 Worker 回放，MySQL 和 Milvus 读写为真实运行。[收尾复验](../../../output/acceptance/2026-11-21-d-closeout/k11-closeout.json)

- 两份具有显式引用的合成文档整批发布两次。从浏览器把 r2 批次回退到直接上一版 r1，实测核对匹配索引、保留范围暂停和对象禁止、回读全部实际指针及原审计。r1 重新生效后，曾从旧入口构建的候选仍被阻断。另一个批次的一份文档单独发布到 r3 后，旧回退提交返回 409301，两个指针保持 r3 和 r2。[正常回退](../../../output/acceptance/2026-11-21-knowledge-batch-rollback/normal.json) · [成员替换阻断](../../../output/acceptance/2026-11-21-knowledge-batch-rollback/blocked.json)

- 撤下验收通过正式接口发布目标、直接和间接引用方及共享事实的独立文档。弹窗打开后再发布一个引用方，旧清单返回 409002，重核后四份正式知识同时撤下。历史正文仍可读，受影响绑定的问数使用检查拒绝，独立文档继续可用。单独处理来源事项的两份合成知识时，首份退出后仍处于知识处理中，最后一份退出才回写完成。[接口证据](../../../output/acceptance/2026-11-21-knowledge-withdrawal/api.json) · [浏览器证据](../../../output/playwright/2026-11-21-knowledge-withdrawal/browser.json) · [来源回写](../../../output/acceptance/2026-11-21-knowledge-withdrawal/source-completed.json)

- 生效版本 r2 实测暂停、隔离验证、题单改审使旧结果失效及显式恢复。暂停期间问数使用检查拒绝 r2，同源其他版本继续可用。数值题由只读 MySQL 查得 2，说明题查看 Milvus 召回证据后人工裁定。向量服务超时的实际运行保留暂停，后续正向场景在隔离 Worker 回放合成索引已存向量。问数对话与在途执行尚未接入，验收覆盖后端正式知识使用检查。[接口证据](../../../output/acceptance/2026-11-21-version-recovery/api.json) · [浏览器证据](../../../output/playwright/2026-11-21-version-recovery/browser.json)

- 隔离平台的真实文档接口覆盖同源确认、四类治理引用、必要依赖补齐、防重、过期写入、历史回读和越界拒绝。旧依据被 C 批修改时，确认需重新核对。见[文档接口](../../../output/acceptance/2026-11-20-d-knowledge/documents-api.json)和[权限与过期依据](../../../output/acceptance/2026-11-20-d-knowledge/permission-stale-api.json)。
- 商品事项的数值题与说明题已审核。发布准备按实际确认修订读取两道审核题，并披露来源未启用、目录需核对或缺少向量配置等阻断。样例自身有三条展示记录及两种不同商品，样例查核与候选运行分别取证。见[题单与发布准备接口](../../../output/acceptance/2026-11-20-d-knowledge/tests-preflight-api.json)和[隔离环境复验](../../../output/acceptance/2026-11-20-d-approval/approved-api.json)。
- ego-lite 通过文档创建、保存、确认和回读依据，以及题目编辑、重新审核和发布准备检查。见[1024px 文档依据](../../../output/playwright/2026-11-20-d-knowledge/documents-confirmed-1024.png)和[发布准备](../../../output/playwright/2026-11-20-d-knowledge/release-preflight-1024.png)。
- 文档规划和生成节点已在隔离库分配。向量配置通过真实 Embedding 探测，合成商品候选使用 1024 维向量构建独立 Milvus 代次。Strong 回读与 MySQL 的完整章节、边界和七项治理引用一致，代表性问题命中同版索引。见[向量连接](../../../output/acceptance/2026-11-20-k04/embedding-probe.json)及[存储对账](../../../output/acceptance/2026-11-20-k04/strong-readback.json)。
- 缺题时可保存准备任务，直接构建被拒绝。补齐两道审核题后回到同一任务，首次构建才关联候选并冻结输入。重复命令返回同一构建代次，原候选历史仍可回读。见[构建前接口](../../../output/acceptance/2026-11-21-release-task/before-build.json)、[首建结果](../../../output/acceptance/2026-11-21-release-task/result.json)及[桌面交互](../../../output/playwright/2026-11-21-release-task/browser.json)。
- 原任务可改用同一文档的最新确认或替换为另一份同源文档。隔离实测 r1 调整到 r2 后回到准备中，旧修订和构建可在历史候选回读，补齐审核题后新候选完成真实索引构建。构建中拒绝调整，旧任务版本和旧文档修订均被拒绝。见[调整接口](../../../output/acceptance/2026-11-21-release-scope/adjusted.json)、[实际构建](../../../output/acceptance/2026-11-21-release-scope/rebuilt.json)和[同源替换](../../../output/acceptance/2026-11-21-release-scope/replaced.json)。
- 合成商品候选构建后自动跑两道已审核题。只读 MySQL 去重查询实得 2，说明题实际命中同版片段，浏览器阅读证据后提交裁定并进入待发布。另以预期 3 验证明确失败，接口拒绝改判及裁定旧运行，重测保留历史。见[自动运行](../../../output/acceptance/2026-11-21-release-validation/automatic-run.json)、[人工裁定](../../../output/acceptance/2026-11-21-release-validation/judged.json)和[失败及重测](../../../output/acceptance/2026-11-21-release-validation/failure-and-retry.json)。

## 验收用例

| 场景 | 通过条件 |
| --- | --- |
| K01 同源范围和依赖 | 以 PC 实际创建商品文档草稿。精确回读表与字段、关联、指标、实际修订和自动纳入的依赖。跨源身份或未确认条目退回 |
| K02 草稿确认和失效 | 保存正文后确认。重复提交复用原回执；并发编辑保留先提交的修订。确切的 C 批依据变更能定位相应文档，旧候选不能发布 |
| K03 标准题审核 | 数值题独立给出期望 2；说明题包含判定依据。草稿、无相关题或缺少必要覆盖时阻断构建或发布，页面能定位办理 |
| K04 实际构建 | Python 用当前固定配置构建独立 Milvus 代次。Strong 读取命中同一候选，返回完整条件和同版治理证据。构建失败或迟到结果保留现行入口 |
| K05 自动验证和人工裁定 | 实际去重查询得到 2。说明题给出实际结果及依据，待裁定时阻断，裁定后方可发布。明确失败和异常只能修复后重跑 |
| K06 真实切换 | 先发布首版，再从同一基础版发起两个候选。兼容产物就绪且检查通过的候选才可切换。下一候选因基础版过期阻断；同键重试只生效一次。实际 MySQL/Milvus 读取的绑定、片段和事实一致 |
| K07 故障与回退 | 构建失败旧版不变；切换回包丢失查询原命令。实际回退到直接上一版，缺必要匹配索引或受当前禁止影响时给出阻断。正常回退不解除任何仍有效的限制 |
| K08 权限和桌面操作 | 分别核对文档、题单、构建、裁定、发布和回退权限。跑通 PC 的来源定位、提交后回读、失败处理与返回。浏览器证据记录视口和操作结果 |
| K09 暂停与恢复验证 | 暂停保留生效绑定，指定知识的问数使用检查被拒，同源无关版本仍可使用。隔离测试通过后仍暂停，题单或验证依据变化拒绝旧结果，只有授权人员显式提交依据后才能恢复 |
| K10 撤下及依赖范围 | 清单逐条展示目标、直接和间接引用方。打开确认后新增实际引用，旧凭据失败且原状态不变。整批退出后保留历史，独立共享文档正常使用，全部必要知识办理完成后才回写来源 |
| K11 多文档发布及整批回退 | 同批固定全部正式绑定和依赖，回退预检要求每项直接上一版通过，指针一次切换。确认实际匹配索引后才恢复普通使用检查，暂停和禁止保留。任一成员已被后续发布替换则整批不写入 |

当前状态以实际接口、存储记录和浏览器证据为准。
