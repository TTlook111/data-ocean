# 接入概览与对账

页面与筛选见[接入概览](../../frontend/pages/dashboard.md#正式接入概览)，业务定义见[运营看板方案](../../product/modules/08-dashboard.md)。

| 只读接口 | 权限 | 返回 |
| --- | --- | --- |
| `GET /api/v1/datasources/overview` | `sources-dashboard.view` | 来源选项、截止时刻、分组趋势和整段区间汇总 |
| `GET /api/v1/datasources/overview/details` | `sources-dashboard.view` 和 `collections.view` | 贡献记录分页，含来源、原记录编号及适用的结束时间或发现时间 |

后台接入查看权确定采集运行汇总的可见范围，沿用现有数据源管理边界。来源选项只返回编号和名称。选中的数据源是统计条件，调用者可按 `sourceId` 单源读取或汇总全部。原始任务、结构变化和目录继续在各自接口核验权限。

和反馈概览共用 `fromDate`、`toDate`、`timeZone`、`asOf` 以及日、自然周、自然月分组规则。缺省采用近 30 个北京时间业务日。下钻按 `metric` 选择 `SUCCEEDED`、`FAILED`、`CANCELLED`、`DURATION` 或 `PENDING`，沿用所选区间和原汇总截止时刻。

## 统计依据

| 读数 | 口径 |
| --- | --- |
| 运行趋势及结果环图 | 采集任务按 `ended_at` 进入所处区间。成功、失败和已确认取消分别计数。取消意图仍待确认的任务保留现行状态 |
| 成功采集平均耗时 | 仅取起止时间完整的成功任务，按 `ended_at - started_at` 计算执行秒数。全期按全部有效任务重算，无样本时为空 |
| 期末待核实变化 | 按原发现时间建立待核实区间，取首次人工核实、系统成功重读或后继变化发现作为退出边界。直接确认的采集变化不进入待核实存量。周末、月末取各分组截止时刻 |

汇总和明细使用同一组终态事实及历史变化条件。按截止时刻回看时，后续核实结果仅影响实际生效后的存量。V50 增加采集任务结束时间索引，期末待核实使用已有结构变化与核实台账。

## 验收

- 隔离平台库使用已有采集记录及可控终态样本。11 月 18 日至 23 日查询与独立 SQL 对账，得到成功 6 次、失败 1 次、取消 1 次，成功采集平均 22.7715 秒。跨业务日任务落在结束日，排队取消没有执行耗时。[汇总与明细](../../../output/acceptance/2026-11-23-source-overview/statistics.json) · [独立 SQL 结果](../../../output/acceptance/2026-11-23-source-overview/metrics-oracle.tsv)
- 历史样本覆盖人工核实、成功重读和后继变化，期末序列为 0、2、2、2、1、1。下钻可定位期末仍待核实的后继变化，日内截止点能读回人工核实前后的不同存量。周、月按各分组期末读取。[历史验证](../../../output/acceptance/2026-11-23-source-overview/statistics.json)
- 独立账号验证只看汇总、查看明细、已有会话撤权后的响应；共用期间调整后复验了反馈汇总与下钻。[权限证据](../../../output/acceptance/2026-11-23-source-overview/permissions.json)
