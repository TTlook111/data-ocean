# 数据源接入与采集接口

本页对应[采集设计](设计.md)，覆盖连接、凭据替换、手动及定时采集、目录与变化核实。关联字段和约束见[表结构](表结构.md)，完成条件见[验收](验收.md)。当前为评审稿。

## 共用契约与复用

以下路径均以 `/api/v1` 开头；返回沿用 `Result<T>`，SSE 除外。实体 ID 对外字符串、任务及命令 UUID、UTC 时间、分页、字段错误、CSRF、版本、核对凭据、幂等和无变化保存均引用[公共契约](../../architecture/接口与事件契约.md)。外部状态及类型代码接收字符串并校验，不直接用 Java enum 接收，不允许任意 Map 或未声明字段。

复用现有 `PageQuery`／`PageVO`、`CreatePreviewDTO<T>`、`ImpactPreviewVO`、`CommandLookupQuery`／`CommandStatusVO` 和 `MutationService` 的分页、非秘密核对和命令语义。计划状态变更与任务取消共用原因字段规则，现有 `ActionReasonDTO` 绑定 IAM 动作，数据源动作通过组合复用原因校验。核实证据是事实判断的输入，有独立模型。

每个写动作同时核所属页面权。`sources.*` 属 `sources.view`，`collections.*` 属 `collections.view`。目录读核 `catalog.view`，结构变化页签读核 `collections.view`，事实核实另核 `collections.review`。同一个路径按声明动作核权；“保存并启用”同时核保存权和启用权。选项、详情、统计和 SSE 均按对应资源重新核权。

## 连接接口

| 方法与路径 | 输入 | 返回与权限 |
| --- | --- | --- |
| GET `/datasources` | SourceQuery | PageVO<SourceRowVO>；sources.view |
| GET `/datasources/{id}` | 源 id | SourceDetailVO；sources.view，不回显秘密 |
| GET `/datasources/options` | purpose=CATALOG／COLLECTIONS | SourceOptionVO[]；分别 catalog.view／collections.view，只返回源 id、名称、生命周期及版本 |
| GET `/datasources/contact-options` | keyword、PageQuery | PageVO<UserOptionVO>；sources.create 或 sources.edit 及 sources.view，仅正常账号；复用现有安全人员选项，不依赖 users.view |
| POST `/datasources/impact-preview` | CreatePreviewDTO<SourceCreateProposalDTO> | ImpactPreviewVO；sources.create；拟启用再核 sources.enable；提案不含密码 |
| POST `/datasources` | SourceCreateDTO | 201，SourceMutationVO；按 DRAFT／ENABLED 目标核新增与启用能力 |
| POST `/datasources/{id}/impact-preview` | SourcePreviewDTO | ImpactPreviewVO；按声明动作核编辑、启用、发起／重试、替换或暂停／恢复计划的权限 |
| PUT `/datasources/{id}/configuration` | SourceUpdateDTO | 200，SourceMutationVO；sources.edit；已启用源在影响连接测试依据的变更上按设计复核 |
| POST `/datasources/{id}/enable` | SourceEnableDTO | 200，SourceMutationVO；sources.enable；仅启用已有草稿，不接收配置字段 |
| POST `/datasources/{id}/schedule/state` | ScheduleChangeDTO | 200，ScheduleMutationVO；sources.pause + sources.view；暂停或恢复现行计划，包括首次成功前保存的暂停设置 |
| POST `/datasources/connection-checks` | ConnectionCheckDTO，sourceId 为空 | 201，ConnectionCheckVO；sources.test；只测试未保存源，不创建正式数据源 |
| POST `/datasources/{id}/connection-checks` | ConnectionCheckDTO，sourceId 由路径决定 | 201，ConnectionCheckVO；sources.test；核基础源版本与拟测参数，不修改运行配置 |
| GET `/datasources/connection-checks/{checkId}` | 检查 id | ConnectionCheckVO；sources.test；未保存检查只对原操作者开放，已绑定源还核其当前读取资格 |
| POST `/datasources/{id}/credential-changes` | CredentialChangeDTO | 202，CredentialChangeVO；sources.edit；候选凭据经测试和核对后进入停止旧任务与替换流程 |
| GET `/datasources/{id}/credential-changes/{changeId}` | 源及替换操作 id | CredentialChangeVO；sources.view；非原操作者还需 sources.edit，返回不含候选秘密 |
| GET `/datasources/{id}/credential-changes/by-command/{commandId}` | 原替换命令 UUID | CredentialChangeVO；原命令主体与当前 sources.edit／sources.view，按同源 command_id 精确定位；不存在或不可披露返回 404 |
| GET `/commands/{commandId}` | 已有 CommandLookupQuery.operationCode | 已有 CommandStatusVO；原命令主体与当前操作资格，结果只给安全资源引用；不得返回密码正文 |

连接测试受平台超时、频率和并发限制，在有界请求内完成，不启动全库采集。业务能力检查失败仍是成功取得检查报告，返回 201 与逐项失败；身份、参数、平台存储不可用等协议错误按公共错误响应。HTTP 超时不能被当作测试通过，重发沿用原 Idempotency-Key。检查记录及命令回执不包含秘密。

## 连接输入字段

| 模型 | 字段与组合规则 |
| --- | --- |
| SourceConfigurationDTO | name 1—80；purpose 0—1000；technicalContactId／businessContactId 可空；databaseType=MYSQL／POSTGRESQL；host 最长 253，不能是含路径、userinfo 或任意 JDBC 参数的 URL；port 1—65535；databaseName／account 最长 160；schemas 为实际名称数组。输入长度按 Unicode 字符校验，数据库容量不截断原文 |
| RuntimePolicyDTO | maxConnections 1—20 默认 4；collectionConcurrency 1—8 默认 2 且不超过连接数；retryLimit 0—5 默认 2；taskTimeoutSeconds 30—3600 默认 600；queryTimeoutSeconds 1—300 默认 30；rowLimit 1—10000 默认 1000；syncHours 1—720 默认 24；windowStart／windowEnd 为 HH:mm，默认 02:00／05:00，不能相同。范围沿原型，正式容量须验证 |
| SourceCreateProposalDTO | configuration、runtimePolicy、targetLifecycle=DRAFT／ENABLED、credentialProvided 布尔值、checkId 可空；这是非秘密核对提案，credentialProvided 仅声明拟动作，不作为秘密已验证依据 |
| SourceCreateDTO | proposal、password 可空、reviewToken；新源名称必填，其他连接字段 DRAFT 可缺；ENABLED 必须完整并绑定有效 checkId，password 与测试凭据摘要一致 |
| SourceUpdateDTO | expectedVersion、configuration、runtimePolicy、credentialProvided、password 可空、checkId 可空、reviewToken；草稿允许不完整；已启用源不接收身份变更。实际账号或非空密码变化转专门替换接口，不能通过普通配置保存绕过停止旧任务 |
| SourceEnableDTO | expectedVersion、checkId、reviewToken；服务器读取已有完整草稿，不接收 userId、状态来源或连接资料 |
| ConnectionCheckDTO | 未保存或拟修改的连接字段、runtimePolicy、password 可空、expectedVersion（已保存源必填）；已有源密码留空使用现有受控引用，新密码只在连接层使用；不接受客户端版本识别结果或 canEnable |
| CredentialChangeProposalDTO | account、checkId、credentialProvided=true；不含密码。来源账号未改也须声明当前账号，核对时展示旧／新账号及受影响活动任务 |
| CredentialChangeDTO | expectedVersion、proposal、password、reviewToken；password 非空且与 checkId 绑定，不能替换数据库身份；操作接受后秘密只保存在加密候选引用 |
| SourcePreviewDTO | action、expectedVersion、proposal；UPDATE_CONFIG 绑定非秘密配置及测试依据，ENABLE 绑定 checkId，REPLACE_CREDENTIAL 绑定 CredentialChangeProposalDTO，START_COLLECTION 绑定可空 retryOfTaskId，PAUSE_SCHEDULE／RESUME_SCHEDULE 绑定 ScheduleProposalDTO |
| ScheduleProposalDTO | reason；暂停必填，恢复选填，非空值按公共原因长度及字符规则校验 |
| ScheduleChangeDTO | action=PAUSE_SCHEDULE／RESUME_SCHEDULE、expectedVersion、proposal: ScheduleProposalDTO、reviewToken；不接收周期、窗口或计划游标字段 |

configuration 的 runtimePolicy 使用明确组合，不在多个 DTO 复制相同字段；不同动作的目标状态、版本和秘密字段留在本动作外壳。MySQL 的 schemas 必须为空；PostgreSQL 可以保存未选范围的草稿，启用前须至少一个已核验可见 Schema。Schema 顺序变化不形成实质变更。

未保存源的检查由原操作者使用并在成功保存时绑定到新源；不能把另一个源的检查移植过来。已绑定同源同一连接依据的检查可由有权启用者复核使用，但必须重新核对当前凭据摘要、配置、有效期和披露资格，不能通过 checkId 绕过权限。核对凭据仍必须属于当前操作者。

所有含密码 DTO 从 toString、追踪、错误回显、命令序列化和浏览器缓存排除。预览不接收 password；请求秘密变化后重新测试，旧核对凭据不能证明新密码已验证。

## 连接返回与查询

| 模型 | 公开字段与含义 |
| --- | --- |
| SourceRowVO | id、name、databaseType、detectedVersion 可空、technicalContact、lifecycle、health、latestTaskSummary 可空、lastSuccessfulAt 可空、freshness: CatalogFreshnessVO、version；治理及知识统计取对应服务事实 |
| SourceDetailVO | 复用 SourceRowVO 同一披露范围，扩展 configuration、runtimePolicy、credentialConfigured、configurationRevision、currentSnapshotId 可空、capabilitySummary、schedule: ScheduleStatusVO、activeTaskId 可空、pendingCredentialChangeId 可空及配置修订摘要；无密码、密文、HMAC 或密钥路径 |
| SourceMutationVO | sourceId、version、configurationRevision、lifecycle、commandId；与共用命令引用保持关联 |
| ScheduleStatusVO | state=WAITING_FIRST_SUCCESS／READY／WAITING_WINDOW／BLOCKED／PAUSED／INACTIVE、paused、timeZone、scheduleRevision 可空、nextScheduledAt 可空、blockedReasonCode 可空；按当前计划推算下次可调度时间，阻断解除时间未知、暂停、未初始化或停用时为空 |
| ScheduleMutationVO | sourceId、version、commandId、schedule: ScheduleStatusVO；不改变连接修订，状态无变化时返回当前结果 |
| CatalogFreshnessVO | scopePending、stale、lastApplicableSuccessAt 可空、staleSince 可空；按适用范围计算，查询结果相同口径 |
| ConnectionCheckVO | checkId、sourceId 可空、checkedAt、expiresAt、detectedVersion 可空、availableSchemas、verifiedSchemas、coverage、items、readOnlySafety、businessReadStatus、canEnable；两个只读相关字段不合并 |
| CheckItemVO | code、label、status、message、verifiedObjectCount、verifiedSchemas；status=PASS／FAIL／UNVERIFIED；完整枚举零对象时本次结构读取允许 NOT_APPLICABLE 并明确覆盖为 0，不能拿来掩盖未完成枚举；属性支持情况列入 CapabilityAttributeVO[]，不返回业务行 |
| CapabilityAttributeVO | objectType、attributeKind、status、reason；status 另允许 NOT_APPLICABLE／UNSUPPORTED；实际未执行与适配器不支持分别表达 |
| CheckCoverageVO | enumerationScope、structureObjectRefs、businessProbeObjectRefs；对象引用仅包含本次测试权限内的路径及类型，不带样本或完整 SQL |
| CredentialChangeVO | changeId、sourceId、commandId、state=PENDING_STOP／APPLIED／FAILED、blockingTaskId 可空、executionState、acceptedAt、stopConfirmedAt 可空、completedAt 可空、currentConfigurationRevision、failureCode 可空、message；PENDING_STOP 显示当前停止核实状态；读取任务详情另核 collections.view |
| SourceQuery | name、databaseType、technicalContactKeyword、lifecycle，加 PageQuery；条件取交集，默认 updatedAt 倒序、id 倒序；排序白名单 name／updatedAt |

源详情的配置修订摘要保留当前有效修订及实际变更，启用已有草稿、重复测试及无修改保存不制造内容修订。联系人对象复用安全的人员引用结构，包含 id、姓名、登录名及必要状态，不复用会暴露其他人员资料的完整详情。

替换核对凭据绑定当时的活动任务，提交时如已出现另一笔在途任务，按公共 REVIEW_STALE 重新核对。从已保存操作回看时使用 changeId 或原命令定位，定时入口只在平台内部调用任务接收服务。计划状态依次判断 INACTIVE（源非启用）、WAITING_FIRST_SUCCESS、PAUSED、BLOCKED（同源占位或容量限制）、WAITING_WINDOW、READY（可推算计划）。暂停设置可在首次成功前保存，仍显示等待首次成功。

## 采集与目录接口

| 方法与路径 | 输入 | 返回与权限 |
| --- | --- | --- |
| POST `/datasources/{id}/collections` | StartCollectionDTO | 202，CollectionAcceptedVO；无 retryOfTaskId 核 collections.collect，有则核 collections.retry；均需 collections.view |
| GET `/datasources/{id}/collections` | CollectionQuery | PageVO<CollectionRowVO>；collections.view；固定当前源 |

| POST `/collection-tasks/{taskId}/cancel` | expectedVersion、reason、reviewToken | 202，CollectionCancelVO；collections.cancel；接收仅表示记录意图，已终态返回实际冲突及可回看任务 |

| GET `/datasources/{id}/objects/{objectId}` | snapshotId 可空 | CatalogObjectDetailVO；catalog.view；无 snapshotId 读当前目录，有值只允许同源成功快照中的成员 |
| GET `/datasources/{id}/catalog-observations/{observationId}` | 成功快照观察编号 | CatalogObjectDetailVO；catalog.view；用于尚无稳定对象身份的观察回看，不读取失败候选 |

| ConstraintVO | kind、name 可空、readStatus、members[]（ordinal、columnId、expression、targetColumnRef、sortDirection，除 ordinal 外按成员类型可空）、targetObjectRef 可空；保留复合约束真实顺序 |
| ViewFactsVO | definitionReadStatus、dependencyObjectRefs[]、refreshFacts 可空；不暴露配置范围外对象的受限内容，不将视图定义直接当作可执行查询 |

## 结构变化与核实接口

| 方法与路径 | 输入 | 返回与权限 |
| --- | --- | --- |
| GET `/datasources/{id}/changes` | StructureChangeQuery | PageVO<StructureChangeRowVO>；collections.view，固定当前源 |
| GET `/datasources/{id}/changes/{changeId}` | 源及变化 id | StructureChangeDetailVO；collections.view，回看本条记录的前后证据 |
| POST `/datasources/{id}/changes/{changeId}/impact-preview` | expectedVersion、proposal: ChangeReviewProposalDTO | ImpactPreviewVO；collections.view + collections.review，核对可办版本、证据和实际禁用影响 |
| POST `/datasources/{id}/changes/{changeId}/reviews` | ChangeReviewDTO | 200，ChangeReviewMutationVO；collections.view + collections.review，确认或排除事实 |

| 模型 | 字段与口径 |
| --- | --- |
| StructureChangeQuery | keyword（路径或变化项）、changeType、fromDate、toDate、timeZone、stage，按表头顺序提供筛选，加 PageQuery；objectId、taskId 可空，供来源跳转精确定位；默认 discoveredAt、changeId 倒序，排序白名单 discoveredAt |
| StructureChangeRowVO | changeId、sourceId、target、changeType、attributeKind、discoveredAt、factState、stage、version、successorChangeId 可空；阶段与事实状态独立 |
| ChangeTargetVO | targetKind=OBJECT／COLUMN／CONSTRAINT／VIEW_DEPENDENCY、beforePath 可空、afterPath 可空、objectId、columnId 均可空；路径只由真实对象、字段或约束名称组成，变化项单独显示 |
| StructureChangeDetailVO | 扩展 row 的同范围字段，增加 discoveryKind、sourceTaskId、before、after、evidence、latestReview 可空、impactRefs[]、pendingReviewCount；pendingReviewCount 为同一对象的全量可办理待核实数，与列表筛选无关 |
| ChangeEvidenceSideVO | snapshotId、observationId 可空、objectRevisionId 可空、columnRevisionId 可空、path 可空、value 可空、absenceReason=NOT_OBSERVED／NOT_IN_SCOPE 可空；快照必须同源且已成功 |
| ChangeValueVO | 按 valueKind 提供 TEXT（原注释或表达式）、BOOLEAN、NUMBER（顺序）、NATIVE_TYPE、REFERENCE（对象或字段引用）、STRUCTURE（约束或视图事实）或 ATTR_STATE；每种只接收对应的已声明字段，空内容与未读取分开 |
| ChangeReviewProposalDTO | decision、evidence（1—1000 个 Unicode 字符，去除首尾空白后必填）；ACCESS_LOST 允许 REMOVED／STILL_EXISTS，IDENTITY_UNCERTAIN 允许 SAME_OBJECT／REBUILT，其他待核实事实允许 CONFIRM／EXCLUDE |
| ChangeReviewDTO | expectedVersion、proposal: ChangeReviewProposalDTO、reviewToken；证据与选定结论一并绑定，客户端不填写来源快照、影响范围或身份分配 |
| ChangeReviewVO | decision（人工的允许值或系统的 READ_RESTORED）、evidence、reviewedBy、reviewedAt、verifiedObservationId 可空、解析后的 objectId／objectRevisionId 可空；保留历史观察及原判定 |
| ChangeReviewMutationVO | changeId、version、commandId、factState、stage、review、catalogVersion；更新同对象的核实摘要 |

变化类型使用 OBJECT_ADDED、OBJECT_REMOVED、OBJECT_RENAMED、OBJECT_REBUILT、ACCESS_LOST、IDENTITY_UNCERTAIN、COLUMN_ADDED、COLUMN_REMOVED、COLUMN_RENAMED、COLUMN_IDENTITY_UNCERTAIN、ATTRIBUTE_CHANGED。attributeKind 按实际事实返回 EXISTENCE、IDENTITY、NAME、TYPE、ORDINAL、NULLABILITY、DEFAULT、GENERATED、COMMENT、PARENT、CONSTRAINT、VIEW_DEFINITION、VIEW_DEPENDENCY、VIEW_REFRESH 或 ATTRIBUTE_STATE。核实保存原发现类型，确认后可更新显示类型及事实状态。影响引用须按目标模块权能披露，源记录只给获准的治理条目、知识待办和使用控制引用，具体内容由所属入口核权。变化阅读权允许回看本条前后差异；打开整份目录结构另核 catalog.view。

## 任务事件与模块通知

采集 SSE 复用任务信封，`requestId` 为 taskId，`stateVersion` 为任务 version。事件按同一采集任务权限过滤，进度以当前代次为准。过期或跨代次游标发送完整的获准快照；失败终态排除候选、计数和源侧执行句柄。

| eventType | payload |
| --- | --- |
| `collection.snapshot` | collection: CollectionDetailVO、streamEpoch、lastEventId 可空 |
| `collection.progress` | phase、counts: CountsVO |
| `task.cancellation` | status=REQUESTED／CONFIRMED／VERIFYING、executionState |
| `collection.finished` | state、content: TaskContentVO；仅三种采集终态 |

领域 Outbox 复用公共信封。任务接收发 `datasource.collection.requested`（sourceId、taskId）；目录成功、结构结论或可用性投影变化发 `datasource.catalog.changed`（sourceId、currentSnapshotId、catalogVersion），消费者按源和目录版本回读失败可补偿，使用限制在事实事务内生效。一次陈旧期间发一条 `datasource.catalog.stale`（sourceId、staleSince、scopeKey、lastApplicableSuccessAt 可空）。凭据成功切换沿用 `datasource.availability.changed`，reason 为 CREDENTIAL_REPLACED，消费者按源和配置版本核验持有的执行。领域消息与 SSE 均排除秘密、原始读取句柄和源库连接上下文。

## 错误与重复请求

身份、无权、字段、版本、核对过期、同键冲突、终态、旧执行代次、未知执行和平台依赖故障使用公共错误码。连接／采集的业务原因保存在检查报告或任务中，不把每个源库错误转成新的 HTTP 500。

| 模块代码 | HTTP／任务原因 | 含义 |
| --- | --- | --- |
| DS_NAME_EXISTS，409501 | 409 | 源名称重复，仅向有管理权者披露 |
| DS_CHECK_STALE，409502 | 409 | 测试过期、连接或凭据摘要、范围、适配器或平台策略不匹配 |
| DS_CHECK_REQUIRED，409503 | 409 | 未满足当前启用／替换条件；业务行读取失败本身不触发此码 |
| DS_COLLECTION_ACTIVE，409504 | 409 | 同源有排队、执行或停止尚未确认的任务 |
| DS_CONNECTION_IDENTITY_CHANGE，409505 | 409 | 已启用身份被改成另一端点／数据库，需新建源 |
| DS_CREDENTIAL_CHANGE_PENDING，409506 | 409 | 凭据替换在途，暂不接收新采集或冲突配置提交 |
| DS_CHANGE_NOT_REVIEWABLE，409507 | 409 | 变化已有结论、被转交或不属于本次核实动作；返回可披露的当前引用 |
| SOURCE_NETWORK／SOURCE_AUTHENTICATION／SOURCE_PERMISSION | 任务／测试原因 | 明确连接、认证及读取权限失败，不能泄漏秘密或业务记录 |
| SOURCE_STRUCTURE_INCOMPLETE／SOURCE_STRUCTURE_UNSTABLE | 任务原因 | 必要结构缺失或持续变化，候选不得成为目录 |
| SOURCE_CAPABILITY_UNSUPPORTED／SOURCE_SCOPE_UNVERIFIED | 任务／测试原因 | 必要能力不支持或配置边界无法核验 |
| WORKER_INTERRUPTED／TASK_BUDGET_EXCEEDED | 任务原因 | 进程中断或预算耗尽，保留原任务及候选，不自动拼接成功 |

同命令重发只返回原接收或提交事实；异步凭据替换仍需查询对应 changeId，不能把命令已接收显示为凭据已更新。响应不明时先查询现有命令，再读取资源当前状态；源创建、采集启动、取消和凭据替换均不得通过换 Idempotency-Key 掩盖旧请求的未知结果。

现有 CommandStatusVO.resultRef 使用十进制实体 ID 的 EntityVersionRefVO。采集和替换命令在此指向 sourceId；回包丢失后分别通过同源采集查询的 startCommandId 和凭据替换 by-command 找回业务 UUID。变化核实可指向 changeId。命令重放仍校验原主体及当前权限。
