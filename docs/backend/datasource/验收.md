# 数据源接入与采集验收

本页定义[设计](设计.md)、[接口](接口.md)和[表结构](表结构.md)的验收条件。除 API 与页面外，执行、快照、使用控制、审计及调度均以真实平台库和测试业务源的持久状态为依据。

## 当前验证范围

- 隔离平台 MySQL 验证 Flyway V1—V3。源库 MySQL 8.4.9 和 PostgreSQL 16.16 使用专用只读账号验证真实字段、注释、键、索引、视图及源端会话。源端单条查询停止与原会话实际结束分别核实。
- 双库真实 API 覆盖连接测试、启用、首次采集、同命令防重、成功目录与字段回看。另验证无变化快照、字段新增、权限不符合只读策略时保留旧目录、重试、定时暂停与恢复、成功切换到另一个只读账号及随后采集。见[接入与字段证据](../../../output/acceptance/datasource-20261118/api-initial.json)、[日常维护证据](../../../output/acceptance/datasource-20261118/api-maintenance.json)。
- 双库在原采集实际读取期间提交凭据替换，验证原任务取消、源端确认停止、随后切换新凭据及保留最近成功快照。见[在途替换证据](../../../output/acceptance/datasource-20261118/api-inflight.json)。
- 在最终构建上验证双库连接测试命令防重、对象消失后待核实、重复采集不新增同一待办、人工确认移除、原成功快照回看及任务 SSE 快照回执。见[结构核实证据](../../../output/acceptance/datasource-20261118/api-final.json)。
- 两种真实库均在采集已经读取部分对象后强制退出隔离应用。重启接管核实原连接已停止，原任务以执行进程中断收尾，已成功目录继续使用。见[进程重启证据](../../../output/acceptance/datasource-20261118/api-restart.json)。
- 正式 React 和真实 API 使用 ego-lite 验证两种数据库的目录和字段页，MySQL 另从页面发起采集并回看成功任务。见[MySQL 字段页](../../../output/playwright/datasource-live-20261118/mysql-fields.png)、[PostgreSQL 字段页](../../../output/playwright/datasource-live-20261118/postgresql-fields.png)。完整故障矩阵、不同源库版本、PC 原生缩放及下游治理使用控制仍待专项验证。
- 本机 MySQL 8.0.46 使用专用合成源复验首次和无变化采集、停用后实际访问阻断、连接复验恢复、退役及凭据解除、企业业务说明与原件历史。证据见[B 批验收](../access/验收.md)。
- MySQL 8.4.9 和 PostgreSQL 16.16 复验了连接、认证与 DNS 失败、成功快照、停用恢复及退役。隔离 PostgreSQL 连接检查另用环回无响应服务和不受信任的 CA 分别复验超时及证书错误。故障阻止使用失败的检查结果启用数据源，未执行的后续步骤保留未验证。见[B 批接口结果](../access/验收.md)和[网络故障结果](../../../output/acceptance/b-closeout-20261119/network-faults.json)。
- 同一合成源的新增列产生可回看的结构变化。临时撤掉专用账号的源库读取权限后采集失败，目录仍指向最近成功快照；恢复权限后再次采集成功，变化结果为无变化。见[结构与失败复验](../../../output/acceptance/data-access/collection-recheck.json)。

## 取消、替换与故障

| 编号 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| DS23 | 排队取消、运行取消、源库取消暂不确认 | 先记录取消意图；未知时保留真实执行和同源占位，不立即显示数据库已结束 |
| DS24 | 取消与成功竞争、旧工作者迟到、重复终态事件 | 只能有一个有效提交；取消先提交则不切换目录；成功先提交不倒改；旧执行代次无权写入 |
| DS25 | 页面关闭、刷新、退出、事件断连，随后重新打开 | 展示恢复原任务，不重新发起；普通退出不取消任务；账号停用或实际撤权阻断相应人工任务 |
| DS26 | 新密码测试失败；新凭据通过但多连接中仍有旧读取未确认停止 | 测试失败不变更旧配置和当前任务；有任一旧执行未确认停止，则操作为 PENDING_STOP，手动和定时均无法接收新任务，原运行引用及当前目录可回读 |
| DS27 | 旧任务结束后替换成功；对照停止后测试过期、配置冲突或实际失权 | 成功切换新修订并释放替换占位。原任务按实际终态回看，下一任务用新凭据和当时范围。失败保留原运行引用，回执有实际原因，原任务不复活，候选秘密不进入运行配置 |
| DS28 | 接收后、登记源连接前、登记后读取中及成功提交前后分别终止工作进程 | 按原命令／任务核实；接管按已登记连接验证源侧状态和可继续读取的资格。已提交成功可回读；未完成者确认结束后以中断失败或已取消收尾，旧代次无权写入或再发采集 |
| DS29 | 平台 MySQL 不可用，审计／Outbox 写入失败，通知回包丢失 | 不产生无审计成功或目录半切换；已提交事实可补投；依赖故障不停止或替换共享基础设施进行演示 |
| DS30 | 在日志、异常、命令回执、SSE、候选、详情及浏览器缓存查找合成秘密 | 原始密码、完整连接串、密钥及业务行不存在；仅专用凭据存储有受控密文引用 |

| 编号 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| DS31 | 同范围手动与定时采集内容相同；穿插失败、取消或提交回滚 | 每笔任务及候选可追溯。成功为 NO_CHANGE，复用结构修订；比较只选成功快照。失败与取消均保留原目录和变化列表 |

| DS33 | 稳定对象新增字段、注释、默认值、索引；有字段删除或确认不兼容 | 前后结构及稳定 ID 正确，可靠事实直接确认并进入对应治理。实际受影响依赖与事实同事务禁止，旁系条目继续可用。使用控制写入失败时目录和任务成功一起回滚 |
| DS34 | 对象消失，分别为权限被收回、仍存在、真实删除和重读成功 | 首先标访问丢失及待核实。仍存在可排除删除，读取异常直到真正重读才解除；确认删除写权威限制。重复消失且无新证据沿用未决项；成功重读已证实的同一对象时复用身份，不制造新增变化，也不自动解除既有禁止 |
| DS35 | 已证实名称变化；证据不足的同名重建；核实前又两次成功采集 | 有证据的改名保留稳定身份；待核实观察不承担旧依赖。证据发生实际变化才接续，始终沿用确证基准。旧记录可回看并跳到后续，无法用旧版本重复办理 |
| DS36 | 对照选择仍为原对象和确认同名重建；核实与采集成功并发 | 确认为原对象后补算被暂缓的真实差异；确认重建只产生一个新世代，旧依赖继续关联旧身份。比较依据已变须重算或拒绝过期提交；历史快照的观察身份和证据不被覆盖 |
| DS37 | 无关变化、属性能力由可读变为不支持；受影响条目完成审核、发布或显式解除 | 保留实际覆盖及未受影响的解释，能力变化不冒充删除。只回写对应变化的治理或知识阶段，办结与使用资格分别核实。尚待核实的同表项即使被筛选隐藏也阻断该表进入治理 |
| DS38 | 只有目录权、只有采集记录权、无核实动作权；跨源读取或提交变化证据 | 目录及变化页签、任务来源和事实核实分别核权。变化页只给本条证据；整份目录和下游详情另核资格。跨源编号、失败候选、猜测 UUID 或旧核对凭据均不能获得越权内容 |

## 证据与完成判定

按适配器类型、源库版本及对象类型分别记录真实结果。每个支持组合需留只读配置范围、元数据能力、原执行定位和停止确认依据。平台独立测试库须核对实际 DDL、索引与约束，覆盖串源引用、定时防重、事务回滚、当前指针及旧代次拒写；测试数据不含真实秘密。

MySQL 源侧复验使用专用只读测试账号及其采集连接，分别核实停止单条查询、关闭原连接、停止回包丢失及重启后接管。按原实例及原会话确认证据，记录最小所需权限和无法核实的条件。MySQL 发出停止响应时，源端仍可能在清理，见[官方 KILL 说明](https://dev.mysql.com/doc/refman/8.4/en/kill.html)。

本机 MySQL 8.4.9 已在隔离测试库验证 `SELECT` 和 `SHOW VIEW` 的专用账号能读取表、视图、索引和外键，并按实例与连接标记核实同账号的原会话。单条查询中断后原会话仍存在，关闭连接后标记消失且旧连接不可继续读取；强制退出读取进程后，独立连接能确认原会话已消失。结果覆盖本次版本和配置，正式 Java 适配器、回包丢失、编号复用及其他版本仍待验证。见[源端探针](../../../output/acceptance/2026-11-18-source-stop/mysql.json)。

单元测试覆盖计数、属性状态、比较键、触发窗口和命令状态。真实 API 与数据库证据覆盖连接、快照、并发、进程退出及在途替换。浏览器覆盖 PC 操作、失败保留、核对、取消进度、焦点与权限反馈。证据分别放 `output/acceptance` 和 `output/playwright`。原型仅供页面交互对照，治理、知识与问数使用实际依赖完成跨模块验收。
