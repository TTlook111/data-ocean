# 数据源接入与首次采集验收

本页定义[设计](设计.md)与[接口](接口.md)的完成条件。当前尚未实施或真实验收；离线原型只验证交互，不能代替业务源适配、权限、事务或进程故障验证。普通接口与页面之外，必须检查当前目录指针、实际源读取、审计和持久任务。

## 接入与权限

| 编号 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| DS01 | 只填名称保存草稿，再次打开补齐；重复名称、非法端口、无修改保存 | 草稿可不完整，已填字段仍校验；名称唯一；无变化不制造内容修订或重复成功审计；密码不回显 |
| DS02 | 只具新增、只具测试、只具启用或只具目录查看权，直接调用其他动作 | 每个动作及所属页面独立核权；保存并启用同时核保存与启用；目录权不产生业务数据访问 |
| DS03 | 测试元数据可读、业务行不可读或未验证的专用只读账号 | 只读安全及必要元数据能力满足可启用、可采集；业务行失败／未知原样显示，不伪装可问数 |
| DS04 | 使用含写权限账号或只读安全无法核验的账号 | 不进行试写，不用成功认证代替只读安全判定；不能启用或开始采集 |
| DS05 | DNS、连接超时、认证及证书分别失败 | 分项原因准确、后续未执行步骤为未验证；不关闭校验，不试授予权限，不返回秘密或业务样本 |
| DS06 | 测试后更改地址／账号／密码，复用其他人的未保存检查或其他源检查 | 服务端拒绝；伪造 canEnable 或测试通过数组无效；同源已保存检查仍核当前依据及使用资格 |
| DS07 | 修改联系人／用途、调整 Schema 顺序或缩小已验证范围 | 不强制重复网络测试；实质配置修改才增修订；扩大到未核验范围重新测试；已过期依据拒绝启用 |
| DS08 | PostgreSQL 未测试、未选择 Schema、移除到零项、同名表分布在不同 Schema | 测试前不可选，启用至少一项；范围贯穿核对、任务、目录；同名对象不混合；MySQL 不提供 Schema 输入 |
| DS09 | 变更已启用源的数据库身份；无目录查看权者启用源 | 身份变更要求新建源；无目录权返回原列表，不借自动跳转披露目录 |
| DS10 | 连接测试或采集尝试指向部署策略禁止的端口／解析地址 | 测试、正式连接及再次解析统一执行策略；不能用先前测试成功或直接 API 绕过 |

## 首次采集与目录

| 编号 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| DS11 | 启用尚未采集的源，打开采集核对并开始 | 启用不自动采集；目录保持空；只做一次范围及账号核对，记录真实操作者及配置 |
| DS12 | 双击启动、同键重发、不同键并发启动、接收响应丢失 | 同一命令一笔任务，同源仅一笔占位；回包不明查原命令，不新建任务规避未知状态 |
| DS13 | 包含表、视图、分区、系统对象及适配器可见的其他类型 | 全部分类记录，属性按类型读取；视图无伪造物理索引；不静默过滤已发现对象以获得成功 |
| DS14 | 无注释、无声明外键、明确不适用或可选不支持属性 | 保留真实空结果与原因；不等同于权限不足；必要身份、字段与类型不支持则不能成功 |
| DS15 | 枚举中断后已发现 23 项；读取失败也计入尝试数 | totalCount 未知而非 23 或 0；计数等式成立，不显示 100%，不推断对象删除 |
| DS16 | 发现 23 项，21 项完整、2 项索引无权限；另设核心字段读取失败 | 两种情况均整次失败，候选保存；第一次目录仍为空，不生成变化或治理事项 |
| DS17 | 完整枚举但零对象；对照枚举失败返回零项 | 前者可建立明确的零对象基线，后者失败；PostgreSQL 范围仍非空，不能把未知当空库 |
| DS18 | 全部结构完整的首次采集成功 | 原子切换当前成功快照；显示初始基线；无虚假结构变化、自动业务确认、授权或发布；源注释与业务解释分开 |
| DS19 | 失败或取消后修改权限／配置，再重新采集 | 新任务关联原任务，固定当前修订，读取完整范围；原任务、候选和原因仍保留，不拼接新旧片段 |
| DS20 | 采集中源库持续 DDL；其中一次复读稳定、另一次超出预算 | 稳定者保存一致的对象结构及读取时段；持续不稳定者失败，不承诺全库同一时刻 |
| DS21 | 请求别源 objectId／snapshotId，读取失败候选或未提交对象 | 当前目录和历史接口均不披露；成功历史绑定确切成员和结构修订，不读最新版替代 |
| DS22 | 列表组合搜索、日期、分页、空结果、详情返回 | 条件取交集；数量与列表范围一致；无权限不是零条；当前源、有效页码、滚动及焦点保留 |

## 取消、替换与故障

| 编号 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| DS23 | 排队取消、运行取消、源库取消暂不确认 | 先记录取消意图；未知时保留真实执行和同源占位，不立即显示数据库已结束 |
| DS24 | 取消与成功竞争、旧工作者迟到、重复终态事件 | 只能有一个有效提交；取消先提交则不切换目录；成功先提交不倒改；旧执行代次无权写入 |
| DS25 | 页面关闭、刷新、退出、事件断连，随后重新打开 | 展示恢复原任务，不重新发起；普通退出不取消任务；账号停用或实际撤权阻断相应人工任务 |
| DS26 | 新密码测试失败；新密码通过但旧任务停止未知 | 失败不影响旧配置和当前任务；停止未知时替换保持在途，新任务被阻断，运行引用不提前切换 |
| DS27 | 旧任务停止后替换成功；另测期间配置版本变化／测试过期 | 成功仅切换新配置及凭据引用，保留旧任务实际终态；冲突或过期不覆盖旧运行引用，不恢复已取消任务 |
| DS28 | 接收后、读取中、成功提交前后分别终止工作进程 | 按原命令／任务核实；已提交成功可回读，未完成者按中断失败；停止未知不并发新采集，不拼接候选续作 |
| DS29 | 平台 MySQL 不可用，审计／Outbox 写入失败，通知回包丢失 | 不产生无审计成功或目录半切换；已提交事实可补投；依赖故障不停止或替换共享基础设施进行演示 |
| DS30 | 在日志、异常、命令回执、SSE、候选、详情及浏览器缓存查找合成秘密 | 原始密码、完整连接串、密钥及业务行不存在；仅专用凭据存储有受控密文引用 |

## 后续定时与跨模块回归

| 编号 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| DS31 | 启用后首次成功前经过定时窗口；首次失败后继续等待 | 不自动启动首次采集，仍由人员修复并手动发起 |
| DS32 | 首次成功后到达周期；手动采集位于窗口外 | 定时按保存的周期、时段与业务时区执行；手动允许，仍受并发与预算限制 |
| DS33 | 同源繁忙、凭据替换、暂停／停用期间经过多个周期 | 不累计重叠任务或绕过阻断；触发合并及恢复按真实计划核实，不用系统调度冒充人员登录 |
| DS34 | 二次成功无变化、有变化、不可比范围，或失败／取消 | 接入快照比较及变化处理；无变化不新增结构修订；失败不覆盖成功目录；不可比范围不捏造删除 |

DS31—DS34 定义首次成功后的衔接条件，随二次采集和调度实际接入验收。首次链路通过不能记为真实定时、变化治理、授权或问数已通过。后续业务读取、知识禁止及凭据轮换接入时，回归源生命周期、读取权限变化与在途任务。

## 证据与完成判定

按适配器类型、源库版本及对象类型分别记录真实结果，不把 MySQL 的结果扩大为 PostgreSQL 验收。单元测试覆盖计数、属性状态、版本和规则；真实集成覆盖源库读取、平台事务、并发与进程退出；浏览器覆盖 PC 操作、失败保留、核对、取消进度、焦点与权限反馈。证据分别放 `output/acceptance` 和 `output/playwright`，不得记录真实秘密。

正式 DDL、真实接入与构建尚未产生，本页全部场景均为待实施验收条件。原型走查只能核对页面流转；不能把固定 TLS 通过、固定数据库版本、计时器成功或原型测试数量计入真实采集结果。
