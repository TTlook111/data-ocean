# 人员与权限首批接口

本页给出首批逐接口契约。公共返回、分页、幂等、日期、错误码及核对凭据见[公共契约](../../architecture/接口与事件契约.md)，业务条件和表结构入口见[设计](设计.md)。路径均以前缀 `/api/v1` 开始。表内返回类型指 Result 的 data；命令均按实际提交结果返回，不把收到请求当作成功执行。

## 共用类型与校验

`Id` 为十进制字符串，`Version` 为正整数，`Instant` 为 UTC 毫秒时刻；`PermissionCode` 为系统目录中的字符串。`Reason` 为 trim 后 1–500 字符，`ReviewToken` 为服务端不透明签名字符串；下文 `?` 表示可省略，`|null` 表示显式允许空。其他未标注字段必填，拒绝未声明输入字段。字符串长度按 Unicode 码点计算，密码不 trim；枚举按区分大小写的固定值校验。

| 类型 | 字段 |
| --- | --- |
| `EntityVersionRefVO` | `{id:Id,version:Version}` |
| `UserVersionRefVO` | `{userId:Id,version:Version}` |
| `RoleVersionRefVO` | `{roleId:Id,version:Version}` |
| `UserRefVO` | `{id:Id,username:string,displayName:string,displayStatus:UserDisplayStatus}` |
| `DepartmentRefVO` | `{id:Id,code:string,name:string,lifecycle:Lifecycle}` |
| `RoleRefVO` | `{id:Id,code:string,name:string,lifecycle:Lifecycle,version:Version,containsProtected:boolean}` |
| `MembershipSelectionDTO` | `{primaryDepartmentId:Id,secondaryDepartmentIds:Id[]}`，兼任去重且不含主部门，目标须正常；最多一个主部门 |
| `MutationVO` | `{commandId:string,targetType:string,targetId:Id,version:Version}`，只返回安全的目标引用，不返回请求中的密码 |
| `VersionActionDTO` | `{expectedVersion:Version,reviewToken:ReviewToken,reason:Reason}` |
| `RoleAssignmentDTO` | `{expectedVersion:Version,roles:RoleVersionRefVO[]}`，完整替换当前分配，可空；已有受保护分配普通接口只允许原样保留 |
| `CreatePreviewDTO<T>` | `{proposal:T}`；人员、角色和部门的创建核对共用此包装，各入口固定具体非秘密资料类型，不含密码和核对凭据，无基础对象版本 |

`Lifecycle=ENABLED|DISABLED|ARCHIVED`；`UserDisplayStatus=PENDING_FIRST_LOGIN|PASSWORD_CHANGE_REQUIRED|ENABLED|DISABLED|ARCHIVED`。正常／停用／归档与待改密的对应见设计。密码、确认密码、HMAC 和 Cookie 不进入任一 VO。

所有管理写接口需要有效完整登录、CSRF、Idempotency-Key 和当前能力；每个动作还须其目录中显式所属页面权。表内只列动作代码，不重复页面代码。读取、选项、计数与返回数据均核验当前查看资格。角色及数据源名称不参与身份判断。

本人联系方式修改同样使用 Idempotency-Key。登录、退出及本人改密按其专属会话语义处理，不使用通用命令结果重放。

已有对象的预览分别使用 `UserImpactPreviewDTO`、`DepartmentImpactPreviewDTO`、`RoleImpactPreviewDTO`，统一保留 `action`、`expectedVersion` 和 `proposal`。各输入按同级 action 直接绑定允许的具体提案，不再逐动作增加包装类型；提案自身仍执行完整字段及组合约束，并拒绝混入其他动作字段。

目标用户保留的角色中含受保护功能或受保护授予项时，重置、停用、恢复及归档另须 roles.protected，包含停用角色仍保留的分配；不允许普通管理员通过密码重置取得该账号能力。相关预览与提交使用同一规则。

## 登录与本人

| 方法与路径 | 入参 | 返回 | 资格与主要错误 |
| --- | --- | --- | --- |
| GET `/auth/csrf` | 无 | `CsrfVO` | 匿名或登录；依赖不可用 503；不返回登录会话 ID |
| POST `/auth/login` | `LoginDTO` | `LoginVO` | 匿名＋有效 CSRF；凭据不正确、停用或归档统一 AUTH_INVALID_CREDENTIALS，不枚举账号存在性；限流 429 |
| GET `/auth/me` | 无 | `CurrentSessionVO` | 完整或待改密会话；失效 401 |
| POST `/auth/logout` | 无 Body | `null` | 有效 CSRF；注销当前会话；已无登录时可幂等结束，返回统一成功响应，不触发后台任务取消 |
| POST `/auth/password/initial` | `InitialPasswordDTO` | `PasswordChangedVO` | 待改密会话＋CSRF；清除待改密并失效所有旧登录，必须重新登录；不走通用成功重放 |
| GET `/account` | 无 | `AccountVO` | 当前完整登录本人，不要求人员管理权限 |
| PUT `/account/contact` | `UpdateContactDTO` | `AccountVO` | 当前完整登录本人；用户版本 CAS；保存同一条人员资料 |
| POST `/account/password` | `ChangePasswordDTO` | `PasswordChangedVO` | 当前完整登录本人＋当前密码；不要求管理员重置权限，不走通用成功重放 |

| 请求类型 | 字段与组合校验 |
| --- | --- |
| `LoginDTO` | `{username:string,password:string}`；username trim 后 1–80，密码 1–32，不限制登录请求必须先符合新密码强度而泄露凭据状态 |
| `InitialPasswordDTO` | `{expectedVersion:Version,newPassword:string,confirmPassword:string}`；沿用当前受限会话认证，不增加原型中没有的当前密码输入；新密码满足规则且不同于现有散列对应密码 |
| `UpdateContactDTO` | `{expectedVersion:Version,phone:string|null,email:string|null}`；手机号最多 32、邮箱最多 254 并检查格式，空值可清空，无变化返回当前资料 |
| `ChangePasswordDTO` | `{expectedVersion:Version,currentPassword:string,newPassword:string,confirmPassword:string}`；当前密码正确、新密码 8–32 且包含字母数字、两次一致、新旧不同 |

| 返回类型 | 字段 |
| --- | --- |
| `CsrfVO` | `{headerName:string,token:string}`；仅 CSRF token，no-store，登录成功／退出后重新取 |
| `LoginVO` | `{userId:Id,authenticationState:AuthenticationState,mustChangePassword:boolean,absoluteExpiresAt:Instant}`；会话 Cookie 经响应头设置 |
| `CurrentSessionVO` | `{userId:Id,username:string,displayName:string,version:Version,authenticationState:AuthenticationState,mustChangePassword:boolean,absoluteExpiresAt:Instant,permissionCodes:PermissionCode[],securityVersion:string}`；待改密时 permissionCodes 为空，只用于必要导航和改密 |
| `PasswordChangedVO` | `{reloginRequired:true}`；响应后前端清理受限缓存并回登录页；回包丢失仍以服务端已更新认证版本为准 |
| `AccountVO` | `{id:Id,username:string,displayName:string,displayStatus:UserDisplayStatus,primaryDepartment:DepartmentRefVO|null,secondaryDepartments:DepartmentRefVO[],roles:RoleRefVO[],phone:string|null,email:string|null,version:Version}` |

`AuthenticationState=AUTHENTICATED|PASSWORD_CHANGE_REQUIRED`。失败按公共错误目录，其中本人当前密码不正确为 IAM_CURRENT_PASSWORD_INVALID，两次新密码不一致为 VALIDATION_FAILED，原密码相同为 IAM_PASSWORD_UNCHANGED。待改密会话访问其他接口统一 PASSWORD_CHANGE_REQUIRED。GET /auth/me 与 SSE 心跳不自动视为有效用户活动刷新空闲时限。

## 人员与选项

| 方法与路径 | 入参 | 返回 | 能力及业务条件 |
| --- | --- | --- | --- |
| GET `/iam/users` | `UserQuery` | `PageVO<UserRowVO>` | users.view；过滤后统计，不能返回无权数量 |
| GET `/iam/users/{id}` | 路径 Id | `UserDetailVO` | users.view；归档只读，数据访问区域另由 B 批服务提供 |
| POST `/iam/users/impact-preview` | `CreatePreviewDTO<NewUserProfileDTO>` | `ImpactPreviewVO` | users.create；初始角色非空另核 users.assign 及完整角色上限 |
| POST `/iam/users` | `CreateUserDTO` | `MutationVO` | users.create；初始角色非空另核 users.assign；201；登录名、主兼任、角色与密码同事务 |
| POST `/iam/users/{id}/impact-preview` | `UserImpactPreviewDTO` | `ImpactPreviewVO` | 按 action 对应 edit/transfer/disable/enable/archive/password 检查，不因能预览统一开放写权限 |
| PUT `/iam/users/{id}` | `UpdateUserDTO` | `MutationVO` | users.edit；若成员关系变化另核 users.transfer；一个事务保存整份人员表单 |
| PUT `/iam/users/{id}/memberships` | `TransferUserDTO` | `MutationVO` | users.transfer；不改变角色；结束移出部门对应来源，其他来源保留 |
| PUT `/iam/users/{id}/roles` | `RoleAssignmentDTO` | `MutationVO` | users.assign；完整能力与上限检查；沿用直接保存，不加原因与预览 |
| POST `/iam/users/{id}/disable` | `VersionActionDTO` | `MutationVO` | users.disable；停用及恢复途径保护，不能停用最后恢复人员 |
| POST `/iam/users/{id}/enable` | `EnableUserDTO` | `MutationVO` | users.enable；角色或归属变更另核 users.assign／users.transfer；复核来源，不恢复旧任务 |
| POST `/iam/users/{id}/archive` | `VersionActionDTO` | `MutationVO` | users.archive；已停用且外部责任／待办已处理；确认中明确结束当前角色及主兼任，保存归属快照并同事务归档，无需先调用一个不存在的“移出主部门”入口 |
| POST `/iam/users/{id}/password-reset` | `ResetPasswordDTO` | `MutationVO` | users.password；普通管理员不能凭重置绕过受保护账号安全及最后恢复途径保护 |
| GET `/iam/department-options` | `DepartmentOptionQuery` | `DepartmentOptionVO[]` | 需要相关人员创建／归属调整／恢复，或部门配置动作；仅返回本次动作可选部门和原已选项，不开放无条件目录查询 |
| GET `/iam/role-options` | `RoleOptionQuery` | `RoleOptionVO[]` | 需要 users.create/assign/enable 对应入口；按角色状态、完整能力和上限决定可分配；原已选停用／受保护角色只读保留 |
| GET `/iam/user-options` | `UserOptionQuery` | `UserOptionVO[]` | purpose 对应部门配置或成员加入权限；数据源审批负责人选项由 B 批数据源接口按其配置权限提供 |

| 请求类型 | 字段与校验 |
| --- | --- |
| `UserQuery` | PageQuery＋`{displayName?:string,username?:string,departmentId?:Id,includeDescendants?:boolean,displayStatus?:UserDisplayStatus}`；两个文本分别匹配姓名和登录名；选部门时默认包含后代并按人去重；sortBy=updatedAt/username/displayName，默认 updatedAt desc |
| `UserProfileDTO` | `{displayName:string,membership:MembershipSelectionDTO,phone:string|null,email:string|null,managementNote:string|null}`；新增、修改与修改预览共用的非秘密人员资料；姓名 trim 后 1–80、备注≤300，其余按共用校验 |
| `NewUserProfileDTO` | UserProfileDTO＋`{username:string,roles:RoleVersionRefVO[]}`；登录名 trim 后 1–80，仅新增人员时接收登录名和初始角色 |
| `CreateUserDTO` | NewUserProfileDTO＋`{initialPassword:string,reviewToken:ReviewToken}`；初始密码与新密码相同强度；初始角色允许空，默认角色仅作为可修改建议，不能隐式授予 |
| `UpdateUserDTO` | UserProfileDTO＋`{expectedVersion:Version,reviewToken:ReviewToken}`；登录名不作为修改字段，角色独立办理 |
| `TransferUserDTO` | `{expectedVersion:Version,membership:MembershipSelectionDTO,reason:Reason,reviewToken:ReviewToken}` |
| `EnableUserDTO` | `{expectedVersion:Version,membership:MembershipSelectionDTO,roles:RoleVersionRefVO[],reviewedAccess:boolean,reason:Reason,reviewToken:ReviewToken}`；reviewedAccess 必须 true，所有现存有效关系均纳入复核，不忽略兼任；待改密标记不因恢复清空 |
| `ResetPasswordDTO` | `{expectedVersion:Version,initialPassword:string,reason:Reason,reviewToken:ReviewToken}`；原因沿用原型必填；核对凭据不含密码，命令指纹含受控 HMAC；不在结果或审计保存密码 |
| `UserImpactPreviewDTO` | `{action:UserPreviewAction,expectedVersion:Version,proposal:UserProposalDTO}`；UserPreviewAction=UPDATE/TRANSFER/DISABLE/ENABLE/ARCHIVE/RESET_PASSWORD/PROTECTED_ROLES；proposal 对应动作 DTO 去掉 expectedVersion/reviewToken，RESET_PASSWORD 只用 `{reset:true,reason:Reason}`；DISABLE/ARCHIVE 的 proposal 仅含 reason；PROTECTED_ROLES 使用下文 ProtectedRoleAssignmentDTO 的 roles 与 reason |
| `DepartmentOptionQuery` | `{purpose:DepartmentOptionPurpose,q?:string,selectedIds?:Id[]}`；purpose=USER_CREATE/USER_TRANSFER/USER_ENABLE/DEPARTMENT_EDIT/MEMBER_TRANSFER；q 只匹配名称和编号 |
| `RoleOptionQuery` | `{purpose:RoleOptionPurpose,userId?:Id,q?:string}`；purpose=USER_CREATE/USER_ASSIGN/USER_ENABLE；非创建时 userId 必填，q 只匹配角色名 |
| `UserOptionQuery` | `{purpose:UserOptionPurpose,departmentId?:Id,q?:string}`；purpose=DEPARTMENT_MANAGER/MEMBER_ADD；后者 departmentId 必填，排除已在该部门的当前成员；q 匹配姓名或登录名 |
| `UserProposalDTO` | 由 UserPreviewAction 判别的严格联合结构，字段见下表；不允许把另一动作的字段混入当前提案 |
| `ActionReasonDTO` | `{reason:Reason}`；人员停用／归档、部门停用／归档及角色启用／停用／归档共用的原因提案；三个资源的预览输入分别声明允许的动作，各动作的权限与业务检查分别保留 |

| UserPreviewAction | proposal 字段，类型与对应正式 DTO 一致 |
| --- | --- |
| UPDATE | displayName、membership、phone、email、managementNote |
| TRANSFER | membership、reason |
| ENABLE | membership、roles、reviewedAccess、reason |
| DISABLE / ARCHIVE | reason |
| RESET_PASSWORD | reset=true、reason |
| PROTECTED_ROLES | roles、reason |

| 返回类型 | 字段 |
| --- | --- |
| `UserRowVO` | `{id:Id,username:string,displayName:string,primaryDepartment:DepartmentRefVO|null,secondaryDepartments:DepartmentRefVO[],roles:RoleRefVO[],displayStatus:UserDisplayStatus,version:Version,updatedAt:Instant}` |
| `UserDetailVO` | UserRowVO＋`{lifecycle:Lifecycle,mustChangePassword:boolean,phone:string|null,email:string|null,managementNote:string|null,firstLoginAt:Instant|null,disabledAt:Instant|null,archivedAt:Instant|null}` |
| `DepartmentOptionVO` | DepartmentRefVO＋`{version:Version,selectable:boolean}` |
| `RoleOptionVO` | RoleRefVO＋`{selectable:boolean,selected:boolean}`；不在人员分配弹窗展开功能明细 |
| `UserOptionVO` | UserRefVO＋`{version:Version,selectable:boolean}` |

选项结果初始最多 100 条，q 搜索后仍超限时返回 CAPACITY_EXCEEDED 并要求缩小搜索；不能静默截断后误认为查全。已选受保护或越界项按权限只读保留；原持有的停用普通角色可以移出，不能新分配。完整最终集合仍核验当前动作上限，selectedIds 不能枚举不可见对象。人员详情当前来源清单不包含在本批 VO 中，B 批通过独立受控来源接口接入。

归档人员 UserRowVO／UserDetailVO 的主兼任和角色字段读取归档快照，仅展示历史归属；不代表仍有当前分配。当前关系在归档事务中结束，状态和历史含义必须在页面保留，不能让后续角色改名改写归档时身份。

| ENABLE | reviewedMembers、reason |

| 返回类型 | 字段 |
| --- | --- |
| `DepartmentTreeVO` | `{id:Id,code:string,name:string,lifecycle:Lifecycle,version:Version,matched:boolean,totalMemberCount:number,children:DepartmentTreeVO[]}`；totalMemberCount 为本部门和后代当前成员按人员去重的数量 |
| `DepartmentDetailVO` | `{id:Id,code:string,name:string,parent:DepartmentRefVO|null,manager:UserRefVO|null,note:string|null,sortOrder:number,lifecycle:Lifecycle,version:Version,directMemberCount:number,descendantMemberCount:number,accessReviewRequired:boolean,updatedAt:Instant}`；汇总人数按人去重，后代计数不包含本部门 |
| `DepartmentMemberVO` | UserRowVO＋`{matchingMemberships:MembershipRefVO[]}`；匹配主兼任关系均保留，用户只占一行 |
| `MembershipRefVO` | `{id:Id,department:DepartmentRefVO,isPrimary:boolean,joinedAt:Instant}` |

父部门变化、成员增加移出、角色变化涉及的版本由事务统一递增，不能仅更新关系表而保留旧核对凭据。大批迁移的可接收上限在真实容量验证时固定，超限拒绝整批，不自动拆成不可见的部分提交。

## 角色、授予与恢复

| 方法与路径 | 入参 | 返回 | 能力及条件 |
| --- | --- | --- | --- |
| GET `/iam/permissions` | 无 | `PermissionPageVO[]` | roles.view 或已有 roles.create/edit/protected 的获准配置入口；返回系统目录，受保护标记只读 |
| GET `/iam/roles` | `RoleQuery` | `PageVO<RoleRowVO>` | roles.view；名称与状态过滤，不搜索说明 |
| GET `/iam/roles/{id}` | 路径 Id | `RoleDetailVO` | roles.view；只读查看使用功能，授予上限另核受保护权限 |
| GET `/iam/roles/{id}/members` | `PersonQuery` | `PageVO<UserRowVO>` | roles.view；当前分配人员含停用账号，不把停用误作已移出 |
| POST `/iam/roles/impact-preview` | `CreatePreviewDTO<RoleProfileDTO>` | `ImpactPreviewVO` | roles.create 及完整可授予能力 |
| POST `/iam/roles` | `CreateRoleDTO` | `MutationVO` | roles.create；201；普通接口不得含受保护项，至少一个可用功能，动作必须有页面权 |
| POST `/iam/roles/{id}/impact-preview` | `RoleImpactPreviewDTO` | `ImpactPreviewVO` | action 对应 edit/disable/enable/archive/protected；历史恢复另核 users.recover |
| PUT `/iam/roles/{id}` | `UpdateRoleDTO` | `MutationVO` | roles.edit 及完整授予能力；原受保护项只读保留；影响全部现有成员 |
| POST `/iam/roles/{id}/disable` | `VersionActionDTO` | `MutationVO` | roles.disable；含受保护项须另核 roles.protected；保留分配，检查最后恢复途径 |
| POST `/iam/roles/{id}/enable` | `VersionActionDTO` | `MutationVO` | roles.enable 及完整授予能力；含受保护项另核 roles.protected；重新核对当前实际内容 |
| POST `/iam/roles/{id}/archive` | `VersionActionDTO` | `MutationVO` | roles.archive；先停用且无当前成员，受保护历史按实际能力检查 |
| GET `/iam/roles/{id}/grant-limit` | 路径 Id | `GrantLimitVO` | roles.protected；仅功能授予目录，无数据源／规则名单 |
| PUT `/iam/roles/{id}/grant-limit` | `UpdateGrantLimitDTO` | `MutationVO` | roles.protected；受保护核对，不能提高操作者自己的上限 |
| PUT `/iam/roles/{id}/protected-permissions` | `UpdateProtectedRoleDTO` | `MutationVO` | roles.protected 及相应当前授予资格；完整目标权限集合，普通接口不能代办 |
| PUT `/iam/users/{id}/protected-roles` | `ProtectedRoleAssignmentDTO` | `MutationVO` | roles.protected＋users.assign 及完整授予资格；普通角色分配弹窗不新增受保护项 |
| POST `/iam/users/{id}/recovery-preview` | `RecoveryPreviewDTO` | `RecoveryPreviewVO` | users.recover；读取匹配目标的历史记录及角色快照，构造服务端提案 |
| POST `/iam/users/{id}/recover` | `RecoverUserDTO` | `MutationVO` | users.recover；目标可用、历史／当前角色相容、guard 内复核；不恢复旧任务或数据来源 |

| 请求类型 | 字段与校验 |
| --- | --- |
| `RoleQuery` | PageQuery＋`{name?:string,lifecycle?:Lifecycle}`；sortBy=updatedAt/name，默认 updatedAt desc |
| `PersonQuery` | 人员查询共用的 PageQuery＋`{displayName?:string,username?:string,displayStatus?:UserDisplayStatus}`；排序同 UserQuery，UserQuery 和 MemberQuery 分别扩展自身条件 |
| `RoleProfileDTO` | `{name:string,description:string|null,permissionCodes:PermissionCode[]}`；名称 trim 后 1–80、说明≤300，按目录校验去重，nameKey 按设计规范化后不得超 160 |
| `CreateRoleDTO` | RoleProfileDTO＋`{reviewToken:ReviewToken}`；新角色不继承上限和受保护标记；复制仅把普通可授予项作为新建表单建议 |
| `UpdateRoleDTO` | RoleProfileDTO＋`{expectedVersion:Version,reviewToken:ReviewToken}` |
| `UpdateGrantLimitDTO` | `{expectedVersion:Version,grantablePermissionCodes:PermissionCode[],reason:Reason,reviewToken:ReviewToken}`；可空，受保护项需实际授予资格，缩小不自动撤销别人使用权 |
| `UpdateProtectedRoleDTO` | RoleProfileDTO＋`{expectedVersion:Version,reason:Reason,reviewToken:ReviewToken}`；受保护及其页面权变化明确显示，整体检查全部既有成员 |
| `ProtectedRoleAssignmentDTO` | RoleAssignmentDTO＋`{reason:Reason,reviewToken:ReviewToken}`；使用用户 impact-preview 的 PROTECTED_ROLES 动作，须 roles.protected＋users.assign |
| `RoleImpactPreviewDTO` | `{action:RolePreviewAction,expectedVersion:Version,proposal:RoleProposalDTO}`；action=UPDATE/DISABLE/ENABLE/ARCHIVE/GRANT_LIMIT/PROTECTED_PERMISSIONS，proposal 为对应 DTO 去掉版本与核对凭据；DISABLE/ENABLE/ARCHIVE 绑定同一原因提案 |
| `RecoveryPreviewDTO` | `{expectedVersion:Version,sourceAuditId:Id,reason:Reason}`；历史须真实关联目标用户原有管理分配，不能指定任意权限列表 |
| `RecoverUserDTO` | RecoveryPreviewDTO＋`{reviewToken:ReviewToken}`；服务端从绑定历史和角色快照重建提案，内容变化不能沿用 token |
| `RoleProposalDTO` | 由 RolePreviewAction 判别的严格联合结构，字段见下表；字段类型与对应正式 DTO 一致 |

| RolePreviewAction | proposal 字段 |
| --- | --- |
| UPDATE | name、description、permissionCodes |
| DISABLE / ENABLE / ARCHIVE | reason |
| GRANT_LIMIT | grantablePermissionCodes、reason |
| PROTECTED_PERMISSIONS | name、description、permissionCodes、reason |

PROTECTED_ROLES 预览只向已有 roles.protected 和 users.assign 者提供。任何受保护变更均核对最后有效恢复途径，不能以系统角色名、isBuiltin 或复制角色作为豁免。

| 返回类型 | 字段 |
| --- | --- |
| `PermissionPageVO` | `{pageCode:PermissionCode,moduleCode:string,name:string,operations:PermissionVO[]}` |
| `PermissionVO` | `{code:PermissionCode,name:string,purpose:string,protected:boolean,enabled:boolean,pagePermissionCode:PermissionCode|null}` |
| `RoleRowVO` | `{id:Id,code:string,name:string,description:string|null,lifecycle:Lifecycle,isBuiltin:boolean,containsProtected:boolean,memberCount:number,version:Version,updatedAt:Instant}` |
| `RoleDetailVO` | RoleRowVO＋`{permissionCodes:PermissionCode[]}` |
| `GrantLimitVO` | `{roleId:Id,version:Version,grantablePermissionCodes:PermissionCode[]}` |
| `RecoveryPreviewVO` | ImpactPreviewVO＋`{sourceAuditId:Id,restoredRoles:RoleVersionRefVO[]}`；完整实际提案及变化由服务端核对，不能只预览人数 |

角色历史快照只供受保护恢复及审计定位，不新增普通历史编辑接口。归档、状态冲突及引用未处理返回对应公共错误；角色改名冲突返回 IAM_ROLE_NAME_EXISTS，完整能力越界返回 GRANT_LIMIT_EXCEEDED。

## 审计与命令核实

| 方法与路径 | 入参 | 返回 | 能力及条件 |
| --- | --- | --- | --- |
| GET `/iam/audit-records` | `AuditQuery` | `PageVO<AuditRowVO>` | audit.view；普通用户不取得记录和数量，失败／拒绝与成功分别展示 |
| GET `/iam/audit-records/{id}` | 路径 Id | `AuditDetailVO` | audit.view；关联原申请、授权及业务原文继续单独核权 |
| GET `/commands/{commandId}` | `CommandLookupQuery` | `CommandStatusVO` | 当前登录的原命令主体，重新核对原动作的当前可披露资格；不能查他人命令或把命令结果当新权限 |

| 类型 | 字段 |
| --- | --- |
| `AuditQuery` | PageQuery＋`{actor?:string,actionCode?:string,target?:string,outcome?:AuditOutcome,fromDate?:string,toDate?:string,timeZone?:string}`；操作者匹配历史姓名／登录名，目标匹配历史目标名或编号；时间用 occurredAt；sortBy=occurredAt，默认 desc |
| `AuditRowVO` | `{id:Id,actor:AuditActorVO,actionCode:string,targetType:string,targetId:string,targetName:string|null,outcome:AuditOutcome,occurredAt:Instant}`；AuditOutcome=SUCCESS/REJECTED/FAILED |
| `AuditActorVO` | `{kind:ActorKind,userId:Id|null,username:string|null,displayName:string|null}`；ActorKind=USER/SYSTEM/BOOTSTRAP，真实自动行为不伪造人为操作者 |
| `AuditDetailVO` | AuditRowVO＋`{reason:string|null,changes:ChangeVO[],securityVersion:string|null,commandId:string|null,businessRequestId:string|null,roleSnapshots:RoleVersionRefVO[]}`；ChangeVO 沿用公共契约，只含准许的必要差异 |
| `CommandLookupQuery` | `{operationCode:string}`；与当前用户及路径 commandId 一起定位唯一命令 |
| `CommandStatusVO` | `{commandId:string,operationCode:string,state:CommandState,resultCode:string|null,target:EntityVersionRefVO|null}`；CommandState=ACCEPTED/COMMITTED/REJECTED，响应敏感正文不能放入 target |

命令核实接口仅用于确定是否提交，登录失效后先重新登录；不能在匿名状态凭 commandId 查账号或密码变更结果。前端收到“已提交”后重新读取有权详情并更新列表、详情与数量，不把旧返回缓存覆盖新状态。

## 接口与物理记录的对应

| 动作组 | 主要写入 | 版本及审计 |
| --- | --- | --- |
| 登录／退出／改密 | Redis 登录会话；改密写 iam_user、iam_user_credential | 登录凭据校验绑定认证版本；改密／重置在同事务写审计与失效 Outbox |
| 人员资料／归属 | iam_user、iam_user_department | 每个受影响用户 version；组织动作同时更新相关部门聚合版本和权限版本 |
| 个人角色分配 | iam_user_role | 用户 version、所选角色 version、完整授予能力；分配历史保存当时角色版本 |
| 角色内容及上限 | iam_role、iam_role_permission、iam_role_grant_permission、iam_role_snapshot | 同事务递增角色 version、追加快照、递增权限版本，关联全部当前成员影响 |
| 部门生命周期／迁移 | iam_department、iam_user_department | guard 内无环、成员完整集合及各版本；当前数据来源由 B 批同事务服务协调 |
| 受保护配置与恢复 | 上述明确目标，不直接编辑历史 | guard 内最后恢复途径、历史兼容、当前资格、审计与通知 |
| 共用命令及通知 | sys_command、audit_record、sys_outbox、sys_event_receipt | 与业务可靠提交，失败不显示成功；事件消费独立幂等 |

本页所有写操作都须覆盖允许、拒绝、重复、版本变化与失败回滚场景，详见[验收](验收.md)。B 批接口不在本页伪造占位路径；进入实施前另补共享规则、申请、审批、来源和撤销的字段级完整契约。
