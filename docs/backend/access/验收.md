# B 批业务验收

## 可复验入口

在确认当前平台开发库已应用 V5—V9 的增量迁移，Flyway 校验 V1—V9。接口见[合成场景报告](../../../output/acceptance/data-access/api-report.json)。真实浏览器完成同一张合成单据的草稿恢复、分派、要求补充、重提、批准、授权追溯和撤销，核对返回保留输入，Esc 返回原入口，撤销保留其他有效来源。见[整单操作记录](../../../output/playwright/2026-11-19-b-recheck/request.json)、[补充核对](../../../output/playwright/2026-11-19-b-recheck/09-resubmission-preview-fixed.png)和[授权状态](../../../output/playwright/2026-11-19-b-recheck/grants-1024.png)。

在 1024、1280、1440、1536px 桌面视口复验数据源、审批责任、采集记录、目录、资料、输出规则、审批收件箱、授权及两个本人页面，无整页横向溢出。后台刷新保留当前结果和空态操作。鼠标与键盘清空后，筛选和焦点回到起点。授权与资料状态在 1024px 下可读。见[视口结果](../../../output/playwright/2026-11-19-b-recheck/viewport-report.json)、[空态操作](../../../output/playwright/2026-11-19-b-recheck/empty-filter.json)和[原型对照](../../../output/playwright/2026-11-18-b-prototype-alignment/report.html)。采集的双库历史验收见[采集验收](../datasource/验收.md)。

## 剩余验证

本轮真实 API 覆盖本机 MySQL 配置。PostgreSQL 在本轮环境未重复运行；实际库版本组合、采集完整故障矩阵、PC 原生缩放仍按数据源及前端验收执行。治理任务取用说明和目录、知识发布及问数输出约束，在对应批次接入后联调。
