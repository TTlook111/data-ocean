# 010 平台配置、通知与工作台

平台模块提供模型与提示词管理、运行状态、个人通知、后台操作日志及问数工作台。查询 SQL 的执行审计由[审计与血缘模块](011-audit-lineage.md)负责。

| 功能 | 实现方式 | 源码入口 |
| --- | --- | --- |
| 模型与供应商配置 | Java 在 `sys_config` 保存供应商和模型设置，对管理界面隐藏密钥，经 Python 调用供应商测试连接、同步模型及检测向量维度。变更已有 Embedding 配置会记录待切换设置和重建状态。 | [配置页面](../../frontend/src/views/admin/system/AiConfig.vue) · [管理接口](../../backend/DataOcean/src/main/java/com/dataocean/module/system/controller/AiConfigController.java) · [配置服务](../../backend/DataOcean/src/main/java/com/dataocean/module/system/service/impl/AiConfigServiceImpl.java) |
| 提示词版本 | 按场景维护草稿，校验内容后送审。审批针对指定版本，审核通过的版本可供运行时读取。回滚从历史版本生成新草稿。调用回执支撑版本使用记录和效果查询。 | [提示词页面](../../frontend/src/views/admin/semantics/PromptsView.vue) · [版本与审批](../../backend/DataOcean/src/main/java/com/dataocean/module/prompt/service/impl/PromptTemplateServiceImpl.java) · [调用记录](../../backend/DataOcean/src/main/java/com/dataocean/module/prompt/service/impl/PromptInvocationServiceImpl.java) · [Python 运行时](../../python-service/dataocean/prompt/service.py) |
| 健康状态、SQL 连接池与告警规则 | 运行页读取服务状态和连接池信息，支持按数据源重置连接池。告警规则接口提供配置维护。 | [运行页](../../frontend/src/views/admin/system/RuntimeView.vue) · [健康接口](../../backend/DataOcean/src/main/java/com/dataocean/common/health/SystemHealthController.java) · [连接池实现](../../python-service/dataocean/sandbox/pool_manager.py) · [告警规则接口](../../backend/DataOcean/src/main/java/com/dataocean/module/audit/controller/AlertController.java) |
| 通知与后台操作日志 | 通知按收件人分页、计算未读数并支持单条或批量标记已读。后台操作日志由切面采集，经独立的 `operation-log:view` 权限按条件查询。 | [个人通知](../../backend/DataOcean/src/main/java/com/dataocean/module/system/service/impl/NotificationServiceImpl.java) · [操作日志切面](../../backend/DataOcean/src/main/java/com/dataocean/module/system/aspect/OperationLogAspect.java) · [操作日志接口](../../backend/DataOcean/src/main/java/com/dataocean/module/system/controller/OperationLogController.java) |
| 工作台 | 汇总负责范围内的问数任务状态、等候时间和用户赞踩，提供慢回答和点踩记录的分页明细。回答耗时从任务创建计至服务端完成。使用量和反馈分别按审计、治理权限可见的数据源统计。 | [工作台](../../frontend/src/views/AdminHomeView.vue) · [统计接口](../../backend/DataOcean/src/main/java/com/dataocean/module/dashboard/controller/QueryExperienceController.java) · [范围与指标计算](../../backend/DataOcean/src/main/java/com/dataocean/module/dashboard/service/impl/QueryExperienceServiceImpl.java) · [聚合与明细 SQL](../../backend/DataOcean/src/main/resources/mapper/dashboard/QueryExperienceMapper.xml) |
