# 007 IAM-SIMPLE-1 权限

S1 在 Java 侧分别裁决用户可以执行哪些功能、可以管理哪些数据源，以及在问数中可以读取哪些业务数据。功能定义来自固定目录，授权依据来自 S1 的角色绑定、负责源、数据授权和字段保护记录。[功能目录](../../backend/DataOcean/src/main/java/com/dataocean/module/permission/s1/catalog/IamS1FunctionCatalog.java)、[授权工作区](../../frontend/src/views/admin/access/IamS1AccessWorkspaceView.vue)

## 授权与申请

| 业务路径 | 实现与边界 |
| --- | --- |
| 后台功能与管理范围 | 全局操作核对功能码。管理某个数据源时，功能和负责源须来自用户的同一角色绑定。对快照、文档等对象的操作先解析对象的真实所属数据源。注解切面与显式权限检查分别覆盖相应接口。[权限切面](../../backend/DataOcean/src/main/java/com/dataocean/module/permission/s1/aspect/IamS1AuthorizationAspect.java)、[管理权限检查](../../backend/DataOcean/src/main/java/com/dataocean/module/permission/s1/support/IamS1AdminGuard.java)、[能力快照](../../backend/DataOcean/src/main/java/com/dataocean/module/permission/s1/service/impl/IamS1CapabilityServiceImpl.java) |
| 可查询数据 | 汇总用户、部门和角色的有效数据授权，结合禁止规则、有效期限、行条件与列保护，形成目标数据源上本次请求的授权结果。后台管理身份本身不会产生业务数据授权。[授权写入与撤销](../../backend/DataOcean/src/main/java/com/dataocean/module/permission/s1/service/impl/IamS1DataGrantServiceImpl.java)、[数据授权裁决](../../backend/DataOcean/src/main/java/com/dataocean/module/permission/s1/service/impl/IamS1DataAuthorizationResolverImpl.java) |
| 字段保护 | 管理员可保存、撤销保护策略，也可审阅元数据产生的脱敏候选。确认候选时复核目标字段并落地保护设置。查询阶段再据实际输出来源施加保护。[保护规则](../../backend/DataOcean/src/main/java/com/dataocean/module/permission/s1/service/impl/IamS1FieldProtectionServiceImpl.java)、[脱敏候选](../../backend/DataOcean/src/main/java/com/dataocean/module/metadata/service/impl/MetadataMaskCandidateServiceImpl.java) |
| 临时访问 | 用户申请指定源、快照、表字段与有效期，可撤回待审申请。审批人须对该源有审批能力且不能自审。批准时核对授权范围、禁止规则、隐藏字段与元数据可用性，在事务内创建限时授权并记录决定。禁用或废弃的资源无法经此路径放行。[申请与审批](../../backend/DataOcean/src/main/java/com/dataocean/module/permission/s1/service/impl/IamS1AccessRequestServiceImpl.java)、[审批页面](../../frontend/src/views/admin/access/IamS1ApprovalView.vue) |

## 权限如何作用于问数

Python 在已授权的数据范围内解析 SQL，分别检查投影、筛选、连接等字段用途，并在相应作用域内注入参数化行条件。仅用于服务端行策略的列不因此进入用户可查询的列集合。Java 对每次尝试重新授权，并在交付前依据实际输出来源处理脱敏。历史结果、SQL 查看和导出各自按当前权限检查。[SQL 权限校验](../../python-service/dataocean/iam_s1/sql_security.py)、[执行与结果保护](../../backend/DataOcean/src/main/java/com/dataocean/module/query/service/impl/IamS1QueryAttemptServiceImpl.java)、[结果与导出](../../backend/DataOcean/src/main/java/com/dataocean/module/query/service/impl/IamS1QueryServiceImpl.java)

需要解释某用户的实际权限时，后台预览调用同一数据授权裁决器。查看者本人的功能和数据源范围也接受校验。[实际权限预览](../../backend/DataOcean/src/main/java/com/dataocean/module/permission/s1/service/impl/IamS1EffectivePermissionServiceImpl.java)
