# 007 人员、角色与功能权限

正式 IAM 由 Java 决定当前页面权、操作权、个人角色和逐动作授予上限。角色名称及内置标记不放行，管理角色不自动产生数据源访问。规则与接口见[设计](../backend/iam/设计.md)和[接口](../backend/iam/接口.md)。

## 当前正式实现

| 范围 | 源码与约束 |
| --- | --- |
| 使用权与授予上限 | [PermissionServiceImpl](../../backend/src/main/java/com/dataocean/module/iam/service/impl/PermissionServiceImpl.java)；动作仍需所属页面权，检查完整实际能力，不依赖前端勾选或角色名称 |
| 角色及历史恢复 | [RoleServiceImpl](../../backend/src/main/java/com/dataocean/module/iam/service/impl/RoleServiceImpl.java)；使用权、上限及快照分开，停用保留分配，有当前成员不可归档，恢复核验当前兼容性 |
| 个人角色与受保护管理 | [AssignmentServiceImpl](../../backend/src/main/java/com/dataocean/module/iam/service/impl/AssignmentServiceImpl.java)、[受保护入口](../../backend/src/main/java/com/dataocean/module/iam/controller/ProtectedIdentityController.java)；普通分配直接保存，受保护变更另核验，自身上限不可借新提案提高 |
| 核对与可靠提交 | [核对服务](../../backend/src/main/java/com/dataocean/module/iam/service/impl/ReviewServiceImpl.java)、[命令事务](../../backend/src/main/java/com/dataocean/module/iam/service/impl/MutationServiceImpl.java)、[Outbox](../../backend/src/main/java/com/dataocean/module/iam/service/OutboxDispatcher.java)；核对绑定操作者和安全版本，命令、成功审计及事件同事务 |
| 审计 | [审计模块](../../backend/src/main/java/com/dataocean/module/audit/)；成功保留最小差异，拒绝与失败独立记录，历史身份只读，秘密不入审计 |
| React | [角色列表、详情及配置](../../frontend/src/modules/iam/RolesPage.tsx)、[权限审计](../../frontend/src/modules/iam/AuditPage.tsx)、[共用核对](../../frontend/src/shared/ReviewDialog.tsx)；返回恢复列表上下文，布局以原型为准 |

最后恢复途径在配置锁内计算实际可用图，不只计算管理员人数；停用、重置密码、角色与上限调整均不能将恢复图清空。真实验证范围见[首批验收](../backend/iam/验收.md)。

## 数据访问接入边界

数据源访问、部门初始配置、申请审批、授权来源和输出限制由 [B 批授权服务](README.md#数据访问授权)提供。审计页通过申请和授权各自的读取接口核验追溯资格。
