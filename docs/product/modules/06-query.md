# 智能问数与查询流程

本页帮助理解方案第 6 章的职责和衔接，详细规则以[方案原件](../产品方案.docx)为准；不表示模块已经实现。

## 职责与使用者

有权用户在独立问数工作台提出、补充或修正问题。

## 主流程

选单一数据源 → 理解与澄清 → 授权检索和同版详情 → SQL 生成与校验 → 只读执行 → 结果与反馈。

## 衔接与边界

- 同一输入框承载追问、改条件和换题；切源隔离上下文，不跨源拼接结果。
- 业务歧义、无权限、知识不足和技术失败分别处理，不凭猜测执行。
- 历史展示当次事实，重新查询产生新记录；问数结果能查看即可导出，不提供回答分享。
