# 智能问数与查询流程

本页是方案第 6 章的阅读入口，详细业务规则只维护在[产品方案](../产品方案.docx)。

## 职责与主链

单源提问 → 理解与必要追问 → 检索及同版详情补取 → 生成 SQL → 意图、安全与输出核验 → 只读执行 → 结果、解释及反馈。

补齐原缺项回暂停节点续作，改变原意才重新理解；同题已确定时间区间不因等待或重试漂移。正式问数只使用获准、同版且当前可用知识，输出限制与禁止使用分别核验。历史保留当次事实，重新查询形成关联新请求。
