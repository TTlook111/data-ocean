# 用户反馈与持续改进

本页是方案第 7 章的阅读入口，详细业务规则只维护在[产品方案](../产品方案.docx)。

## 职责与主链

接收反馈 → 核查与分派 → 治理、技术或源数据处理 → 验证 → 结案并回告；无需修复可凭依据说明结案。

反馈是线索，分派不扩权；跟进不算完成。已解决、其他结案和已合并分别统计。核实后的业务定义修正沿用治理、知识文档与发布流程。

## 按问题读取方案

| 问题 | 第 7 章小节 |
| --- | --- |
| 评价、证据与统一队列 | 2 端到端闭环；4 统一问题队列与责任 |
| 事项状态、退出、合并与重开 | 事项状态与关闭规则 |
| 记录边界、归组与归因 | 3 治理成果与反馈记录分开；5 相似问题归组与问题归因 |
| 权限与回告 | 7 权限与信息可见范围；9 处理完成后的结果提示 |
| 验收与配置 | 12 完整目标验收；13 配置与生效要求 |

在仓库根目录运行 `.\tools\read-product-plan.ps1 -Chapter 7` 列出小节，再以 `-Section '小节标题'` 读取对应正文和表格；流程图查看方案原件。
