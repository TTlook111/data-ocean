# 用户反馈与持续改进

本页帮助理解方案第 7 章的职责和衔接，详细规则以[方案原件](../产品方案.docx)为准；不表示模块已经实现。

## 职责与使用者

分流者指定责任，治理或技术处理者核查原因，验证者确认结果。

## 主流程

接收反馈 → 核对与分派 → 补充或处理 → 候选回归 → 生效后复验 → 结案并回告原提问人。

## 衔接与边界

- 反馈是线索，不能直接改写治理事实或放宽权限；分派任务不授予业务数据访问权。
- 状态沿用方案统一字典；已解决、其他结案、已合并分别统计。
- 处理结论、验证结果和通知投递分别记录，知识修正需经过治理与发布。
