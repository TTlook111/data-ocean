# 项目定位与整体流程

本页帮助理解方案第 1 章的职责和衔接，详细规则以[方案原件](../产品方案.docx)为准；不表示模块已经实现。

## 职责与使用者

管理员、治理人员、分析人员及普通问数用户通过各自职责协作。

## 主流程

接入数据源 → 治理确认 → 知识构建与发布 → 授权问数 → 反馈核实与复验。

## 衔接与边界

- 一次部署服务一家企业及多个部门；可接入多个数据源，每次问数只使用一个源。
- 源业务数据库只读，平台维护自己的治理、知识与流程记录。
- 治理确认、知识发布、业务授权是不同动作，不能互相代替。
