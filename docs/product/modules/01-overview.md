# 项目定位与整体流程

本页是方案第 1 章的阅读入口，详细业务规则只维护在[产品方案](../产品方案.docx)。

## 职责与主链

接入数据源 → 治理确认 → 知识构建与发布 → 授权问数 → 反馈核实与复验。

一次部署服务一家企业；可接多个数据源，每次问数只使用一个源。业务库只读。治理确认、知识发布、数据访问授权分别办理。
