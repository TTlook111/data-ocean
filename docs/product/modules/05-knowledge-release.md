# 知识库与发布管理

本页帮助理解方案第 5 章的职责和衔接，详细规则以[方案原件](../产品方案.docx)为准；不表示模块已经实现。

## 职责与使用者

知识整理、测试及发布人员各自处理获准范围的文档和候选版本。

## 主流程

已确认治理内容 → 知识草稿 → 候选构建与相关测试 → 发布检查 → 范围整体切换 → 影响复核或回退。

## 衔接与边界

- 草稿、候选与当前有效版本隔离；构建或测试失败不切换有效版本。
- 知识含义改变需回到治理记录确认，不能产生两套口径。
- 回退仅到直接上一版，并重新检查当前依赖和禁止状态；回退不恢复已撤销权限。
