# 知识库与发布管理

[产品方案第 5 章](../产品方案.docx)维护知识文档、标准题、发布与恢复的业务规则。本页提供阅读顺序、职责和重构输入，不另维护一套详细规则。页面表达见[知识页面说明](../../frontend/pages/knowledge-release.md)，实现与验证边界见[原型状态](../../frontend/原型状态.md)。

## 职责与主流程

治理维护唯一的表说明、字段、关联和指标定义。知识模块组织这些已确认成果，不另创业务口径，不管理主题或场景分类；每份文档属于一个源，单次问数不跨源。

发起规划 → AI 提出文档建议 → 人工调整职责并核对完整范围 → 生成或合并草稿 → 确认实际修订 → 固定候选、构建和相关验证 → 发布预检 → 本批完整切换。

规划在有权限者发起时产生，不是进入列表就自动在后台运行。建议包含名称、用途、适用条件、问题、用表作用、依据、已有文档匹配和缺项。规划建议尚不算真实文档，生成草稿不等于发布；同一有权限者可以兼任，各步仍分别核权和留记录。
