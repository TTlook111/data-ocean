# 数据源接入与元数据采集

本页是方案第 3 章的阅读入口，详细业务规则只维护在[产品方案](../产品方案.docx)。

## 职责与主链

配置一套只读账号与读取范围 → 测试连接 → 成功采集建立目录 → 核实来源变化 → 交治理处理影响。

只有采集成功更新目录并分析差异，事实核实不代替业务审核。停用可复核恢复，退役只读留档。资料按源供治理参考，历史取用与成果引用约束删除。

## 按问题读取方案

| 问题 | 第 3 章小节 |
| --- | --- |
| 连接、账号与适配范围 | 5 连接配置与安全；6 分项连接测试；15 部署配置与适配边界 |
| 采集成功、快照与目录 | 7 全量采集的具体规则；9 状态和日常生命周期 |
| 来源变化、对象身份与恢复 | 10 元数据同步与结构变化；11 采集失败与故障恢复 |
| 业务说明与操作入口 | 13 管理界面与操作上下文；企业业务说明入口 |
| 验收 | 14 完整验收清单 |

在仓库根目录运行 `.\tools\read-product-plan.ps1 -Chapter 3` 列出小节，再以 `-Section '小节标题'` 读取对应正文和表格；流程图查看方案原件。
