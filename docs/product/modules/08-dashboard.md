# 治理与问数运营看板

本页是方案第 8 章的阅读入口，详细业务规则只维护在[产品方案](../产品方案.docx)。

## 职责与主链

选择数据源与期间 → 查看同口径趋势、存量及待处理项 → 按权下钻 → 进入责任模块处理。

总览和四个模块概览共用近 30 天默认期间，短期按天、长期按周或月汇总。期间发生量与期末存量分开；结果交付率、用户评价和业务正确性分别表达。

## 按问题读取方案

| 问题 | 第 8 章小节 |
| --- | --- |
| 信息与统计口径 | 2 看板需要提供的业务信息；4 趋势与统计的业务含义；5 指标定义与计算要求 |
| 问题线索、正确性与评测 | 3 问题线索与队列衔接；6 用户反馈与真实正确性分开 |
| 权限、页面与状态 | 8 角色视图与权限；9 页面状态与提示 |
| 验收及配置 | 13 验收要求；14 配置与模块协作 |

在仓库根目录运行 `.\tools\read-product-plan.ps1 -Chapter 8` 列出小节，再以 `-Section '小节标题'` 读取对应正文和表格；流程图查看方案原件。
