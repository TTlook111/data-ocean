# 治理与问数运营看板

本页帮助理解方案第 8 章的职责和衔接，详细规则以[方案原件](../产品方案.docx)为准；不表示模块已经实现。

## 职责与使用者

运营、治理和技术职责通过获准统计观察可用性、质量、积压和运行状态。

## 主流程

选择范围与期间 → 查看状态、趋势及待办 → 下钻证据 → 进入责任模块处理 → 回看处理结果。

## 衔接与边界

- 总览负责观察和进入处理流程，不代替治理修改、授权、发布或模型配置。
- 点赞率不等于业务正确性；零样本、未接入、延迟、失败和无权限分别表达。
- 统计与明细可见性分别控制，下钻保持业务范围和期间。
- 问数统计沿用问数模块的统一终态，单列资源或预算超限；有效结果已交付而解释失败时仍计已交付结果，并单列解释未完成，不把交付率当正确率。
