# 人员角色与权限

本页是方案第 2 章的阅读入口，详细业务规则只维护在[产品方案](../产品方案.docx)。

## 职责与主链

创建账号与首次改密 → 分配功能角色、关联部门初始访问 → 申请与审批生效 → 撤权、复核与恢复。

角色控制功能，部门提供直属成员的初始数据源访问，不形成业务记录过滤；额外申请审批通过即生效。同源有效来源的输出限制共同适用并按当前内容核验，历史快照保留。
