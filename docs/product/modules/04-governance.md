# 数据治理与业务知识审核

本页是方案第 4 章的阅读入口，详细业务规则只维护在[产品方案](../产品方案.docx)。

## 职责与主链

选择源与对象 → 自动取用有效资料、生成建议或人工填写 → 就地补充与逐项审核 → 交付已确认修订。

按源及对象组织，不设主题或场景分类。表说明、字段、关联和指标分别确认；主进度只汇总表说明与字段。来源核实结论只读沿用，受影响条目就地复核；AI 草稿、人工确认与知识发布分别表达。
