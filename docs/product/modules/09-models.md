# 模型管理与安全调用

本页帮助理解方案第 9 章的职责和衔接，详细规则以[方案原件](../产品方案.docx)为准；不表示模块已经实现。

## 职责与使用者

具有配置、测试、用途切换或诊断能力的人员维护对应事项。

## 主流程

维护配置修订 → 分层测试 → 绑定治理或问数用途 → 确认切换 → 监测并处理故障。

## 衔接与边界

- 治理生成、问数生成、向量和重排用途分别管理；切换模型不改变业务口径或数据权限。
- 生成模型切换不自动重建索引；检索配置变更按方案进入相应验证与发布流程。
- 凭据不回显，业务数据发送范围受控；模型不决定用户权限。
