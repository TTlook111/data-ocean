# 模型配置与安全调用

本页是方案第 9 章的阅读入口，详细业务规则只维护在[产品方案](../产品方案.docx)。

## 职责与主链

接入模型 → 为业务节点分配匹配能力 → 按当次配置调用 → 查看诊断并处理故障。

模型能力与接口格式分开。启停和连接测试分别表达，节点选择即保存；向量配置与索引匹配后才切换。模型提供生成与语义依据，权限、只读执行和发布仍由系统与人工规则控制。
