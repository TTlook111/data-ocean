## 按需读取原文

在仓库根目录运行：

```powershell
.\tools\read-product-plan.ps1
.\tools\read-product-plan.ps1 -Chapter 2
.\tools\read-product-plan.ps1 -Chapter 2 -Section '管理能力与可授予上限'
```

默认先列章节，指定章节后列小节；`-Section` 输出对应正文和表格，`-Full` 才输出整章。图示查看方案原件，不把文本提取当作完整图示信息。

## 维护边界

业务结论变化时更新方案对应条款和受影响解说；只改界面或技术细节时维护各自设计。解说不复制全部原文，不把尚未确认的技术建议写成已选架构。

## 架构与重构任务怎样读取

选定模块 → 读本模块列出的方案小节 → 核对页面专题与原型 → 只补必要上下游 → 沿[系统架构](../architecture/README.md)进入对应技术专题。已确认的技术栈与职责直接沿用，物理模型及逐接口结构按模块细化；实现后再补真实源码定位。

验收先对照方案本章的业务场景，再按[前端验收](../frontend/验收.md)检查界面与交互。实际原型覆盖统一见[原型状态](../frontend/原型状态.md)，真实服务另行验收。方案中的逻辑字段不直接作为物理表结构，原型样例不作为真实执行服务。
